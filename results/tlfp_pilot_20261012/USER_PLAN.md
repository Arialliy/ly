## 1. 思想与代码来源

NS-FPN（CVPR 2026）在低频引导特征净化LFP中，将低频的通道均值与最大值送入空间门控，用所得权重调制本帧高频，并对选定幅值范围的高频系数滤波、重建。这里只借鉴LFP，不引入其整个FPN或SFS模块。

DeepPro-Plus公开路径：conv_in -> layer1 -> 唯一TPro -> conv_out1 -> conv_out2。接入点固定在layer1之后、原维度置换之前；本地冻结源码是最终依据。其前端已经使用时空信息，所以S-LFP不是完整单帧检测器。

原始研究目标、借鉴空间算子、自己的候选机制分别登记，不能把二维换三维本身称为论文创新。

## 2. 候选假设

在原TPro读取特征之前，相比只依据本帧低频描述，允许低频引导门控读取相邻帧的低频描述，是否能更有选择地调节当前帧高频细节，从而恢复原漏检，而不是仅压低背景或整体提高响应？

该门控不跟踪目标、不配准背景、不平均邻帧高频，也不创造输入中不存在的目标信息。高频不等于噪声，低频不等于纯背景。它仅检验新增时间条件的价值，不预设长漏检由这一因素造成。

## 3. 网络定义

输入F：[B,C,T,H,W]，当前参考C=32。

1. 每帧沿空间维作已通过测试的Haar分解：得到L_t及三个高频子带H_t，保留通道/子带轴。
2. 生成G_t = concat(mean_c(L_t), max_c(L_t))，形状为[B,2,h,w]。
3. 空间控制：aS_t = sigmoid(Ks * G_t)，Ks为无偏置7×7卷积。
4. 时序候选：aT_t = sigmoid(K- * G_(t-1) + K0 * G_t + K+ * G_(t+1))。
5. 仍对当前帧H_t执行与空间控制相同的调制、条件Gaussian滤波及重建P(F)_t。
6. 输出Fout_t = F_t + tanh(alpha) * (P(F)_t - F_t)。不修改原TPro、BN状态、输出头、sigmoid、五窗融合、阈值和匹配。

原空间控制100参数 = 98门控 + sigma + alpha；时间候选296参数 = 294门控 + sigma + alpha（with_gauss=True且两标量可训练时）。这是参考规格，不推定所有本地修订恰有相同命名。

### 初始化与运算约定

- 从同一份未训练空间初始化复制，K0=Ks，K-/K+=0；sigma、alpha完全一致，alpha=0。
- 先构造并保存共同初始化，再分支成S和T。不是先训练S、再把更长训练预算给T。
- 原tanh(alpha)为有符号系数。alpha<0时可能反向放大残差差异；不得把任何输出都叫抑噪。本轮不顺手改成正门控。
- `gauss_gate=0.5`是参考代码中特征系数的条件滤波阈值，与检测概率0.5不同。
- 只读取当前合法窗口。首尾帧复制窗口内端点guide；复制不产生新证据。时间分块携带一帧halo，不得把内部块边界当成窗口边界。
- 不重新引入作者代码的已登记子带重排差异；沿用用户已通过检查的变换约定。

两组共同使用本轮登记的监督。建议延用已登记的有目标窗口损失与空窗top-1%负监督；标签支持域、正负权重、外层归约及1%选择不变。这是当前适配协议，不是作者原训练配方复现。若已有明确空间协议，则直接以其哈希为准，不混用历史多种配方。

若尚未冻结更新预算，建议首轮seed=46、512步，仅作为固定原型筛选；保存0、64、128、256、512，主结果512。已登记本轮预算则按原登记执行。无论选择什么预算，都在查看开发结果前固定两组相同方案，不能失败后自动延长。512步不是普遍充分收敛的声明。

数据曝光、batch、裁剪、优化器、学习率日程、精度模式完全一致；原模型参数及BN状态不动；不增加辅助损失、蒸馏、轨迹标签、额外数据、NMS或检测数量上限。

只向优化器传入新增模块参数。新增模块后的冻结TPro和头必须保留对输入的autograd：参数冻结并不意味着整段forward使用no_grad。前端若无可训练参数可用no_grad，但不要用inference_mode产生供可训练后续保存的张量而未经验证。

### 随训练同步记录，不增加新任务

alpha及tanh(alpha)；sigma；中心/邻帧门控核范数；gate饱和比例；修正/原特征范数；未加权正负损失及各自实际加权贡献；学习率和各新增参数的梯度与更新幅度。

alpha=0时，第一步gate及sigma梯度可能为零，而alpha有梯度；alpha更新后再验证门控梯度。不要为追求所有参数第一步非零而改初始化。

## 8. 预登记机制诊断与后续条件

固定T检查点，在同一次评价脚本中保存：

1. T-normal：真实邻帧guide。
2. T-current：三个时间槽都读取当前guide，仅在新增门控内替换。原F、当前高频、alpha/sigma和整个原网络均不动。
3. T-bypass：仅关闭新增适配器。原网络冻结且状态一致时应还原发布输出。

T-current等价于将门控核求时间和后应用到当前guide；它不是完整单帧baseline，也不是重训的容量控制。仅凭输入替换导致性能变化不能单独做因果证明，但如果新增恢复在T-current下全部保留，就不支持“必须使用实际邻帧”这一解释。

若T优于S且通过检测目标，再做同结构current-only训练控制及成对多seed/新来源验证。重复当前输入的三个线性核存在冗余，所以只能说名义参数/接口相同，不能声称有效容量被严格匹配。

不新增时间乱序大矩阵，不额外运行一个oracle，不需要先证明空间分支有效才运行T。

## 9. 去留

- S/T都只有背景下降、无实际恢复：不通过恢复目标。
- T≈S或不如S：不支持新增时间条件；不因参数更“新”而保留。
- 只多几个临界帧且最长漏检无改善：如实保留小增量，不升级持续漏检主线。
- T恢复多条轨迹原失败、背景/保持满足预定要求、优于S且诊断支持时间信息作用：进入重复与新来源，随后决定主线。
- 单seed失败只否定当前协议下筛选，不证明整个频域方向无效；也不自动解冻骨干、扫描核长或加分支挽救。
