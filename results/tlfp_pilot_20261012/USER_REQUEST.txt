## 一、我们在baseline上具体改什么？

### 固定网络：DeepPro‑Plus＋时序条件化频带调节

公开DeepPro‑Plus的路径是：前端提取全分辨率特征，经过唯一TPro，再进入原预测头。当前接入位置——`layer1`之后、原维度变换之前——与这条结构一致。[GitHub](https://raw.githubusercontent.com/TinaLRJ/DeepPro/main/networks/models/DeepPro-Plus.py)

本轮保持：

```text
输入：原合法40帧窗口
          ↓
原 conv_in、layer1
          ↓
【新增：低频条件化频带调节】
          ↓
原维度变换
          ↓
原唯一 TPro
          ↓
原预测头
          ↓
原 sigmoid、五窗融合、0.5阈值、组件匹配
```

**空间版本与时间版本是这个位置上的两个替代配置，不是前后串接两个分支。**

原TPro、预测头、输出概率含义和后处理都不变。也不再引入目标查询、轨迹分配、新响应标签、参考帧匹配或独立解码器。

### 借鉴部分与自己的候选部分

NS‑FPN的CVPR 2026论文提出低频引导特征净化LFP：通过处理高频成分减少干扰，再进行特征融合。其完整方法还包含特征采样等部分，我们本轮只借鉴LFP，不搬整套FPN。[开放获取计算机视觉论坛](https://openaccess.thecvf.com/content/CVPR2026/html/Yuan_Seeing_Through_the_Noise_Improving_Infrared_Small_Target_Detection_and_CVPR_2026_paper.html?utm_source=chatgpt.com)

| 部分 | 本轮定位 |
|---|---|
| 空间小波分解、低频引导高频调制、条件滤波与重建 | **借鉴机制及实现参照** |
| 将本帧低频引导扩展为合法邻帧的联合引导 | **我们的候选改动** |
| 保留原网络、使用零初始化特征修正 | **适配与实验控制方式，不单独作为创新** |
| 恢复持续漏检并控制背景与原成功丢失 | **最终研究目标** |

官方代码中的`SpatialAttention`由低频特征的通道均值和最大值生成空间权重；`wav_Enhance`用该权重调制本帧高频，再进行条件滤波和重建。我们据此明确扩展位置，而不是只借一个“频域增强”的名称。[GitHub](https://raw.githubusercontent.com/mengduann/NS-FPN/main/model/NS_FPN.py)

**“二维卷积换成三维卷积”本身不足以成为论文贡献。** 本轮需要证明的是：正确的时间条件，是否帮助模型作出空间控制做不到的、有利于目标恢复的特征选择。

## 二、它准备解决时序中的什么问题？

本轮假设应写成：

> **对当前帧的细节特征，仅根据本帧低频上下文决定保留或减弱，可能缺少对场景变化的判断。加入邻近时刻的低频信息，是否能更有选择地处理当前细节，使原TPro更容易区分目标与干扰？**

这里有一个关键设计区别：

**参考帧只帮助决定“怎样处理当前帧”，不把参考帧的高频内容搬进当前帧。**

因此，本方案不需要先从弱特征中找到可靠目标对应，也不直接对邻帧高频平均，避免将“取对参考目标”作为进入恢复路径的前提。

但它也有明确限制：

- 不是目标跟踪或运动补偿，不能保证处理大位移、强视差或遮挡。
- 高频不等于噪声，目标细节也可能被错误削弱。
- 低频不是纯背景；其他目标和场景结构也可能影响门控。
- 它不能创造输入中没有的目标证据，也不保证恢复全部极低响应对象。

此外，原DeepPro‑Plus前端已经包含时空处理。**S‑LFP不是完整的单帧模型；T‑LFP检验的是“门控处新增显式跨帧条件”的价值。** 不能把它包装成从无时序到有时序。[GitHub](https://raw.githubusercontent.com/TinaLRJ/DeepPro/main/networks/models/DeepPro-Plus.py)

当前材料已经支持真实失败存在，但没有证明“缺少这种门控”就是根因。这一归因边界继续保持。CLOSEOUT

## 三、模块怎样实现？

### 1. 保留已经通过检查的空间运算

令输入特征为：

\[
F\in\mathbb R^{B\times C\times T\times H\times W}.
\]

逐帧进行空间小波分解，得到低频 \(L_t\) 和三个高频子带 \(H_t\)。构造两通道低频描述：

\[
G_t=
\operatorname{Concat}
\left[
\operatorname{Mean}_{c}(L_t),
\operatorname{Max}_{c}(L_t)
\right].
\]

空间控制使用：

\[
A_t^{S}
=
\sigma(K_S*G_t).
\]

**沿用你已经验证的子带顺序、奇偶尺寸处理、Gaussian滤波和重建规则。** 不再次混入作者裸变换，也不顺手调整滤波阈值。

### 2. 时间版本只改变权重生成

时间版本使用：

\[
A_t^{T}
=
\sigma\left(
K_{-1}*G_{t-1}
+
K_0*G_t
+
K_{+1}*G_{t+1}
\right).
\]

对应实现是一个无偏置的：

```python
nn.Conv3d(
    in_channels=2,
    out_channels=1,
    kernel_size=(3, 7, 7),
    bias=False,
)
```

随后仍用 \(A_t^T\) 处理**当前帧** \(H_t\)，而不是将 \(H_{t-1}\) 或 \(H_{t+1}\) 聚合进来。

| 规格 | S‑LFP | T‑LFP |
|---|---:|---:|
| 低频门控 | \(7\times7\)空间卷积 | \(3\times7\times7\)时空卷积 |
| 门控权重 | 98 | 294 |
| 加上现有两个可训练标量 | **100** | **296** |
| 原模型参数 | 冻结 | 冻结 |
| 输出链 | 原样保留 | 原样保留 |

这些参数数目对应上传参考包的具体配置。本地字段或参数约束不同，应以实际计数为准，不能为了对齐296而修改已验证实现。

### 3. 用同一份空间初始化启动两组

初始化规定为：

\[
K_0=K_S,\qquad K_{-1}=K_{+1}=0.
\]

其他标量与空间版本相同。这样，时间门控初始退化为空间门控。

**不是先把S训练完，再给T接着训练。** 两组均从同一发布权重、同一份未训练空间初始化开始，避免T多获得一段训练预算。

在参考实现中，外部修正仍为：

\[
F_t^{\mathrm{out}}
=
F_t+\tanh(\alpha)
\left[P(F)_t-F_t\right].
\]

\(\alpha=0\)时起点与baseline一致，但训练后没有保持性保证。

还要保留两个细节：

**第一，\(\tanh(\alpha)\)有正负。** 负值可能反向放大修正，不能把模块任何作用都称为“抑噪”。本轮不顺手改成非负门控，否则又多改变一个因素。

**第二，代码中的`gauss_gate=0.5`是特征系数的滤波条件，与检测阈值0.5不是一回事。**

```python
temporal_candidate = TemporalLFPAdapter.from_spatial(
    spatial_init,
    mode="temporal",
    frame_chunk=8,

```

### 你本地只需补时间扩展新增的检查

已有空间检查继续保留，只新增以下验收：

| 检查 | 通过条件 |
|---|---|
| 时间核中心继承 | 邻帧核为零时，与空间版本一致 |
| 时间边界 | 不读取原窗口外帧，边界填充规则固定 |
| 时间分块 | 每块携带一帧外围上下文，内部块边界不当作窗口边界 |
| 实际梯度 | \(\alpha\)启动后，中心及邻帧核能够从检测损失获得更新 |
| 冻结与资源 | 原参数、BN不变；实际40帧输入的显存、耗时可接受 |

**参数冻结不能写成对整个后半网络使用`no_grad()`。** 新增模块之后的TPro和预测头，虽然参数不更新，仍需保留对输入的梯度，才能训练新增模块。PyTorch对参数冻结与关闭梯度记录有明确区分。[PyTorch 文档](https://docs.pytorch.org/docs/2.10/notes/autograd.html)

## 六、怎样检验“时序条件真的有用”？

除S与T的训练对照外，在预定终点保存三个固定输出：

| 输出 | 改变什么 | 回答什么 |
|---|---|---|
| **T正常** | 使用真实邻帧低频描述 | 完整候选结果 |
| **T当前帧替换** | 三个门控时间槽都读取当前 \(G_t\) | 新增检出是否依赖真实邻帧信息？ |
| **T关闭分支** | 只绕过适配器 | 在原网络完全冻结时，是否还原发布预测？ |

当前帧替换只作用于新增门控，**不替换整个输入序列，不改变当前帧高频，也不改原TPro输入之外的路径**。

如果T正常获得的恢复，在当前帧替换后全部保留，就不能用这些对象证明“真实时间条件是必要的”。如果替换后下降，也只能作为辅助证据，因为输入替换存在分布变化。

T相对S还有参数量差异。**只有首轮出现值得继续的检测收益，才增加同结构、三个槽均读当前帧的训练控制。** 它用于进一步排除额外参数和优化方式的解释，不必现在就展开大矩阵。
