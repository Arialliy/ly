# C-v2：同检查点的检测读出短修订

本轮落实用户提供的 C-v2 方案，完成训练链核验及三个额外 256 步的配对修订。旧 `track_contrast_v1` 的代码、结果和失败结论保持原样。参考代码来自用户指定的 `deeppro_c_v2_reference`，直接调用其 `temporal_miss_risk` 和 `visible_segments`；本地测试另存，不把参考包原有测试记录当作本地执行结果。

## 固定模型、数据与控制

CONT、FRAME、GAP 都从 C-v1 的 `snapshot_2048.pth` 恢复模型和完整 Adam 状态，seed46，学习率 1e-5、weight decay 1e-4、betas(0.9,0.999)、eps1e-8，无调度器。额外更新 256 次，主端点为 global step2304；2112/2176 只作过程记录，不选检查点。

唯一 TPro、conv_out1、conv_out2 的原有 28 个参数张量可训练，共 14,593 参数；总参数 70,913，无新参数。所有 BN 处于 eval，统计缓冲固定，原白名单内 BN affine 可训练。FP32、确定性运算、禁用 TF32。输入仍为原始 40 帧，微批量2。

三组同读原计划 indices0..255，即完成4轮512步后的自然下一段；每步4检测窗和4原有全局辅助窗，逐步核对输入、标签和辅助输入哈希。原 C 检测损失、同轨迹对比、可靠保持的代码、缓存、系数和归约完整复用。旧对比仍对完整请求配对数归约，旧保持仍按8窗、目标/背景固定各半归约，检测仍用前4窗。CONT 只优化该原 C 总损失。

## 新增读出与分组

从实际 `conv_out2` logits 取原整数半开目标框的均值，不归一化 logits，不增加读出层。困难背景沿用发布教师按 ROI 平均概率选取的位置；本地32像素范围候选、全局网格辅助窗候选都须整框合法。原检测窗的全局候选来自其对应辅助窗，辅助窗的全局候选来自自身整个裁块；均不穷举原始全画面。困难背景 logit 为当前模型两路中合法背景 ROI 均值的最大值。缺本地背景可用合法全局背景，反之亦然；两者都缺失时断开该观察，禁止跨越它构造连续段。

背景掩码排除全部现有已标注任务目标框及其2像素扩展区，包括非严格小目标和显式 ignore/crowd 框，并排除裁块9像素外圈。当前来源中的标注框均有效、可定位；这不能作为未来无法定位无效框的排除保证。现有数据没有额外的标注完整性区域或完整性真值，因此不能保证未标注目标已被排除。全256批缓存审计确认131,626个背景ROI整框合法，72,341个目标观察均具备两路合法背景；本轮实际未触发单路回退或缺背景断段。

新段使用全部8窗口内的合法严格小目标，沿用原最大边≤16像素、完整裁块核心框、无标注重叠及34个疑义身份排除，不要求属于旧 B/C 的共同配对集合，不按教师目标分数筛选。按同来源、同视频内身份、同窗口分段，输入帧编号与来源帧编号均须相邻；缺标、不可见状态、身份不确定、无效框或时间断点终止该段，不插值。

现有训练标注不含可见性/遮挡字段。因此本次实际使用“连续有效已标注段”，不能把它报告为已核实连续可见段；用户提供的参考包未补充此数据字段。若原标注新增显式可见性或遮挡状态字段，当前适配器会按未审核状态 schema 保守排除对应观察，不自动将其判为可见。

固定段长8个连续来源帧、步幅4；每条足够长的连续 run 末尾补一个对齐末帧的完整8帧段（若已存在则不重复）。前256训练批中246批有段，共15,591段，覆盖69,602/72,341个合法观察曝光、89个身份及全部8个训练来源；实际背景筛选后覆盖不变。尾对齐新增493段、补覆盖950个观察，全部段内重复曝光共124,728次。依据是训练连续性和覆盖，不使用开发结果或开发漏检长度选段长。短于8帧的 run 只保留原 C 监督。段之间重叠曝光明确保留，FRAME 与 GAP 使用完全相同的元素及重复次数；这些曝光不是独立样本数。

每帧 r=sigmoid(q+)×sigmoid(-q-)。FRAME 使用每段内各帧 -log(r) 的均值；GAP 直接调用参考实现的对数空间首次成功递推，计算 -log[1-prod(1-r)]。各窗先对段取均值，再固定除以8；空窗为0，不转换成全对象均值。CONT 读取相同数据和缓存用于诊断，新增项权重为0。

## 训练侧校准及核验

只使用上一轮已固定的8个训练 indices[5,6,18,25,30,32,51,7]，从原 C2048 实测，不作预热或参数更新。记录原三项损失、特征余弦间隔、实际目标/背景 logit 和 sigmoid 分数间隔，以及新项到 q+/q-、TPro、conv_out1、conv_out2 的梯度。记录与原检测/保持/对比梯度的夹角，以便解释冲突。

FRAME/GAP 共用同一新增系数：0.25×median(||grad L_C||) / max(median(||grad L_frame||), median(||grad L_gap||))。这使二者中较大的训练中位梯度为原 C 的25%；各自实测比例一并报告。原 C 三个系数不重新校准。不能按开发恢复或背景预算调这个数。

训练前验证原参考 CPU 测试、本地 ROI/窗口归约/空段/断点和实际检测头梯度路径；训练末在同8批复测分数间隔。三组的模型初态、Adam 初态、256步曝光、冻结前端和 BN 缓冲必须一致。所有来源、缓存、系数在正式更新前记录 SHA256。

## 冻结评价与解释

推理仅原 detector→sigmoid→原 O/S 五窗 max→0.5→原组件匹配。两个原开发片段使用完整画面，确认片段保持隔离。比较 release、C_init、CONT、FRAME、GAP；严格集合5200、固定低响应4342、极低响应4170、双侧保护646、非严格对象、全部背景和130轨迹的分母不变。

报告相对 release、C_init、CONT、FRAME 的匹配恢复/丢失、低/极低恢复与身份覆盖、双侧保护、新背景组件及框外前景面积、最长连续漏检。额外报告同轨迹三个连续原帧上的010孤立检出，端点或缺标/时间断点不当作010。M/U仍为现有诊断量，U<=4015只适用于当前完整评价范围；S通过共同预算不等于S背景成本未超过发布模型3967。

新增评分不是校准检测概率，框内均值不是组件匹配，采样背景不代表全部背景。soft-OR允许单个强帧降低整段损失，必须结合总体恢复、丢失和背景解释；段内排列不变，不能把段内洗牌当作分组消融。

256步用于判断修订方向，不是收敛或论文结论。若梯度连接失败则修复；若实际读出改善但代价突出，则给出针对该代价的下一项单因素修订。若逐帧对照解释收益，削弱连续段必要性；只有实际恢复和取舍表现支持连续段额外价值时，才进入从发布权重的同预算比较、跨轨迹/跨段归属打乱和成对重复。本轮不因单一预算未过而自动换网络，也不从最长漏检一项宣称成功。
