# 五帧 RGB 视频超分的首次模型配对试训

显式局部采样几何头 C 相对同容量、同输入的学习头 B，独立评估平均提升 **0.0051 dB**。三次配对有一次下降；按序列先对三个种子平均，八段中六段上升。这轮训练未给出足够稳定的收益来支持把该几何形式作为方法主贡献。

## 模型与训练

A 为冻结的 DUF-16L ×2 官方预训练权重。B 和 C 均使用同一个 DUF 初步重建、五帧真实 RGB 观测、双向光流、可靠度和相同的投影残差。两个头各有 52,456 个可训练参数，分别学习观测修正、图像先验修正和 4×4 自由门控修正。B 的基础门固定为 0.5I，C 的基础门由局部多相采样矩阵决定，参数化的其余部分相同。每个 2×2 单元的四相修正和为零，无法修复初始结果中的单元均值错误。[模型实现](../model.py) · [局部几何](../geometry.py) · [观测残差](../transport.py)

使用 12 段 REDS 视频的 96 个 RGB 图块训练，在另外 8 段视频的 32 个图块上评价。每种子两版参数初值相同，初始预测均逐元素等于冻结 A。两版使用相同的 240 个批次、Adam 学习率 0.001 和中心 128×128 的 RGB Charbonnier 损失。全部训练完成后读取评估图块。训练日志、每步损失、批次索引和最后的六套校正头参数均已存档。[预先冻结的试训协议](../PAIRED_PROTOCOL.md) · [运行与输入代码哈希](receipt_001.json) · [训练和评估驱动](../paired.py)

## 判断边界

这次比较排除了校正头参数量、输入帧、训练初态、数据次序和优化预算的差异。所有模型使用同一套固定训练设置。样本只有八个独立评估序列、每段一个中心时刻，而且为自定义 ×2 高斯退化；试验采用轻量级校正头、固定粗光流和实值周期 2×2 几何近似。不同网络实现或更多训练数据是否会改变结论仍然未知。当前可保留此实现为基线；这个差值不能支撑领先标准 REDS 或证明一种新的超分机制。
