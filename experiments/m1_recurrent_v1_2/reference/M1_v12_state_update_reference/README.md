# M1-v1.2：内容条件化的有界状态更新

状态：独立参考实现和实验提案；不是已经有效的方法，不是本地M1工程补丁。保持DeepPro-Plus、研究目标和原评价，继续只修M1，不增加M2。

## 1. 最新证据如何用于设计

依据用户本轮汇报：v1.1将更新改为`M=A+TSFM(A,X)`，低响应对象上的状态相对差异增大，但目标/背景logits主要一起下降，无新增恢复，S多丢1个保护对象，其最长漏检从14增至17。此处没有读取用户本地新日志，数值不是本包独立复算结果。

由此可以说：仅增强状态差异没有提供所需检测收益，不能继续把状态差异的百分比作为优化目标。不能据此证明全部记忆无用、代码错误，或已确定唯一根因。

本次候选假设：旧状态A和新融合候选R的相对作用应随当前空间内容改变，而不是让旧状态无条件相加。内容选择是否有用，需要与不具空间选择能力的同容量控制比较。

## 2. 唯一改动

现有流程：

    X = 原M1当前特征投影
    A = 原PDA(上一状态, X)
    R = 原TSFM(A, X)

原v1.0：M=R。
已失败v1.1：M=A+R。
本轮：M=(1-g)*R+g*A。

PDA、TSFM、输入投影、TPro旁路接入、原预测头不改。仍使用本地原首帧初始化M0=X0。每个40帧窗口重新开始，不读取窗口外状态；不新增双向遍历或更多参考帧。baseline及M1原输入包含时序运算，不将整个系统称为严格因果单帧系统。

g的含义：历史保留系数，不是目标概率，不是不确定性标定。g接近1更偏向保留对齐历史，接近0更偏向TSFM候选。不能预设目标处必须大、背景处必须小。

## 3. 预测器与来源

参考MatAnyone的“依据内容在旧值/新值间插值”，不复制其mask、对象memory和变化监督。

输入：[A, X, R-A]。
预测器：1x1卷积→ReLU→3x3卷积→ReLU→3x3单通道logit→sigmoid。

独立参考默认C=16、hidden=16，共2017个参数。无新增BN和运行统计。与官方UncertPred通道数、输入和监督均不同；来源差异详见SOURCE_MAP.md。

## 4. 两个模式，一个实现

- `scope='frame'`：先计算概率图，再取每帧空间均值广播，整帧同一保留系数。
- `scope='pixel'`：逐位置使用概率图。
- `scope='original'`：返回R，供回归检查及原更新参照。

frame/pixel参数相同，输入相同，初始权重相同，均实际运行同一预测器。frame不是无历史控制，而是无位置特异选择的控制。

输出层零初始化：两组都从g=0.5起步。这不等于原M=R，也不等于v1.1的M=A+R。若从训练后的M1继续，不能要求初始输出与旧M1完全一致；应要求frame/pixel同起点输出一致。不要为追求表面等价而重新置零旧输出投影。

## 5. 数学范围与风险

对每个元素，g∈[0,1]时，新状态在A与R之间。避免无条件把两者叠加，并不意味着目标与背景已经被区分。

这项单步性质不保证：整个递归稳定、每帧状态范数不增长、概率不增、U下降、原成功保持。PDA、TSFM、后续BN/ReLU和检测头都可能改变这些量。

A和R都没有目标信息时，门控不能凭空创造信息。背景也可被稳定保留。若门控始终为常数，则不能主张位置特异选择有用。

输入无需测试框、首帧mask、轨迹或0.5筛选，避免低响应对象被排除。弱监督本身仍可能不足；本轮不偷偷叠加新监督。

## 6. 最小接入

    aligned = self.deform_align(state, current)
    candidate = self.spatio_temporal_fusion(aligned, current)
    state, retention = self.state_update(
        aligned, candidate, current, scope=self.update_scope
    )

原frame0、状态隔离、时间梯度/截断、输出拼接与预测代码原样保留。不要把此段放到最终概率图后，不在残差外再套另一个新门控。

state_update.py不包含真实PDA、DCN、TSFM和本地训练器；本地接入不能用strict=False忽略已有权重差异。

## 7. 正式训练前必要检查

复用历史的坐标、数据、评分、冻结与梯度核验，只补新更新需要的测试：

1. original模式返回R。
2. frame/pixel共享初始化时输出一致，不宣称与旧M1一致。
3. 强制g=0返回R、g=1返回A；A=R时不因门控而变化。
4. 更新为非零后，gate前层能得到梯度。输出层零初始化时第一步前层梯度为零属于预期。
5. 原参数/BN冻结与既有M1可训练范围保持；被冻结的下游仍保留输入梯度。
6. gate单元空间感受野半径2，tile需halo；PDA另有既有边界。frame模式必须取全帧均值，不能按tile均值替代。
7. 训练/推理和时间分块都传递同一状态，不在内部块边界重置。

若某个测试确证错误，修复并记录，再继续。不能仅因为检测未涨点就假定仍有bug。

## 8. 本轮实验，不扩大网络

起点：M1-v1.0 History的同一个2048步检查点，不用v1.1终点。不让两组从不同训练支路开始。

两组新训练：
- Gate-Frame：帧级均匀保留。
- Gate-Pixel：位置自适应保留。

相同PDA/TSFM/投影参数、相同门控初值、seed46、同样后续128步曝光、损失、原参数可训练清单、BN规则。旧参数的优化器历史一致加载；新增gate状态两边相同。

原History续训128步的既有结果，仅在模型、优化器、RNG、采样、AMP和检查点规则可精确复用时复用。否则先登记差异，不能冒称严格配对；需要补原组时只补同预算控制，不增加其他机制。

训练前后记录目标与固定困难背景的实际logits、gate分布、gate/状态梯度与实际更新量。门控幅度或历史差异不作为成功指标。

主结果固定128步终点；日志支持学习尚在改善时可另行预登记延续，不因未过预算自动判定永久无效，也不事后挑检查点替换旧结果。

## 9. 机制检验与完整评价

主比较：Pixel vs Frame，排除“仅统一减小状态幅度”的解释；共同原History用于观察变更整体是否有益。

终点同权重：History vs current_only，沿用已实现定义，不清空整个TPro时间信息，不用另一个Current权重冒充。若恢复两者相同，不能声称恢复来自新增历史。

可记录同一当前输入下gate空间均值替换的输出作为辅助。相同系数均值不等于相同特征范数；递归演化还会改变后续输入，因此不得将其称为整段严格等能量干预。随机错位gate不能替代成对训练控制。

评价保留：原O/S、0.5、实际组件峰值点匹配、U、框外前景、组件面积、4342低响应/4170极低响应、646保护/其他目标、完整轨迹连续漏检。全窗低响应不是全轨迹未发现，阈值分层也不是物理信噪比。U<=4015仅适用于既有320帧范围；发布S自身U3967，预算通过不代表各成本无增。

特别追踪上一轮受损保护对象：能否从17帧漏检回到对照水平；但不得为它加训练样本或调阈值，不能用它单独决定配置。

## 10. 决策

- Pixel只降低背景/使所有logits共同下降：没证明恢复作用，不以门控图好看扩大训练。
- Frame与Pixel相近：更多支持统一更新比例，不主张位置条件是核心贡献。
- Pixel出现新的低响应恢复、连续漏检改善，且优于Frame：值得在M1内继续定向修订/复测；不马上新增M2。
- Pixel相对Frame改善但与同权重current_only无差别：仅能主张空间读出/容量作用，不主张历史恢复。
- 有训练侧可重复选择性信号但短程尚未过全部标准：可据明确记录延续同一M1；不是必须128步达到最终论文标准。
- 两源不具备可用区分、门控只是常数或退化：先定位这一更新算子，不能自动再加新头、损失和采样策略。

本方案尚未完成新颖性检索。区域自适应插值本身已有工作，这一原型先验证是否适合DeepPro-Plus的真实失败。
