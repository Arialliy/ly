# 对应歧义审计实现：静态独立审查

日期：2026-11-18。审查文件audit.py与PROTOCOL.md。只读检查；未修改代码、未运行数据分析、未读取任何confirmation数据。本报告不是运行结果复核。

**结论：未发现阻止本次观察性运行的致命历史GT泄漏、DP坐标或路径重建错误。存在几项必须在汇总与解释中保持一致的限制。**

## 已核对的成立部分

- TRAIN/DEV明确列举10个允许序列，并在逐序列读取前断言不在FORBIDDEN中。原始数组以mmap_mode='r'打开；图像与标注读取路径不遍历confirmation。
- 当前GT提供anchor、当前尺寸用于峰分离以及样本资格，属于已披露的条件匹配探针。scoremaps只读取图像/描述子、当前anchor和固定patch大小，没有使用历史GT移动搜索区、增强模板或修改响应值。
- boolean GT可达性在历史bbox容差掩码上按相同每轴STEP膨胀传播，最后检查固定终点，避免仅凭中心位移判支持失败。
- transition是每轴有界平方位移惩罚的可分离max卷积；横向argx经过纵向选择后正确合并为二维前驱坐标。forward的指针方向和decode从固定终点回溯一致。
- backward使用对称位移代价，bp指向下一时刻；fs[mid]+bs[mid]−unary[mid]避免中间unary重复计数。前缀回溯和后缀前进拼接可得到经过指定中间状态的完整路径。
- GT受限DP在无GT构造的同一图上屏蔽不兼容状态，仅产生事后上界；其得分没有用于选择无GT top1路径。
- 使用history_hits_tol2<=3定义明显偏离的错误路径，因此至少4/7历史位置在目标容差外；不是仅凭一个像素的小错位记多路径。0.02/0.05/0.1三个阈值同时输出。
- main实际使用range(7,160,8)，是20个窗口、终点159；与当前版本PROTOCOL.md一致。筛选前分母、missing track、边界和cap前后数量被保存。

## 汇总前需处理的口径与边界

1. **主要容差与报告不一致。** 协议规定1px为主要位置容差、2px为敏感性，但summarize主要输出tol2准确率、6/7路径正确率。每条样本已保存tol1计数，应在后处理时同时汇总。GT可达性目前仅使用tol1，因此“tol2结果”实际条件于tol1可达子集，报告需要写明，不解释成完整独立的tol2敏感性实验。

2. **近分正确路径不是必然出现在显式候选中。** competition使用GT受限DP的最佳兼容分数，正确路径可能未被1/3/5切片的max-marginal峰选入candidate_paths。这个量可支持“原无GT图的支持内存在高分GT兼容路径”，不能直接支持“模型top-K候选已经保留了正确路径”。若要声称后者，应另从实际candidate_paths按预先定义的tol1/tol2正确标准统计。逐帧previous_gt_wrong_gap同理使用GT区域内最高响应，而previous_top6_contains_gt才是实际峰候选覆盖，两者不能混用。

3. **数值有效性只部分覆盖历史。** numerically_valid检查当前9×9模板标准差和rich[3]响应方差，没有逐一检查其他6个历史响应图是否近常值。不可说所有历史帧退化均已排除。可在后处理审图时标记，或作为本次限制；若修改检测规则，应保留本次冻结版本及新版本差别。

4. **KLT与DP并非相同搜索支持。** NCC/DP被限制在当前anchor±24以及DP步长6；KLT的金字塔可搜索更广，代码也未按该ROI剪裁KLT路径。把KLT称作额外强度检查是合理的，但“相同候选支持的公平算法比较”不成立。对GT已在DP支持内的子集报告结果可减少覆盖混杂，不能完全消除搜索自由度差异。

5. **聚合权重需明确。** summarize已按clip给结果，也给train/dev/all池化结果；后者是样本加权，不是clip等权或track等权。若报告使用“macro”一词，必须另计算。多个窗口共享同一目标与背景，即便窗口不重叠也不能按独立样本给过窄置信区间。

6. **同对象支持、插值框与背景主导仍需审图。** wrong路径依据框外位置，branch_type只描述所选分支时刻。它不保证整条错误路径始终跟踪另一对象或纯背景。GT受限DP还会从较宽框中选择最有利像素，不能当作真实光学中心轨迹。当前模板17px及KLT可能跟随背景纹理；这是现象解释边界，不是代码错误。

7. **release关联是事后相关性。** annotation_id join没有进入匹配计算，未发现结果泄漏。它只说明既有检测器未匹配事件与代理困难是否共现；不能证明改正对应就能提升检测。应保留实际join命中数和未命中数。

8. **近分代理不等于物理后验。** 匹配分数由人工描述子和固定运动惩罚定义；即便GT兼容路径和错误路径同时近分，也只证明在该评分模型下竞争。需对原始帧核验实例，再看KLT/更强描述是否消除，不能直接称不可辨识。

## 代码复核范围

本次为实现静态审查。root提供的selfcheck覆盖转移暴力对照、回溯分数和NCC坐标，但本分支没有独立重跑，不把静态检查描述成全运行验收。完整结果的解释仍需结合输入哈希、freeze记录、样本清单、筛选分母、实际图像和异常日志。
