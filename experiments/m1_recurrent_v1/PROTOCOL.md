# M1：有限窗口内的检测前递归证据传播

日期：2026-10-14。当前任务是实现并验证 M1。首轮只有 M1-Current 与 M1-History 两组；根据实际恢复、历史依赖和代价判断 M1 的功能。原 DeepPro-Plus 是固定发布参照。持续漏检是已观察的问题，缺少显式状态是否构成原因仍待本轮检验。

## 模块及来源

输入为发布模型 `layer1` 后的 F 和唯一 TPro 后的 H，均为 `[B,32,40,H,W]`。P 为32→16的1×1投影，X=P(F)。M0=X0；t>0时，History 使用 M[t-1]，Current 使用 X[t]，随后两组均执行同一个官方 PDA(previous,X[t])→TSFM(aligned,X[t])。输出为 H[t]+Wout([X[t],M[t]])，Wout 是32→32的1×1线性投影，权重及偏置零初始化。原 conv_out1、conv_out2 保留，模型仍返回8通道头特征与 logits。

PDA、TSFM 的代码来源为 [RFR 官方仓库](https://github.com/XinyiYing/RFR)，固定提交 `fd71ccdf17f056f80e0a5ea8726b87c82c27fb69`，原件和必要编译兼容修改分别保存在 `upstream/`。本地旁路接入、M0直接等于X0、发布模型冻结属于任务适配。作者原首帧会执行TSFM；本轮按用户指定公式跳过首帧PDA/TSFM，两个条件一致。此原型不等于完整RFR复现。

每个 forward 的状态均为局部变量；每个窗口、批次元素、视频独立。时间分块只改变已计算特征的遍历边界，不重新初始化或截断状态梯度。原前端和TPro使用整个合法40帧窗口，整体不声明严格在线因果。没有检测分数启动、跨窗口状态、预测并集或新增读出门控。

官方 DCN 算子保留。官方 PDA 要求空间尺寸可被4整除；首轮128×128训练和512×640推理满足。TSFM频率分支含全局自适应池化，M1的空间分块会改变运算，禁止对M1直接套用旧core128/halo16。首次512×640直接执行在原发布前端触发CUDA非法内存访问，发生于进入M1之前，未把该错误认定为显存不足。登记的推理路径改为：仅冻结前端使用core128/halo16，拼回完整F和H后全空间执行M1，再按单帧执行原1×1预测头。原前端的空间感受野半径为9，TPro不混合空间位置，预测头逐位置运算；仍须通过实际特征/输出一致性与完整帧资源检查才能启动正式实验。原40帧时间访问和M1空间算子均保留。

## 两组共同的训练设置

- 同一发布权重，seed46，同一份M1初始化。原模型70,913参数和全部BN统计冻结；只训练P、PDA、TSFM及Wout，梯度仍经原预测头回传。
- 新Adam，lr=1e-5，weight_decay=1e-4，betas=(0.9,0.999)，eps=1e-8，无scheduler；FP32，无AMP/TF32。
- 精确复用当前F（track_contrast_v2/FRAME）的监督函数、标注和掩码：`det + 5.75443767610971*keep + 0.10885460558865433*C + 0.0023821861727945912*FRAME`；temperature=0.47569116950035095。原det包含正窗SoftIoU及空窗top1%项。保留F已有的keep/C项，不新增ConFIG、GAP、回放采样或负项重加权。
- 原4个检测窗加4个固定辅助窗；已有缓存索引0..255，按原顺序重复8轮，共2048更新步。两组曝光完全相同。本轮使用256×8，不能写作512×4；F原实验的C2048起点和256步预算不是本轮设置。
- 固定2048主终点；中间快照仅作学习过程证据，不根据开发表现选点。单seed筛选不能表述为多seed可重复结论。
- 训练前核查真实DCN、两阶段梯度/实际参数更新、完整F监督路径和冻结状态。以实际步时与峰值显存登记成本；若启用梯度重计算，两组一致并登记，仅改变存储/计算策略。
- 两组均启用逐递归单元的梯度重计算，`use_reentrant=False`。保持PyTorch确定性设置但使用`warn_only=True`：官方TSFM的CUDA自适应池化反向及DCNv2原子累加不保证逐位确定性；保留相同seed、cuDNN确定性选项和禁止TF32，不宣称逐位训练复现。

## 数据访问与评价

仅复用原8个训练来源、2个开发来源。4个确认来源不用于本轮开发。开发序列 DJI_0026_2、DJI_0067_2 各160帧；40帧窗口，O=[0,36,72,108,120]、S=[0,24,60,96,120]。归一化、窗口内输出和窗口间最大值融合沿用原实现，阈值固定0.5，使用原实际连通域匹配器。

保留 strict5200、low4342、extreme4170、protect646；O/S中的恢复按(sequence,frame,annotation_id)去重，同时列出两个安排。对原连续有效标注区间报告恢复帧数、恢复轨迹覆盖、连续漏检长度及孤立010，缺帧/缺标断开；现有材料缺少独立可见性标注，连续标注只是有效区间代理。

发布参照为O M/U=700/4015、S=720/3967。两组均采用共同U≤4015，S另报相对3967的变化。报告保护集合损失、完整未匹配组件面积及标注外预测像素。M/U是诊断点匹配和未匹配组件，不称官方Pd/Fa。

决定依据：History须相对Current形成实际持续失败恢复，并使背景与原成功退化受控。两组近似时按容量/适配解释；未恢复时检查M1状态或接入；背景严重扩张时M1本轮失败。后续工作由本轮剩余错误决定。
