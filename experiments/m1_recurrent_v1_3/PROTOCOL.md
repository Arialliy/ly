# M1-v1.3 源帧证据库：固定开发协议

本轮检验“保留各源帧投影，当前时刻重新关联读取”能否产生原持续漏检的实际恢复。单状态覆盖并未被证明是既往失败根因。只替换 M1 的历史组织，不加入 M2。

## 实现与边界

用户提供的 `M1_v13_evidence_bank_reference.zip` 原样保存在项目根目录，SHA256 为 `cf401479bc7647855b88ddc10c87da8d295d41010636e37955399b05df895dac`；原样解包至本实验 `reference/`，直接调用其 `scan_features`。代码不修改原包、历史实验或官方算子。

沿用原输入投影、原 native PDA、原 TSFM、已训练的输出投影、DeepPro-Plus 前端、唯一 TPro 及预测头。保存检测前 `X_s`，逐源执行 `PDA(X_s,X_t)` 和 `TSFM(A_s,t,X_t)`，固定均值读出。先读旧库后写当前 X，容量 4，按源帧索引 FIFO；首帧读出等于 X0。无分数筛选，无插值门，无新增参数。Bank-Current 每个已占槽均以 X_t 替代历史输入，保留相同调用次数、归约和首帧规则。

一批中的每行是一条固定顺序窗口；每次 adapter forward 创建独立窗口 ID，所有内部时间块继续同一 bank，前向结束全部丢弃。无跨窗口状态，无 detach。原特征域中所有位置写入，标注、ROI、冻结对象清单只参与损失或解释，不输入缓存读写。已有前端和 TPro 已有时间访问，不能将本系统称作严格在线因果模型。

40 帧各调用 150 对 PDA/TSFM，原单状态为 39 对。两新条件参数/算子次数相同，不宣称与旧模型等计算。训练对 PDA、TSFM 分别使用无重入 activation checkpoint；不改算子、随机状态或梯度。完整分辨率推理复用已验证的 frontend core128/halo16 拼接完整 F/H，再全图执行 bank/PDA/TSFM；原 pointwise head 按时间块计算。禁止空间切块 M1 以免改变 TSFM 全图频率池化。

## 训练登记

| 项目 | 固定值 |
|---|---|
| 条件 | BankCurrent / BankHistory |
| 起点 | 原 v1.0 History 第 2048 步；不是 v1.1/v1.2 |
| 起点 SHA256 | eda063496757f368d7442a7fac99a64f7b33ef0414ef99d006716d77a6dcb725 |
| 预算 | seed46；各新增512步，最终2560为唯一主结果 |
| 过程快照 | 2048、2176、2304、2560；不择优 |
| 新曝光 | 既有冻结 F 缓存0…255依次两遍，每项4检测+4辅助窗口 |
| 损失 | 原 F 配方及常数全部保持；原标签和缓存不变 |
| 优化器 | 完整恢复旧53张量 Adam 状态和同一 RNG；lr1e-5、wd1e-4、betas(.9,.999)、eps1e-8 |
| 可训练 | 原 M1 53 张量109350参数；全模型180263参数；新增0 |
| 冻结 | 所有原模型参数及 BN 状态固定，预测链可传递输入梯度 |
| 环境 | 已验证的 PyTorch/CUDA Docker；FP32；无 AMP/TF32；原128训练裁剪、微批2 |

初始化后逐张量身份不变，`strict=True` 载入；输出投影不置零。由于历史策略/输入改变，不要求初始输出等于旧递归模型或两新条件彼此相等。固定 GPU 实现存在已登记的 DCN/adaptive-pool backward 非确定性，不能宣称训练逐位可复现。

训练前完成原包测试、真实 CUDA 集成和全分辨率资源实测。训练代码和参考核心哈希于 `PROTOCOL_FREEZE.json` 冻结。中断仅允许从本条件已有快照继续，并保留原日志；不增加曝光预算。

## 验证与决定

正式输出为 BankCurrentCurrent、BankHistoryHistory、BankHistoryCurrent。同一个 BankHistory 终点采用正常历史、current_only、关闭残差三种前向；共用原 F/H 和 BN，关闭路径复核原冻结预测。既有 release 比较浮点容差2e-5与阈值翻转检查沿用；同运行时直接 bypass 对照要求一致。

同次前向记录来源均值→PDA均值→TSFM实际平均读出→接入残差→预测头→logits 的差异；另记录各源索引、age、逐源标量差异。逐目标 ROI、共同恢复9对象、低响应/极低响应/保护对象和固定困难背景沿用原冻结表。首帧无历史单独解释。保存状态变化不视为检测恢复。

两组训练终点比较和同 BankHistory 权重比较均报告 R_hist/L_hist、O/S 各自及去重结果。保留所有有效标注16297与严格评价5200的区别；低响应4342、极低响应4170、保护646不变。连续漏检主分析沿有效区间，不用子集筛选产生的新断点冒充真实间断。报告逐轨迹覆盖、原零检出轨迹变检出、原成功保持、其他有效 GT、U 和面积。

沿用两开发片段、O/S五窗 max 融合、阈值0.5、原实际组件匹配。共同 U 上限4015；相对发布 S 的 U 增量另报。M/U 是诊断点匹配/未匹配组件，非论文 Pd/Fa。八训练来源不扩充，四确认片段不触碰。

现有8个固定校准训练输入可用于只读过程解释，不新增筛选、不更新权重、不用其分数代替开发实际匹配。若没有历史独有恢复，优先解释逐源读出的作用，不延长训练、不调 FIFO 碰运气、不增加 M2。即便有恢复，也不能凭此证明源帧库优于所有匹配时间范围/计算的递归控制。
