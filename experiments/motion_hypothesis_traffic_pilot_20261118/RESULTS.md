# 基于开源 DeepPro-Plus 的临时原型记录

**研究阶段：设计自有模型架构。** 自有模型的特征输入、运动表示及融合位置尚待确定。此目录记录已试过的候选重评分与接口连通性检查。下表只评价这一临时实现，不代表拟研究模型的性能。后续训练种子固定为 46。

临时比较采用作者的 DeepPro-Plus 实现及 RGB-T 发布权重。 选用这一基线是因为本项目有可核查的作者模型快照、对应40帧权重、未融合逐窗口预测和本地数据。新分支只处理相同40帧内中心附近的17帧。直接对作者模型在同一批位置产生的原始分数进行配对比较，并加入同训练预算的静态残差对照。[作者仓库](https://github.com/TinaLRJ/DeepPro) · [接口和比较说明](RELEASE_CHECK.md)

## 结果

训练仅用五个原训练来源的10个中心帧。每个中心最多保留512个作者模型原始分数图的局部峰，拟合修正分数的头；有179个可用于残差拟合的正候选、3,306个可用负候选。五个民用交通训练来源与两个开发来源分开。源权重发布方所用训练数据的完整历史仍无法单凭本次实验核实。开发集18个中心、678个合格小框（船只片段31个，混合片段647个），候选位置的一对一匹配上限是358/678。帧数、预测窗口、每帧候选及评价规则在各行之间固定。输入缓存在一块128×128的开发图上与本地作者实现重新前向的逐像素最大绝对误差为0。

表中三个数依次为每帧最多0.5、1、5个虚警时，经验曲线上最多检出的逐帧目标数。各列独立扫阈值，因此分源结果不能直接相加得到合并列。两个随机种子共用同一批输入和训练更新预算。静态分支只看原分数及候选中心的图像信息。

| 原分数＋完整帧组与跨度运动残差 | 46 | 6 / 22 / 88 | 2 / 4 / 16 | 3 / 15 / 60 |

在每帧最多1个虚警时，原版检出34个。加完整运动响应的两个种子均检出22个。静态修正头得到38和34个。在每帧最多5个虚警时，原版检出94个，完整运动修正检出88和89个。当前配置未带来稳定增益。结果限于两个已用于开发的片段、少量训练样本、冻结骨干和候选重评分。没有原作者完整测试协议下的论文指标，也没有证据说明端到端特征融合必然有效或必然无效。只保留作者的前512个峰时，分支无法恢复候选集合之外的目标。候选选点用到原版40帧，分支的A/B只在后续原始图像路径测量中分开，不能声称全系统对两组帧统计独立。

## 无预训练的表示原型

用 VT-Tiny-MOT 训练集内含有效道路／水面小目标的五段训练视频拟合候选分类器。训练45个中心，开发18个中心（2个原开发片段，各9帧）。17帧窗口互不重叠。交通小框为监督，评估一对一位置匹配。只改变运动表示和比较头。以下结果是开发集上扫阈值得到的经验检出计数。相邻帧内的同一目标可能在多个中心重复出现。

开发集含678个目标框，其中31个在船只片段，647个在混合交通片段。原始中心图像极值位置最多可覆盖665个，经25像素边界排除后剩594个，经每个分块最多2个位置的预算后剩308个。这里的覆盖是所有预测候选和标注的一对一位置匹配上限，未验证候选运动本身是否跟对实例。所有版本共用位置。框定位结果与作者的像素指标不宜直接比较。

| 线性版本 | 每帧最多0.5 / 1 / 5个虚警时检出的目标框数 |
|---|---|
| A_long_peak | 1 / 1 / 15 |
| A_long_full | 1 / 2 / 27 |
| B_long_full | 1 / 1 / 26 |
| A_multi_full | 0 / 2 / 30 |
| B_multi_full | 0 / 0 / 32 |
| AB_multi_stats | 1 / 1 / 19 |
| AB_multi_full | 0 / 1 / 33 |

| 同原始观测的非线性版本 | 种子46，三个虚警预算下的检出数 | 种子47，三个虚警预算下的检出数 |
|---|---|---|
| group_span_mean | 8 / 12 / 46 | 0 / 0 / 22 |
| group_mean_per_span | 8 / 9 / 41 | 1 / 2 / 26 |
| separate_groups_spans | 9 / 11 / 34 | 0 / 2 / 25 |

同组各跨度取同样帧数，但三个跨度的并集含更多不同时刻。非线性对照使用同一批观测、同样的初始权重和抽样序列，仅改变分组和跨度信息是否保留。完整表示没有稳定优势。该原型是诊断工具；正式检测器应在强开源基线上进行配对比较。两个开发来源不能支持泛化结论。
