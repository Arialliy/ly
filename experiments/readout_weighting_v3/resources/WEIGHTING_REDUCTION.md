# 逐帧负权重的原归约与重复曝光

本轮完全复用 C-v2 的 ROI、local/global 背景、段索引和窗口索引。目标读出为原 bbox 内实际 logit 均值；负读出为 local/global 合法 ROI 均值中较大者。先选出这个既有负读出，再对它加权；不把 local/global 两路当作两个新的归约样本。

N 的重标定组固定为原逐帧项最内层的一个段，即8个连续来源帧的观察曝光。长度、段的重叠及末端对齐、每窗口段均值、固定8窗口均值全部沿用。空窗口为0，不能按非空窗口数重新归一化。

令窗口 w 有 n_w 个有效段，段 s 长度为 l_s（现有缓存均为8），i(s,t) 是该段第 t 个位置引用的原目标观察索引。定义每次曝光的原系数

`alpha_s = 1 / (8 * n_w * l_s)`。

同一观察跨重叠段重复出现，原 F 的有效观察系数为

`c_i = sum_{s,t: i(s,t)=i} alpha_s`。

因此 `L_F = sum_i c_i * [softplus(-q_i+) + softplus(q_i-)]`。一次段内不重复索引；同一索引跨段出现仍必须保留，不能先去重。

D 仅将负项替换为 `stopgrad(p_i^2) * softplus(q_i-)`，其中 `p_i = sigmoid(q_i-)`，gamma固定2。其对负读出的有效梯度为 `c_i * p_i^3`；正读出梯度保持 `c_i * (sigmoid(q_i+) - 1)`。

对 N 的每个原段，计算

`a_s = stopgrad(sum_t p_i(s,t) / sum_t p_i(s,t)^3)`。

段内曝光系数相等，`alpha_s` 在该比值中抵消。归约结构原样保留，N 的负项有效系数为

`p_i^2 * sum_{s,t: i(s,t)=i} alpha_s * a_s`。

对同一个 q_i 在不同段中的重复曝光，a_s 可以不同，梯度须相加。由于所有负读出导数非负，逐段预算相等也意味着重复索引累加后的负读出梯度绝对值总和相等：

`sum_i |dL_N_negative/dq_i-| = sum_s alpha_s * sum_t p_i(s,t) = sum_i c_i * p_i`。

这个等式针对同一快照、同一批读出、同一原归约，并同时计入所有重复曝光。乘共同 lambda 不改变相等关系。它不保证参数梯度范数、Adam 更新量、不同分支演化后的预算或最终背景指标相等。

单有效样本组或组内所有 p_i 相同的组，N 退化为 F。当前合法段长度均为8，仍须检查组内是否同分。全空窗口贡献0，不属于具有选择性分配的有效组。若所有有效组都退化，应跳过 N 的重复短训；只统计不同背景 ROI 数不能证明非退化，因为两个不同 ROI 也可能有同分读出。

校准/检查应报告每个固定训练批的有效段数、长度、逐段概率或 logit 范围、精确/容差同分组数量、N 与 F 的有效观察系数差异，以及累加到原 q_i 后的负梯度 L1。不能只对去重后的观察计算一个全 batch 的重标定常数。极低概率时在 log 空间计算 detached 归一化，避免显式 `0/0`；数值实现由独立损失测试核验。

参考资料边界：用户参考包现位于 `reference/DeepProPlus_C_readout_v3/`。其 `readout_terms` 明确要求 G 是已有归约组，当前段内8帧均值正是这样的最内层组；其 matched-confidence 使用 detached log-sum-exp 计算。`SOURCE_MAP.md` 说明 detached p² 借鉴 DEIM 负分支，matched-confidence 为用户方案自定义适配。本文件不将自定义 N 归为 DEIM 作者公式。
