# 固定 History-2048 检查点的作用诊断检查记录

日期：2026-10-14。范围：检查诊断定义、实现与解释边界；不改动冻结 v1 模型，不预选修订。以下是源码核查后制定的检查要点，尚不是本轮作用诊断结果。

## 固定对象和三模式

三种执行均加载 `experiments/m1_recurrent_v1/training/History/run/snapshot_2048.pth`，保持同一模型张量哈希。原前端、唯一 TPro、原预测头、图像归一化、40帧窗口、O/S安排及融合/匹配器保持一致。每个窗口重置状态，t=0均为M0=X0；History与current_only均执行39次官方PDA→TSFM。

- `history`：previous=M[t−1]。
- `current_only`：previous=X[t]，仍执行同样PDA和TSFM。这里不是另一个独立训练的 v1-Current 检查点。
- `off`：原TPro输出H直接进入原预测头，不接入Wout的任何项，包括其偏置。off应与冻结发布结果一致；否则应先排查执行或评分路径。

该比较回答已训练History模型在推理时如何依赖历史。移除历史会改变该检查点的输入分布，不能用它取代v1的独立成对训练对照，或宣布没有历史的模型训练后必然更差。

## 源码中可精确分解的作用链

实际层序为F `[B,32,T,H,W]` → 1×1 P → X(16通道)；递归cell为官方PDA和TSFM；Wout为32→32的1×1投影。将Wout沿输入通道分为Wx、Wm：

`ΔH_mode = Wx X + Wm M_mode + b`。

同检查点、同F时必须满足：

`H_history − H_current = Wm (M_history − M_current)`。

Wx、X和偏置在这个差分中精确抵消。因此Wx/Wm的权重范数只能是补充记录，实际状态、投影后差分与logit差分才说明作用是否到达检测决策。t=0的History/current_only应相同；off不一定相同。

建议保留紧凑的逐目标/逐窗口统计：

| 阶段 | 最少需要的观察 | 能排除的误读 |
| --- | --- | --- |
| 状态 | X、M_history、M_current的通道RMS；M_history−M_current的RMS及相对状态范数 | 状态是否实际上不同；状态单位缩小不直接等于没有历史信息 |
| 接入 | 各模式ΔH的RMS，相对H范数；Wm(M_history−M_current)及数值恒等校验 | 避免把原始ΔH小直接当作接入过弱；避免将当前投影/偏置收益归给历史 |
| 头部 | 固定位置的实际logit差、probability差、head局部Jacobian与方向投影；ReLU活动通道数 | 区分头部局部不敏感、方向近正交、概率饱和及仅未越过阈值 |
| 检出 | 同一匹配器的G/L、M/U、保护保持、背景面积，以及连续漏检和覆盖 | 有内部变化不等于有实际目标恢复 |

所有比值同时保存分子、分母和epsilon。报告分位数/零值占比和样本数，不能只给一个全图均值或不注明分母的比值。不同通道数用RMS或明确归一化的L2，不直接比较未归一化范数。

## 原预测头的敏感度不能用冻结参数梯度代替

原预测头是1×1 Conv32→8、eval BN、ReLU、1×1 Conv8→1。对每个像素，令eval BN合并后的仿射为A、a，末层权重为v：

`z(u) = vᵀ ReLU(Au+a) + b2`，`J(u)=∂z/∂u=vᵀdiag(Au+a>0)A`。

冻结参数本来就没有参数梯度；这不能证明头部不接收新增特征。推理函数使用no_grad也不构成模型机制。需要在独立诊断小块中将真实H_new分离为requires_grad叶子，保持head的eval状态，计算logit对该叶子的梯度，或用上述等价解析式校验。不能用训练loss梯度或sigmoid概率梯度替代这个Jacobian。

对History/current_only的差，保存实际有限差Δz，并比较J_current·ΔH、J_history·ΔH；若ReLU活动集合改变，单端一阶近似不应被要求等于实际有限差。方向余弦 `|J·ΔH|/(||J|| ||ΔH||+epsilon)` 可辅助区分幅度与方向，但不单独决定修订。若J精确为零，应报告活动掩码与实际有限差，不能自动归因为冻结头。

敏感度位置应由与待比较模式无关的冻结坐标规则确定。例如以off的框内峰位置作固定像素，同时另报各模式框内峰值和实际匹配。模式间分别取argmax会改变采样点，不能把这种差别全部解释为同一特征的作用。

## 空间与目标分层

主分层复用冻结low4342、extreme4170和protect646，逐目标/目标帧聚合；背景使用排除所有有效GT框后的固定局部背景或固定强背景位置。各模式使用同一坐标/掩码。全图统计只能补充，不能让大量背景像素掩盖小目标的行为。

若按新模型的恢复/丢失结果再分组，应明确这是结果条件化的解释性分析，不能把筛选后的平均作用当成全体目标证据。重叠窗口给出逐window诊断，但目标恢复必须按(sequence, frame, annotation_id)去重，O/S分别保留。t=0和t>0分开，避免首帧规则掩盖递归效应。

TSFM具有当前—对齐历史相关性sigmoid、空间注意力、全局池化/DCT频率注意力和末端ReLU。记录门值分布有助于定位，但0.5不等于关闭，多次乘法缩小幅度也不等于信息失效；后续投影可以补偿尺度。真正需要对照的是同位置的状态差、接入差和logit差。TSFM涉及全局空间信息，诊断时不能将M1空间分块后称为同一运算。

## 允许的结果解释

1. 状态差与接入差在数值误差范围内都很小：仅支持该检查点在所测数据上历史依赖弱；未证明所有递归机制无效。
2. 状态差明显、接入差小：结合相对尺度及Wm对实际状态差的投影判断，不能仅凭Wm范数决定加大接入。
3. 接入差存在、logit差小：结合Jacobian方向、ReLU活动和实际有限差区分原因；不能仅因head冻结就决定解冻。
4. logit/概率改变但匹配与连续失败不改善：说明内部作用尚未转化为所需检测能力。
5. 检出改善伴随背景扩张或保护集合损失：记录取舍；不以未来第二模块抵消本轮失败。

目前不提出具体修订。等固定检查点三模式的真实作用链和检测结果对应后，才选择一处与证据一致的M1修改，并保留其余执行与评价条件。
