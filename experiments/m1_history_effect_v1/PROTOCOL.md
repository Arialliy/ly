# M1 同权重历史作用检查

本轮固定 History step2048 全部权重及 BN 状态，在原两开发视频和原 O/S 窗口上，定位历史差异从状态形成、线性接入到原预测头的作用。检查不训练，不扩大数据，不增加 M2。历史 v1 源码、权重、评价和缓存只读。

三条件共享原前端生成的完整 F/H：正常 History；同 History 权重的 current_only（首帧 M0=X0，之后用 X_t 替代上一状态，保留 PDA/TSFM）；整个 M1 残差含 bias 关闭（H 直接进入原头）。40 帧合法窗口独立重置，无跨窗口隐藏状态。前端仍用经验证的空间128/halo16分块，M1完整512×640执行，原逐点头按时间1帧执行。FP32、无 AMP/TF32、同一固定容器。

沿每一帧记录 PDA 输入、PDA 输出、TSFM 状态、线性残差及接入后 H、原头 Conv/BN/ReLU/logit 的 History−current_only 差异。记录绝对幅度、同层相对幅度和时间位置；相邻时间差异比只是描述性变化，不能解释为真实记忆衰减率。核对 ΔH = W_M ΔM，首帧两条件相等；复核正常 History 与旧预测缓存、关闭 M1 与原发布路径的一致性。权重和 BN 状态在推理前后散列相同。

使用既有 strict5200、low4342、extreme4170、protect646、共同恢复9及全部有效GT清单分析，不将标注或分组输入模型。固定困难背景从发布模型、既有合法全图候选网格中选择，同尺寸并排除所有GT及2px边界；坐标在三条件推理之前冻结。背景不是完整真阴性标注，只作为无已标注目标的固定参照。目标与其背景对应相同窗口、时间和安排，分析 Δz 与分数间隔，并保留逐对象数据；重叠 O/S 不当作独立对象。

最终评分保持原 O/S max 概率融合及0.5阈值，复用原实际匹配、全部GT匹配后 U、未匹配面积与框外像素、冻结对象恢复/丢失、连续漏检和轨迹覆盖计算。M/U 仍是诊断量，不称 Pd/Fa；S共同 U 预算通过不抹除相对发布的背景增加，保护集合丢失单列。

本轮先完成作用表，再据其选定 M1-v1.1 的一处改动。只有明确定位后才登记并执行原 History 继续训练与该单因素修订的配对短实验；两者同起点、相同曝光和优化器处理，不把新增训练算作结构贡献。不提前指定新门控、预测头解冻或扩大网络。

执行精度补记：首窗暴露旧 release 缓存使用 torch2.7/CUDA12.8，而 v1 及本轮固定环境为 torch2.2/CUDA12.3。同当前环境的未改原发布 tiled_logits 与三模式中的 Off logits 在两视频首个完整窗口均逐位相同；它们对旧 release 缓存产生相同的约5.1e-6/9.5e-6概率差，阈值像素差均为0（analysis/RELEASE_OFF_PARITY.json）。因此正常 History 与同环境旧 v1 缓存要求逐位相同；Off 与跨环境发布缓存登记绝对概率容差2e-5，仍严格要求0.5像素判断和实际匹配/组件面积一致。原失败日志及初始登记保留于 runtime/reconciliation，不将跨环境浮点尾差归因为 M1 未关闭。
