# 可见光教师能为红外行人提供多少候选框

选用已有暴露片段中全部有行人标注的四个训练片段和一个开发片段。每段在前160帧取第9、29、49、69、89、109、129、149帧，合计40张可见光图片。红外框只提供各帧已标行人总数 G。模型仅接收配对的可见光图，使用未经修改的 torchvision Faster R-CNN ResNet50 FPN V2 COCO 权重。阈值0.5为主，0.2为敏感性。保留得分不低于0.2的框供复核。默认全图推理与四个带重叠的图块推理分开评估。图块横纵各占原图60%，在四角取块，坐标移回原图后跨块执行IoU 0.5 NMS。

每帧至少存在 max(G−D,0) 个没有独占教师框的红外标注实例，其中 D 是该帧可见光教师输出的行人框数量。上限覆盖率为 sum min(G,D) / sum G，允许任意跨模态位置配对，以免误将配准偏差当成漏框。多余的错框也会抬高这个上限。指标只衡量给定教师、阈值、图块策略下能提供多少个框，不估计真实召回、物理可见性或整条轨迹未命中率。

若整图候选稀少而分块能大幅恢复候选数，首先考虑输入尺度的影响。若两个阈值、两种输入在多个片段都有明显候选数缺口，进入独立身份核验。若候选数充足，数量试验给不出额外结论，不能宣称教师已经发现了所有行人。使用一个空闲授权GPU，预算小于0.1 GPU小时，不训练。
