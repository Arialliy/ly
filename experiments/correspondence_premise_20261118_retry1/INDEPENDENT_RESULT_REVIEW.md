# 对应歧义前提：独立结果审查

审查日期：2026-11-18。审查对象：本目录冻结的 `audit.py`、`PROTOCOL.md`、`SAMPLES.jsonl` 和 `RESULTS.json`。只读审查和独立重算；未重跑调参、未修改实验、未读取 confirmation 图像/标注。本审查没有人工复核原始图像，因此不独立背书某个视觉实例确实属于物理歧义。

## 决定

**当前证据不足以把“弱目标跨帧对应歧义，需要多路径证据积累”立为研究主线；建议搁置现有多路径方案，不进入模型开发与大规模训练。** 不建议把题目进一步缩窄到唯一困难片段来保留原方案。

本次结果证明的是：在已测试的图像、GT 当前锚点和特定 NCC/位移惩罚模型下，能够生成少量分数相近且标签解释不同的历史路径。它没有证明这是现有训练数据中普遍而重要的失败来源，也没有证明常规单解无法处理，更没有证明保留多路径能改善盲检测。不能把这个结论改写成“所有真实数据都不存在歧义”：此实验不足以证明不存在；它足以说明目前的立题依据不充分。

## 完整性与独立复核

- 结果状态为 COMPLETE，772 个样本，`sample_id` 和 `(sequence, frame, track_id)` 均唯一。序列列表严格落在 8 个 train 和 2 个 dev 白名单中。
- 200 个窗口共 4,134 个当前标注，其中 3,510 个符合当前小框条件；332 个缺历史轨迹，328 个靠近边界，2,850 个符合抽样资格，限额抽样得到 772 个。筛选分母相加一致。
- 772 个模板/响应均数值有效。3 个样本不满足 GT 路径图支持，剩余 769 个进入主分母：train 567，dev 202。其中 1 个连 ROI 支持都不满足，另 2 个 ROI 相交但无法形成合规完整路径。
- 用独立 Python 标准库计算重新核验：所有最佳路径、独立匹配及候选路径的 tol1/tol2 命中数；候选末端锚点、每轴 6px 步长、锚点 ±24px ROI；候选分数差；显式候选竞争定义；RESULTS 的分组样本数、有效分母、竞争计数、显式计数和 tol1 DP/KLT 成功率。均无不一致。
- 这些检查核验保存输出的一致性，不能替代原始图像人工审查或对匹配分数模型合理性的检验。

## 竞争信号高度集中于一个片段

“竞争”按冻结阈值 0.05 定义：同一图中存在高分 GT 兼容路径，同时存在至少 4/7 历史位置落在 tol2 框外的高分候选。GT 兼容路径由事后 GT 约束 DP 得到，未必出现在实际候选中。“显式竞争”另外要求实际候选中存在 7/7 历史位置满足 tol1、且分数差不超过 0.05 的路径。

| 分组 | 有效样本 | 竞争 | 显式竞争 | 阳性 track / 全部 track |
|---|---:|---:|---:|---:|
| 全部 | 769 | 25 / 769，3.25% | 22 / 769，2.86% | 23 / 163 |
| train | 567 | 2 / 567，0.35% | 2 / 567，0.35% | 2 / 94 |
| dev | 202 | 23 / 202，11.39% | 20 / 202，9.90% | 21 / 69 |
| DJI_0057_1 | 40 | 1 / 40 | 1 / 40 | 1 / 2 |
| DJI_0115_2 | 49 | 1 / 49 | 1 / 49 | 1 / 4 |
| DJI_0067_2 | 160 | 23 / 160，14.38% | 20 / 160，12.50% | 21 / 66 |
| 另外 7 个片段 | 520 | 0 / 520 | 0 / 520 | 0 / 91 |

25 个阳性中，23 个来自同一 dev 片段；只有 2 条 track 出现两个阳性窗口，其余阳性 track 各出现一次。阳性涉及多个 track 不能替代多个独立场景的复现。

| 汇总方式 | 全部竞争 | train 竞争 | dev 竞争 | 全部显式竞争 |
|---|---:|---:|---:|---:|
| 样本加权 | 3.25% | 0.35% | 11.39% | 2.86% |
| 每片段内取率、再等权平均 | 1.89% | 0.57% | 7.19% | 1.70% |
| 每 `(sequence, track_id)` 内取率、再等权平均 | 6.39% | 0.41% | 14.54% | 5.88% |

track macro 给仅被抽中少量窗口的 track 较高权重，不能解释为轨迹总体发生率，更不能视作跨场景置信度。未对样本按独立帧计算置信区间。

阈值 0.02、0.05、0.1 分别得到 7、25、65 个竞争样本；train 为 1、2、4，dev 为 6、23、61。发生率依赖分数阈值，且放宽阈值主要增加同一个 dev 片段中的阳性。此分数差没有校准成物理不可辨识性或后验概率。

## 单解比较与关键反例

路径成功按至少 6/7 个历史位置落入对应容差框判定。

| 分组 | DP 成功，tol1 | KLT 成功，tol1 | DP 成功，tol2 | KLT 成功，tol2 |
|---|---:|---:|---:|---:|
| 全部有效样本 | 678 / 769 | 666 / 769 | 684 / 769 | 681 / 769 |
| train | 558 / 567 | 560 / 567 | 561 / 567 | 563 / 567 |
| dev | 120 / 202 | 106 / 202 | 123 / 202 | 118 / 202 |
| DJI_0067_2 | 78 / 160 | 65 / 160 | 81 / 160 | 77 / 160 |

总体 tol1 成功率的片段 macro：DP 93.21%，KLT 92.18%；track macro：DP 79.23%，KLT 75.33%。KLT 使用不同搜索支持和特征，因此这只是不同匹配器的诊断比较，不能当成同预算的算法优劣实验。

25 个竞争阳性中，DP 和 KLT 各有 18 个 tol1 失败，二者共同失败 13 个；tol2 各失败 17 个，共同失败 12 个。把 raw9、rich17、DP、KLT 四者都要求失败，tol1 剩 12 个、tol2 剩 11 个，**全部来自 DJI_0067_2**。再要求“实际候选中保留正确近分路径”，剩 11 个和 10 个。

两个 train 阳性不支持“必须保留多路径”：

- **sample 340，DJI_0057_1，frame 87**：raw9 和 rich17 逐历史帧匹配都为 **7/7**，加入位移惩罚的 DP 变成 **2/7**，KLT 也是 **2/7**。DP 偏好近乎静止的错误路径，正确移动路径仍在候选中，GT 分数差为 0.0145。这与固定运动惩罚产生偏置一致；至少不能用该样本声称图像自身要求多路径，或常规单解均失效。没有另行调参，不把偏置解释当作已经证明的唯一原因。
- **sample 386，DJI_0115_2，frame 23**：DP 和 KLT 均为 **7/7**，错误候选分数差约 0.049993，几乎正好落在 0.05 阈值内。存在一个近分错误候选，并不表示当前单解处理失败。

全体 91 个 tol1 DP 失败中，只有 18 个属于竞争阳性，约 19.8%；其余 73 个不是该代理所识别的近分正确/错误路径竞争。因此不能把本次多数匹配失败概括为多路径歧义。反过来，也不能因代理没有标记，就证明这些失败绝无任何形式的歧义。

## GT 兼容路径与实际候选必须分开

25 个竞争样本中：23 个的实际候选包含某条 7/7 tol1 正确路径，但只有 22 个满足该正确路径也在 0.05 近分范围内。未达到显式条件的是 sample 649、666、699。

- sample 649：GT 约束图有近分全正确路径，但所存最佳候选仅 6/7 tol1 正确。
- sample 666：实际候选有 7/7 正确路径，但分数差约 0.0549，超出 0.05。
- sample 699：没有实际 7/7 tol1 正确候选，已保存的 6/7 候选也超出 0.05。

因此只能把 22 例称为本候选生成器显式保留正确/错误近分解释的样本，不能把 25 全部称作 top-K 可恢复成功，更不能把 GT 约束路径当作无 GT 推理结果。

## 低对比与检测关联

| 当前框低对比代理分层 | 竞争 / 有效样本 |
|---|---:|
| 全部 absSCR < 1.5 | 25 / 445，5.62% |
| 全部 absSCR ≥ 1.5 | 0 / 324 |
| train absSCR < 1.5 | 2 / 261，0.77% |
| dev absSCR < 1.5 | 23 / 184，12.50% |
| DJI_0067_2 absSCR < 1.5 | 23 / 146，15.75% |

所有竞争阳性均低对比，但 train 也有 261 个低对比样本却仅 2 个阳性。现有证据不能把“低对比”直接等同于“对应歧义”；片段因素仍然很强。这里的 absSCR 是当前框/外环统计代理，不是物理 SNR，也不是整个历史窗口的可见性标签。

两个 dev 的 203 个抽样标注均成功关联到既有检测缓存；下表仍仅使用 202 个图支持有效样本。`not_matched` 是该缓存评价规则下的未匹配事件。

| 分层 | 竞争组未匹配 | 非竞争组未匹配 |
|---|---:|---:|
| dev 池化 | 22 / 23，95.65% | 131 / 179，73.18% |
| DJI_0067_2 | 22 / 23，95.65% | 121 / 137，88.32% |
| DJI_0026_2 | 无竞争样本 | 10 / 42，23.81% |
| DJI_0067_2 且 absSCR < 1.5 | 22 / 23，95.65% | 108 / 123，87.80% |
| DJI_0067_2 中同时有竞争/非竞争样本的 17 条 track | 18 / 19，94.74% | 35 / 39，89.74% |

池化差异明显受到两个片段检测难度差异影响。在同片段、同 track 支持的描述性比较中，差异小得多；竞争组未匹配率也只有 1 个匹配样本决定其变动。上述 track 内子集的等权 track 未匹配率分别是 94.12% 和 87.25%，同样不能作独立样本因果检验。

尤其不能据此宣称“对应歧义导致漏检”或“积分多条路径即可改善检测”：当前锚点来自 GT，检测器未接受任何路径处理干预，而且困难片段在非竞争组也有很高的未匹配率。

## 允许与不允许的结论

允许的结果陈述：**此条件匹配探针在既定数据子集和评分模型上发现了少量正确/错误近分路径候选，集中于一个 dev 片段；其训练子集阳性均可由至少一种已测常规单解处理。** 若图像审查确认，可以补充“观察到某些可复现的模型相关混淆实例”，仍须保留当前锚点和评分模型条件。

不支持的陈述包括：数据集普遍存在不可消除的对应歧义；多路径是弱目标视频检测的主要缺口；一阶/二阶路径矩优于单路径；候选路径方差等同不确定性；以及多路径方法可以改善盲检测。这个审查也不检验方法的文献新颖性。

**决策仍为搁置当前方案。** 这里缺少的不是一个更窄的题目名称，而是足以支持核心动机的独立证据。没有在本审查中建议为保留方案而筛选更多困难片段、放宽阈值、调整模型或读取确认集。
