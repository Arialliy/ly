# C 与 D 的事后诊断

本次诊断复用原来保存的民用道路和水面红外视频结果。确认来源的十二帧用于追查此前同数检出的身份及各阶段上限，标记为已用于诊断；如据此修改模型，最终验证另用独立来源。维持原 5×5 局部峰、2 像素同分抑制、扩张一像素的逐帧框和一对一最大匹配。

在两个原开发来源上固定训练完成的 D 权重。比较正常输入、仅将三个时间子集中非中心速度的局部小图置零、仅打乱这些速度格上的短中长跨度对应关系。打乱使用固定种子 46，在每个非中心速度格用同一套预设错排，不在开发集挑排列。保持中心速度及整段小图不变；边缘有效帧数不同的三行不互换。用 C 作负对照，核对正常前向与归档分数图逐像素对齐。报告所有像素的分数差、在同一批正常 D 局部峰上的分数秩相关、各预算检出，以及主工作点匹配标注框的身份。置零和错排都属于人工输入干预。

固定特征的辅助分类实验只使用五个原训练来源与两个原开发来源。每帧用原版模型的前 1,024 个局部峰定义共同开发候选，计算其覆盖上限；此上限只约束诊断分类器。两种读出方式分别比较同候选的 C/D 信息，复用原特征、原分数和速度提议，报告经验虚警曲线及排序。只把重复且来源方向一致的收益记为进一步检验的线索。合成点用于几何与梯度检查，不计入检测性能。
