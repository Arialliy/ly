# 可见光交通画面的行人候选框数量对照

沿用首轮试验的五段已使用片段 DJI_0043_2、DJI_0057_1、DJI_0115_2、DJI_0217_2、DJI_0067_2。每段固定选第 9、29、49、69、89、109、129、149 帧，共 40 帧。输入为配对 RGB，G 为每帧热红外标注中 pedestrian 的数量。未读取保留片段。此协议在首轮 COCO 筛选之后、本次 VisDrone 推理之前确定。

使用 RISE Foundation 发布的 VisDrone2019 微调 YOLO11s，固定提交 16d8d1709ae6fd7a9920398fbed5612e6208e0f0，文件 weights/best.onnx，预期 SHA-256 为 5abd18e5b630c330e68fe56b2bdc3875b10fbea07fe6912bde3cb9e68b58ca23。发布方的模型卡记载，该模型在 VisDrone 验证集上的整体 mAP50 为 0.377。输入为 640×640 RGB，按模型卡方式等比例缩放到整数尺寸，居中填充值 114，范围 [0,1]，张量顺序 NCHW。输出 [1,14,N] 的前四维为中心点及宽高，后十维为类别分数。[模型卡](https://huggingface.co/RISEF/yolov11s-visdrone/blob/16d8d1709ae6fd7a9920398fbed5612e6208e0f0/README.md)

每个原始预测取全部十类中的最高得分类别。主要计数合并 pedestrian 与 people，辅助结果仅取 pedestrian。按阈值包含端点。对每个类别集合独立计数，各输入视野内部在 IoU 0.5 执行跨类非极大抑制。裁剪模式使用原宽高各 60% 的四角视野，独立推理后把候选映回全图并再做一次相同的跨块抑制；全图模式仅使用一次全图推理。先筛选 ≥0.2，再从经分数排序的贪心抑制结果中取 ≥0.5 及 ≥0.2 两组。该顺序使同一输入视野内阈值 0.5 及 0.2 的输出各自等同于先按该阈值筛选再抑制。

每个片段和总体分别统计总预测数 ΣD、最多能一对一配对的框数 Σmin(G,D)、最少缺额 Σmax(G−D,0) 及数量覆盖上限 Σmin(G,D)/ΣG。即使跨模态位置任意、所有候选都可用，每帧仍最多匹配 min(G,D) 个行人。最终仅保存每帧及片段汇总计数，不保存坐标。比较两种输入方式和两个阈值的缺额，记录该固定模型、样本与设置的结果。

项目镜像中的 OpenCV 4.12 DNN 无法导入该动态 ONNX 图。已在数据推理前用全零合成输入确认，项目镜像内的独立 ONNX Runtime 1.23.2 CPU 能以原始图得到 [1,14,8400]。官方 PyPI cp311 Linux wheel 已按索引 SHA-256 da44b99206e77734c5819aa2142c69e64f3b46edc3bd314f6a45a932defc0b3e 核验，仅解包到本实验的 runtime 子目录。所有结果均来自原始图，推理容器禁网，项目与图像只读，CPU 限额 4 核。
