# 标注辅助选路能否找回冻结检测器的漏检

立项前诊断。使用已查看的 VT-Tiny-MOT 开发片段 DJI_0067_2。训练和确认集均不参与。固定结果目录中的实验代码用于干预现有模型的输入特征，不拟合参数。

## 样本与条件

从先前冻结的 SAMPLES.jsonl 取 dev、主判据竞争成立、显式候选保留标注兼容解释、DP 最佳路径命中历史少于 6/7 的全部样本。以原版漏检的 14 个目标窗口作为主分析，原版检出的 1 个另列为保留检查。每个目标窗口单独施加一次干预，即使同一帧出现多个样本。

利用当前标注中心确定固定 33×33 接收区域（每轴 ±16 像素）。对区域内每个像素 q，在 TPro 前的 32 通道特征图上，从历史位置 q + (路径位置 − 当前锚点) 取值。位置均为原始分辨率整数坐标。比较原位、无标签最高分 DP、显式候选中得分最高且 7/7 命中历史框外扩 1 像素并满足每帧分差 ≤0.05 的路径，以及将该兼容路径每个偏移反向的几何对照。反向对照保持每一步的位移长度，可能偶然与目标相容。记录位置一致、因而干预等价的样本。

历史只替换当前终点之前的七个现有 TPro 输入切片。当前切片及其余时间切片、原始图像、冻结的时空卷积和所有检测权重保持相同。每个覆盖终点的原 40 帧窗口单独前向，仅替换该窗口内存在的历史，按逐像素最大值融合。DeepPro+ 原模型允许使用该窗口中的未来帧，此处检验其原始离线条件。本实验测试历史特征读取位置的影响，未实现新模型的路径概率和一、二阶矩。

## 评价与复核

区域外使用该帧原始发布版本概率图，因为从 TPro 到分类输出的运算均按像素独立。每个条件在整帧运行既有 ≥0.5、8 连通域、峰点入框、一对一匹配。记录指定目标是否被检出、框内峰值、整帧匹配对象增减与未匹配连通域数变化。主比较为标注兼容路径相对原位和 DP 的实际新增检出数，反向对照帮助解释位移的特异性。附峰值的配对变化。按目标窗口计数，多个窗口属于同一视频或轨迹，不能外推为独立抽样检出率。

先核验原位重算与归档发布版本的每窗口接收区域及融合区域概率最大绝对差 ≤0.0002，0.5 阈值掩码、整帧匹配结果与目标命中必须相同。如不一致，优先核查输入、投影、窗口融合及归档；未通过前不解释干预结果。记录权重、输入及先前样本清单校验值。无提前停止、无阈值扫描、无按干预结果重选候选。
