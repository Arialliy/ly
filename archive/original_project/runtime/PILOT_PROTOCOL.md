# 冻结权重的第一轮诊断

## 目的与固定项

先运行官方 DeepPro-Plus，检查数据、权重、归一化、原始分辨率和时间窗口是否正确。只有工程通过且真实小目标数据适合，才测研究问题。没有新方法训练。

- 源码 commit：8fa1a68b94eb22e94ccd0529e6c5ceccdaa7ec28；完整官方 checkout 保持 clean。
- 首个权重：官方 RGB-T DeepPro-Plus epoch21；SHA256 4fd4aa2736d9a33f2bf1459099068d8b4a7e202ff80aecdb4a3277fd13c7abcc。
- 原始灰度输入，RGB-T 固定均值85.0799、标准差47.4845；不改变图像尺寸，不加额外滤波。
- 时间窗口40，默认步长36，尾窗向前补齐40；重叠概率取最大值。模型能使用窗口内未来帧。
- 当前本地推理 seed=46（源码默认值，已显式启用）、FP32、确定性算法、关闭 TF32。不能称为官方训练 seed。
- 第一次整幅前向在当前共享GPU与确定性设置下OOM。已保留日志；不将此失败解释为论文模型普遍无法运行。
- 执行适配：空间128×128核心、halo16，完整40帧不拆分；运行前比较整块与分块，误差门槛rtol=atol=1e-4。适配不是检测算法创新。

## 第一片段的选择与边界

Anti-UAV-RGBT val，字典序首个图像/标注配对完整的序列20190925_101846_1_4，帧0..159。选择只依据文件存在和顺序，没有查看模型预测。完整来源、校验和、逐帧原始框另存first_val_clip/。

它用于跨数据工程检查：框为数十像素，缺少精确像素掩码，也未标注停动事件。其框内概率、框外响应只能作描述，不命名为Pd/Fa，不当作点状目标的失败证据。输出没有给出数据集全部对象的完整标注，不能把每个框外响应都当虚警。

## 进入研究诊断的条件

真实序列应有满足研究尺度的目标、可靠时间顺序、可见性和位置标注。优先使用未用于选阈值的官方开发序列；合成数据只承担原模型工程复现或明确标注的控制实验。重复静态图像不会被包装成真实停止运动案例。

若存在图像坐标的长驻留片段，先检查光度、遮挡、目标尺度及相机运动；固定同一批目标分析，不能把域偏移导致的整体检测失败归因为缺少记忆。

若单帧模型、作者Plus版或简单融合已充分恢复这类目标，应据此缩小或放弃该候选问题。只有具体错误仍存在，才比较有针对性的改动。现阶段不承诺这条路线构成CVPR创新。

## 用户种子要求的落实

早期seed0仅保留为工程历史。当前三个推理任务均为seed46；官方train.py:33定义默认46但原入口没有调用，不能据此确认预训练权重训练时的实际种子。所有后续正式对照遵循所选源码的种子定义，并显式核对其生效路径。
