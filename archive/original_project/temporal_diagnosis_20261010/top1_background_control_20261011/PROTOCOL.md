# 固定 top-1% 背景负监督：单次训练对照

本轮依据用户 2026-10-11 最新工单执行。范围止于一次 seed46、512 更新的 top-1% 训练、既定 O/S 推理和结果判定，不增加前置诊断、参数搜索、种子复测或新模型。本轮不把弱框微调当原作者训练复现。旧 lambda0 和三表目录保持只读。

**唯一优化改动。** 对每个原训练窗口的有效背景像素，沿用原未归约负损失 `softplus(logit)`，取最高损失的 `max(1, ceil(0.01*N))` 个均值，替代全部 N 个的均值。空背景与原实现相同。同损失边界按展开索引破平局；不按二值预测选点、不以 0.5 预过滤。原四窗口外层等权均值不变。原 mask 排除全部有效标注框及 2px 缓冲，非仅小目标；原空间 loss core margin 9 不变。掩码若有错误，不得在这次聚合改动中夹带修复。

**其他训练条件冻结。** 与已完成 lambda0 全背景均值控制相同发布 checkpoint 初始化、原 TRAIN_PLAN、样本顺序和曝光、正 MIL、正负系数各 1、effective extra lambda=0、fresh Adam、学习率 1e-4、weight decay 1e-4、seed46、512 更新、四个 40×128×128 窗口、FP32、BN running buffers 固定、全部可训练参数策略相同。主 checkpoint 为最终第512步，不根据评估选步。不能从失控的 lambda0 最终权重续训。旧采样计划内 extra_lambda=1 是历史元数据，实际优化含义由有效配置与代码明确覆盖。

**记录。** 每步保存全背景均值、top-1% 均值、正项、加权正负项、各窗口 N/k/选中比例、总损失、梯度范数、数据与代码哈希、运行命令/资源/退出状态。新增日志在 no_grad/detach 下计算，不参与优化。两配置目标函数不同，不能用各自总损失下降大小判断哪组更好。所选像素系数约增100倍不代表全网梯度增100倍；位置选择与有效负强度在此改动中共同变化，本轮不分解二者因果。

**评估冻结。** 原预处理/原生坐标/切块/FP32/CPU sigmoid/逐像素 probability max/8连通组件峰/原一对一匹配均复用。只评阈值0.5。O=[0,36,72,108,120]，S=[0,24,60,96,120]，分别全片统一安排，不做逐片事后选择。推理可只计算两安排并集的8个窗口起点，但每个受评系统仍为五窗；同时算O/S的诊断总花费不称为五窗总成本。

六行主比较固定为 发布权重、lambda0全均值、lambda0 top1%，各O/S。5200严格小目标帧全部保留；原冻结low=4342、extreme=4170（子集）不按新响应改组。M为小目标帧实际匹配，U及背景像素等按原完整GT评价范围计算，明确不同分母。不把U称官方Fa。

同时记录相对发布权重同安排的G/L，以及相对原O的G/L（供保持性能比较）；额外记录相对lambda0均值的配对增损，但不要求保住其失控预算下的全部匹配。记录全窗低4342/极低4170恢复、原成功保持、A框外前景像素、未匹配组件面积、总组件和组件大小分布。逐片段与逐轨迹汇总，报告恢复的帧数、轨迹数、片段数、最大轨/前五轨贡献；无恢复时分母写0且比例NA。

**两层结论分别判断。**

1. 训练失控修复：逐O/S报告相对lambda0均值的U绝对/比例变化，同时检查A及未匹配组件面积。U下降但仍>4015只称缓解，不能称预算通过；U下降但其他背景成本增加则报告交换，不能称整体背景改善。U通过但匹配及冻结低组恢复消失，不称有效恢复。
2. 发布权重改善：逐同安排原权重报告M、G/L、低组恢复与背景成本差。U≤4015内M>720可称当前预算下匹配增益，不能称与原S(U=3967)相同背景成本。若U/A/未匹配面积逐项不高于对应发布参照，可另标“所记录背景成本均不增”。保持收益单列：S下相对原O的L低于54，并呈现其M及背景代价；不强行要求零新增丢失，也不把少丢失自动称净增检出。

此前登记的S联合条件 M≥720、L相对原O≤54、U≤4015、A≤38641仍作为一项附属严格检查，不能替代用户本轮要求的“训练修复／检出收益／保持取舍”分开判定。没有预先数值化的“相近”或“显著”不临时赋阈值，也不对单种子、相邻目标帧作独立样本显著性宣称。

**结果后的行动边界。** 若仍超预算，保留失败，检查已有日志/剩余错误，不宣称检测收益、不扫1%比例。若通过预算且有低响应实际恢复并形成更好的检出或保持取舍，记录为值得复测的开发集结果，后续才冻结复测与新来源验证。失败只否定这次固定配方；成功也不证明时序模块根因或通用新颖性。已有OHEM额外正项试验与本轮背景负项试验是不同控制。
