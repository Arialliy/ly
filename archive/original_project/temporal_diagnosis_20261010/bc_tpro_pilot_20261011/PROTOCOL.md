# BC-TPro：完整候选与单路动态控制，固定首轮

立项2026-10-11，执行延续至2026-10-12（UTC+8）。用户最新附件授权实现、初始化等价性测试以及两配置实际结果。CHAL/TEP-SAM 不作开工前置。本文件在训练前固定，不因开发集成绩修改。

## 假设与模型范围

候选：背景条件化差分时序探针 BC-TPro。假设是背景参照参与时间关联抵消可以改善弱目标恢复与原成功保持，并控制背景成本；目前尚未验证机制、新颖性或性能。先前top-1%只证明本地弱框训练背景失控有所缓解，不能证明该假设。

冻结RGB-T发布权重对应 **DeepPro-Plus**，其checkpoint邻接源码只有唯一、全分辨率 `TPro`，32通道、8个固定Linear时间头。附件中的TPro1/2/3来自另一架构，不能原样搬入。只改这个TPro，在原Linear组合后、原norm1（BatchNorm3d）/ReLU前加入残差；原stem、预测头和融合均保留。

对每像素 F∈R^(40×32)，背景分支 Bθ 输入 F.detach 的8方向环形空间采样均值，空间偏移固定40像素，后接逐通道(3,1,1)时间卷积、SiLU、1×1×1通道投影。没有中心跳接、空间反射/循环填充或基于GT的推理掩码；只对实际有效的采样点归一化。正式称谓为“背景监督的上下文参照”：背景身份是学习目标，不是已知推理标签。空间盲区不保证纯背景，其他目标、目标在其他时刻移动到环位置、未知大目标仍可能污染参照，不作因果解释。

支持域选择只看8条训练片段：全部有效框maxside最大23，进入TPro前空间感受半径9。选择40>23+9，避免任意训练框内位置的中心目标通过邻域stem感受野被直接复制；不保证任意更大目标或其他邻近目标不进入参照。采样特征还排除输入块边缘9像素的不完整stem区域。零有效参照处标记并禁用新增修正，不把补零称作真实背景。统计记录见 TRAIN_ANNOTATION_SIZE_STATS.json。

输入明确验证当前40→40；不支持任意Tin/Tout，时间长度不符直接报错，不自动假设两者相等。修正转换为[B,C,Tout,H,W]后才加到原映射结果。

Qφ(Z)=tanh(Wq LayerNorm(Z))，Kφ(Z)=tanh(Wk LayerNorm(Z))，两路共享所有LayerNorm/Q/K参数，rank=4，无dropout。定义 A(Z)=Q(Z)K(Z)^T/(40√4)，E=(F−sg(B))/√40。按Q(K^T E)计算，不创建每像素40×40矩阵，也不称softmax注意力的等价实现。

完整配置：ΔH=[A(F)−A(sg(B))]E。

单路配置：ΔH=A(F)E。

两者均 H_new=H_original+γΔH，γ为可正可负标量、初始0。两个配置具有完全相同的新增参数与初始值，只改变是否减去背景关联项；rank、缩放、参照、辅助监督均相同。Q/K使用非零随机初始化，独立构造种子20261011、fork_rng隔离；不增加null token、光流、跟踪、SAM、解码头或paired项。

## 训练冻结

从相同发布权重重新初始化。完全复用原TRAIN_PLAN：seed46、512次更新、四个40×128²窗口、原顺序、FP32、Adam lr1e-4/weight_decay1e-4、原全网参数更新、原BN运行量固定但affine可更新、最终512步权重作主结果。新增ref使用同一Adam参数组规则与更新次数。

检测项直接调用上一轮已核验的top-1%损失：正MIL、每窗口top ceil(1%背景数)负项、四窗等权、额外配对系数0。其背景掩码仍排除全部有效标注框（含非小目标、ignore/crowd）及2px保护；检测core9不变。

参照项仅用于新增参考分支：原单位|B−sg(F)|的通道/有效位置均值，外层四窗等权，λ_ref=1.0。为避免将目标邻域特征充当背景真值，在原背景掩码上另按stem时间±8、空间±9作保守侵蚀，外边界无效，并要求有有效环采样。F输入与target停止梯度，检测读B停止梯度；两损失的参数梯度严格隔离。空ref背景窗口返回可反传零项并记录，不更改检测样本。

每步记录检测正/负项、原全背景与top1负项、参考L1及相对尺度、有效ref位置数、gamma、修正大小、各组梯度范数、实际top1比例、有限性、BN哈希和峰值显存。不同损失总值不用于宣称模型更好；不增加比例/λ/学习率/阈值搜索。

## 实现通过条件

训练前：发布模型与两配置gamma=0输出一致；两新分支初始tensor一致；共享关联在同输入及任意非零value下相消（不仅测E=0）；参照不直读中心；det-only无ref梯度、ref-only无原主干/QK/gamma梯度；首步gamma可更新，非零gamma时Q/K可得梯度。原状态字典完整加载并记录新增参数数目。

BN必须eval，避免运行统计变化破坏等价或形成空间信息绕路。推理新增有效空间半径至少49，使用halo64；旧halo16仅用于旧模型。保持训练crop128会使部分位置的环上下文不全，采用有效点归一并完整记录，作为首版限制，不静默扩训练裁剪。

训练后必须用非零gamma权重比较直接前向与不同平铺的输出，包括边界；若平铺不能在固定容差内重现，先修复实现，不出检测结论。不得把gamma0时的平铺等价当训练后验证。

## 固定评估与判定

两个已有开发片段、5200对象。O=[0,36,72,108,120]，S=[0,24,60,96,120]，各为五窗40帧，概率逐像素max，阈值0.5，原组件峰/GT/一对一匹配不变。只推理两安排并集8窗用于复用，每种安排仍独立五窗；没有额外窗选优。

主表同时保留发布O/S(700/720匹配、4015/3967未匹配组件)、全网top1 O/S(877/913，8339/8330)，以及single_dynamic、bc_tpro。报告G/L、4342低响应与4170极低子集恢复、框外前景与未匹配组件面积、逐片段/轨迹分布。

窗口依赖另外报告原54个O-only、74个S-only（其中73依赖新窗）、104额外窗口可恢复、286个既有覆盖窗成功/失败混合对象：两安排均成功、仅一侧成功、双侧失败及原成功保持。成员由旧输出冻结；不能把8窗结果声称为11窗全部稳定。只提高低响应恢复而未改善这些可靠性量，只能主张低响应改善。

预算判定：U≤4015且M>720可称现有组件预算内开发收益；若称相对S背景成本不增加，需同时面对U≤3967、框外前景≤38641及组件面积等量。不能只比背景失控的top1训练基线。完整模型不优于单路则不保留背景抵消必要性主张。匹配、保持、不同背景量发生取舍须逐项说明，不事后自定“相近/显著”阈值。

计算报告新增参数、训练时间/显存、实际整段O/S推理耗时、模型前向次数与平铺开销；相同五窗不等于相同计算预算。现有两段是反复使用的开发数据，不能把5200帧当独立样本做显著性结论。

执行止于两配置各一次训练与评估。本轮不启动无语义双路消融或新来源确认；仅在结果值得继续时再按用户矩阵推进。若两配置失败，保存固定配方的失败，不能否定所有背景条件化方法，也不自动换新模块。
