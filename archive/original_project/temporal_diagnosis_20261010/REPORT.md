# DeepPro-Plus：真实序列错误诊断与自然窗口对照

日期：2026-10-10。阶段：官方权重推理复现后的原方法分析。

## 当前结论

**已经找到值得进一步定位的持续低响应案例，但还没有证明一种普遍的时序机制缺陷。** 两段预选运动变化目标持续有强响应；另一段无近邻框重叠的目标出现142帧连续低响应。改变真实40帧窗口起点只能恢复其中少量帧。因此，当前应追踪复杂场景中的持续低响应成因，不能直接将问题命名为“加速失效”“窗口边界失效”或“缺少记忆”。

同时观察到另一类现象：同一个目标在同一帧上的响应会随时间窗口变化。这与上述长期低响应尚无共同原因证据，应分别记录。

## 1. 本轮实际完成

- 按之前冻结的、仅基于标注的候选队列，依次使用前4段真实视频，每段160帧，共640帧；全部84条轨迹、4,973个目标帧标注均纳入诊断。
- 官方RGB-T DeepPro-Plus权重，原生640×512灰度，原始40帧输入，官方归一化与窗口融合；本地显式固定seed46。
- 四张GPU各负责一段。整帧执行均CUDA OOM，失败日志保留；随后用空间core128、halo16执行，完整40帧时序保持不变，四个任务均exit0。
- 保存20个原始时间窗口概率图及4段融合结果；另为每段增加6个预先固定的真实窗口起点，保存24个额外窗口。模型、权重、图像顺序及阈值均未修改。
- 完成背景运动、标注重叠、局部对比度检查，以及独立推理实现审查和阈值0.5的全部640帧数值复算。

**复现范围必须区分：**之前完成的是NUDT-MIRSDT官方20序列/2,000帧checkpoint推理复现；本轮使用另一份官方RGB-T checkpoint分析额外真实开发片段，不是RGB-T官方测试指标复现，也不是从头训练复现。

seed46来自源码声明的默认值，本地已明确启用；官方训练入口未调用该函数，已发布checkpoint的实际训练seed仍未知。

## 2. 先把“没有匹配”与“没有响应”分开

主诊断在阈值0.5下取8连通域的最高响应像素，按确定规则进行最大一对一框内点匹配。框内最大概率只是辅助响应代理，可以受到邻近目标或连通域合并影响。以下均不是论文Pd/Fa/AP。

| 片段 / 预选轨迹 | 点匹配帧数 / 160 | 框内最大概率≥0.5的帧数 | 最长连续框内低响应 | 关键条件 |
|---|---:|---:|---:|---|
| DJI_0028_2 / 3800006 | 154 | 160 | 0 | 与邻居框相交109帧，其中9帧完全同框 |
| DJI_0028_4 / 4400005 | 158 | 160 | 0 | 无GT框相交；存在运动变化 |
| DJI_0032_5 / 4801536 | 0 | 23 | 119 | 与邻居框相交122帧，尺寸和背景改变 |
| DJI_0047_3 / 4621500 | 17 | 17 | 142 | 无GT框相交，低响应段为原始18–159帧 |

首两段所选目标的6次和2次点失配，框内均存在概率为1的饱和平台像素，只是按行优先选出的连通域代表点落在框外。**不能把这些点失配称为目标信号消失。** 第三段也不能写成“160帧完全无响应”。

全部轨迹的点匹配计数为221/1280、354/1280、1037/1748、196/665。它们包含不同类别、尺度和运动状态，不将合并比例当作新基准性能。未关联连通域也不自动等于误报。

## 3. 最值得追踪的案例：DJI_0047_3

预选目标4621500在原帧18–159连续142帧没有点匹配，框内最大概率也都低于0.1。这一现象在0.1、0.5、0.9三个预定阈值下保留。

在失配起点附近：

- 17→18帧，框均为5×9，中心仅纵向移动1像素。
- 框内均值减去邻域背景均值为67.75→68.89，没有同步骤降。
- 框内最大模型概率从0.999830降至0.035859，19帧进一步降至约5.82e-6。
- 固定查看0–39帧原图，未发现能够清楚确认的突发出画、标注跳变或遮挡；这不等于已经建立逐帧可见性真值。

其四个40帧块的背景补偿位移中位为0.614/0.649/0.484/0.459 px/frame。第三块的框均值对比度反号，原图70–100帧的标注位置也更暗、更难分辨，110–150又变亮。**不能用后期对比度反号解释整个18–159区间，也不能仅凭轨迹连续就把所有低响应帧当成已确认可见目标的漏检。**

## 4. 已完成一项最小干预：只改变真实窗口起点

保持同一权重和每一帧原始图像，增加起点12、24、48、60、84、96的真实连续40帧窗口。连同原窗口，共11个起点0,12,…,120。该干预同时改变周围内容和当前帧在窗口内的位置，不能单独归因于时间混合权重、padding或内容。

对上述142帧低响应区间：

| 项目 | 数量 |
|---|---:|
| 拥有至少2个真实窗口的帧 | 130 |
| 实际获得额外窗口的帧 | 118 |
| 0.5阈值下由新增窗口恢复的帧 | 4（53–56帧） |
| 多窗口帧中所有已测窗口仍低响应 | 126 / 130 |
| 仍只有一个窗口的帧 | 12（148–159帧） |

0.1阈值恢复6帧，0.9恢复3帧。**本次有限窗口起点干预不足以解释或消除主要持续低响应。** 任意窗口恢复是GT辅助诊断；新增计算和择优上包络都不是新方法性能。

## 5. 另一类可复查现象：同帧响应依赖窗口

以下保守子集要求GT完整在画面内、无GT框重叠、所有窗口匹配无歧义、至少有2个上下文。尺度按当前帧框最大边≤16像素，计数单位为目标×帧。

| 片段 | 保守≤16像素目标帧 | 点匹配随窗口变化 | 框内最大概率跨越0.5 |
|---|---:|---:|---:|
| DJI_0028_2 | 214 | 5 | 0 |
| DJI_0028_4 | 465 | 15 | 12 |
| DJI_0032_5 | 289 | 55 | 52 |
| DJI_0047_3 | 449 | 54 | 73 |

这支持“部分同帧响应对真实上下文/窗口位置敏感”。它尚不能证明这种变化一定错误、总体性能一定下降，或某个新模块有必要。首段极小目标的5个点变化没有框内响应跨阈值，不能包装成时序抑制。

## 6. 对选题的约束与下一步

**研究对象继续是DeepPro-Plus；当前待解释的具体失败是复杂真实场景中目标响应突然降低并持续较长时间。** 这比“小目标AP不高”更具体，但尚不是已经确定的CVPR创新点。

下一步围绕可明确核查的失配起点与后续重新变亮区间，核对目标可见性、背景运动及对比度；随后在原模型的空间特征、时域差分、时域混合和输出之间记录中间结果，定位差异出现的位置。中间特征变化只用于选择一个可证伪的干预，不能单独当作原因证明。相同失败还需在更多真实轨迹及原RGB-T测试划分核查，再与已有时序方法比较剩余缺口。

未固定改进模块；没有新训练或方法提升。当前证据不支持把普遍加速失效、普遍静止失效、缺少记忆或高频缺失作为结论。

- 原5窗口的融合在四段均由独立脚本逐元素重建一致。
- 0047新增窗口关键结论独立核查通过：`audit/OFFSET_SPOTCHECK.json`。直接从11窗口概率和原框重算，确认53–56恢复；118帧获得新增上下文，其中114帧仍低响应。
