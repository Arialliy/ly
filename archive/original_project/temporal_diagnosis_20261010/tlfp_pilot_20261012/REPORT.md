# S-LFP / T-LFP 固定首轮筛选结果

2026-10-12。主终点：seed46、512步；原DeepPro-Plus 70,913参数及BN完全冻结。完整推理及评分已完成。

**结论：本轮T-LFP未通过持续漏检恢复目标，停止扩展。** S-LFP和T-LFP在5,200个冻结小目标帧上均没有新增匹配或丢失，4,342个全窗低响应对象与其中4,170个极低响应对象恢复均为0；全部130条评价轨迹的最长漏检段不变。T只有小幅背景量下降，且本帧替换几乎保留该效果，未支持新增真实邻帧条件的恢复价值。S的小幅背景变化保留为有限观察，不升级为成功恢复基线。

## 3. 真实邻帧是否提供独立作用

T相对S-LFP、发布权重和T本帧替换的**小目标新增／丢失均为0/0**。在T同一检查点把三个新门控槽全部替换为当前帧描述，O的M、U、框外前景、未匹配组件总面积均相同；S安排只有框外前景与未匹配组件总面积各多1像素，M和U不变。没有可用于证明真实邻帧必要性的新增恢复对象，不能用“0个恢复全部保留”构造恢复率。详见[MECHANISM_SUMMARY.csv](evaluation/MECHANISM_SUMMARY.csv)。

这个推理替换不是重训容量控制，也不证明所有邻帧信息无用；本轮没有达到启动容量控制的条件。

T关闭新增分支后还原发布检测：18份逐窗／融合概率比较的最大绝对差 **7.569789886474609e-06**，低于预先固定1e-4；>=0.5判决差异0，匹配、峰坐标、组件面积和背景数组全部一致。概率并非逐比特相同，原缓存与本次分块浮点计算存在微差；没有据结果修改容差。见[BYPASS_VALIDATION.json](evaluation/BYPASS_VALIDATION.json)。

## 4. 实现与训练证据

新时间扩展37项CPU测试通过，包含与3×7×7 Conv3d的非零前向及梯度等价；实际40帧GPU接入、非零检测损失梯度、冻结状态及时间／空间分块检查通过。这里只支持实现与执行，不等于检测有效。

独立训练审计21,431项通过：两组全部512步输入与标签哈希彼此及历史E0一致；各5个快照的原状态逐张量等于发布权重；Adam只更新新增参数。T两侧时间核确实更新，终点alpha=0.005224805，S为0.005264857。首步sigma损失梯度0但仍受已登记weight decay更新，未混淆两种原因。详见[TRAINING_AUDIT.md](checks/TRAINING_AUDIT.md)。

最后一次训练批次、512次更新之前，S/T施加修正范数占输入范数约0.169%/0.180%。这是单批训练遥测，不是全部开发数据效应，也不能据此把失败确定归因为训练不足或临时延长训练。门控及核变化存在、背景输出变化存在，而冻结小目标的实际恢复没有发生。

四种输出均完成两片全图推理；终点固定裁块direct/tiled检查均通过，0.5判决差异0。评分直接复用原匹配实现；表间校验38,928项通过，来源哈希、冻结分层、逐对象集合和轨迹断段规则均保留。见[TABLE_VALIDATION.json](evaluation/TABLE_VALIDATION.json)。

首次文档跟随预检查曾因criterion导入前缺少networks路径失败，发生在模型执行和正式更新之前。已保留失败日志；修正导入顺序后，由另一代理按同一环境文档实际运行通过，之后才冻结协议及启动正式两组训练。没有失败后补跑或替换正式实验。

## 5. 资源、适用范围及停止决定

GPU3串行执行，其他用户任务未停止；没有使用GPU0或安装新环境。S/T训练分别136.244/140.590秒，训练峰值allocated约3.37GiB。全图推理记录峰值allocated约4.23GiB；T三模式的内存峰值为同进程累计，不能作为三种模式各自的精确资源比较。S/T正式模型条件下，每片五窗的模型计算加CPU拷贝约5.6–5.9秒；写盘、逐窗缓存和额外诊断另计，非重复计时性能基准。详见[runtime/RESOURCE_SUMMARY.csv](runtime/RESOURCE_SUMMARY.csv)。

本结论限定当前固定监督、冻结主干、seed46、512步及两个开发片段，不声称充分收敛、新来源泛化或否定所有频域方法。训练crop局部Haar相位与全图相位、原监督margin9小于新增完整空间依赖18等共同限制已在结果出现前登记于[PROTOCOL.md](PROTOCOL.md)，不撤销本轮负结果，也不作为追加试验理由。

**决策：关闭本轮T-LFP候选，不进入确认、容量控制、新来源或延长训练；不改阈值、解冻主干或追加模块来挽救该版本。** S-LFP仅保留为已测空间控制与有限背景变化记录。真实场景持续漏检的研究目标不变，本轮未建立新的时序机制或模型主线。后续提案需有区别于本轮失败假设的新证据，本任务不自动启动下一结构。
