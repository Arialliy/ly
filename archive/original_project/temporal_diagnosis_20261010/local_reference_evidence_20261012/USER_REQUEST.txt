**下一步建议在 DeepPro‑Plus 上设计一版“局部参照时序证据分支”：借鉴TEP‑SAM先形成可辨别线索的思路，但不搬它的模块，也不重启已经结束的跨帧匹配路线。**

这次只检验一个明确假设：

> **判断一个位置是否值得增强，不能只看它变化了多少，还应看：这种变化相对于附近区域的变化，是否具有区分度。把这两类信息同时提供给检测器，能否比普通时间差分更有选择地恢复漏检？**

这是新的**待验证假设**，不是已确认的失败原因。E2及其原因排查继续保持结题，不补跑、不改写原结果。CLOSEOUT

## 一、借鉴什么，自己设计什么？

TEP‑SAM的重要启发是：单帧目标难以辨别时，先通过全局与局部动态、当前与参考帧的差异形成时序线索，再将线索用于判别。它并不等于“只要帧间匹配更准确，目标就能恢复”。[arXiv](https://arxiv.org/html/2606.27655v1)

**我们借鉴“先形成证据”的思路，自己检验“以局部变化为参照，解释当前变化”这一表示方式。**

举一个说明设计意图的假设例子：

| 当前位置变化 | 附近变化 | 希望模型获得的信息 |
|---|---|---|
| 当前位置变化很大 | 附近也普遍有相似变化 | 大变化不一定是目标证据 |
| 当前位置变化不大 | 附近变化更小、更稳定 | 小变化仍可能有区分价值 |
| 当前位置变化较大 | 附近变化杂乱且幅度很大 | 证据不确定，不应仅凭差分强度增强 |

**不预设第二行一定是目标，也不预设第一行一定是背景。** 这些只是提供给模型的判别信息。

同时必须提前承认：时间差分、多尺度时间上下文和差分引导特征学习已有近期工作，例如AAAI 2026的TDCNet。因此，**“加时间差分”“加归一化”“加残差头”都不能单独作为论文创新。** 本轮需要证明的是：这个局部参照是否提供了普通差分没有的、能够转化为实际恢复的价值。[AAAI Publications](https://ojs.aaai.org/index.php/AAAI/article/view/37385)

## 二、设计什么网络？

### 整体：原检测路径保留，新增证据走独立分支

建议首版采用以下结构：

```text
同一个合法输入窗口
       │
       ├── 原 DeepPro-Plus ──────────────→ 原 logits z₀
       │          │
       │          └── 原预测头前特征 H₀ ─────┐
       │                                    │
       └── 时间差分＋局部参照统计             │
                    ↓                       │
              小型证据编码器 ────────────────┤
                                            ↓
                                    联合读出修正量 Δz
                                            ↓
                                      z = z₀ + Δz
                                            ↓
                                 原 sigmoid、五窗融合、
                                  阈值与组件匹配规则
```

**不修改唯一TPro的内部运算，也不在TPro之前重新混合原特征。**

公开DeepPro‑Plus已经返回预测头前特征及最终logits，可以据此建立明确的读取接口；公开实现的该特征为8通道。本地接入仍以你冻结的源码和实际张量为准。[GitHub](https://raw.githubusercontent.com/TinaLRJ/DeepPro/main/networks/models/DeepPro-Plus.py)

首版暂称为**“局部参照时序证据分支”**。先不取一个听起来已经成立的新网络名称。

### 为什么采用独立分支？

目的是把本轮问题限制为：

> **这种新表示能否为原检测器补充有效信息？**

而不是同时改变原时序表示、原训练轨迹和最终输出方式。

首轮建议**冻结原DeepPro‑Plus参数及BN状态，只训练新增分支和联合读出**。这是一项新的、所有对照共同采用的实验设置，**不是声称冻结必然改善性能，也不是把冻结作为创新点**。

因此，之前全网微调的E0不能充当本轮直接的结构控制，必须使用下面同样冻结设置的新对照。

## 三、证据怎样生成？首版只用一套明确计算

### 1. 从输入序列计算差分，不从已经混合的深层特征猜对应

记经过原有预处理的红外帧为 \(I_t\)。首版固定两个时间间隔，例如：

\[
\delta\in\{1,4\},
\qquad
D_t^\delta(x)=I_t(x)-I_{t-\delta}(x).
\]

保留差分的正负号，不直接取绝对值后当作目标概率。

这些时间间隔是**首版工程规格，不是已经发现的最佳尺度**。所有参考必须位于当前合法窗口内；缺少参考时使用有效性掩码，不能偷偷读取窗口外帧，也不能用复制帧伪装成真实参考。

使用同一套图像预处理，不额外逐帧拉伸亮度，否则可能人为改变要测量的时间变化。

### 2. 给每个差分配一个局部参照

在位置 \(x\) 周围设一个固定环形区域 \(\mathcal R(x)\)，排除中心小区域，计算：

\[
\mu_t^\delta(x)
=
\operatorname{median}_{y\in\mathcal R(x)}
D_t^\delta(y),
\]

\[
s_t^\delta(x)
=
\operatorname{median}_{y\in\mathcal R(x)}
\left|D_t^\delta(y)-\mu_t^\delta(x)\right|.
\]

其中，\(\mu\)描述附近变化的典型水平，\(s\)描述附近变化的离散程度。

然后形成：

\[
E_t^\delta(x)
=
\frac{D_t^\delta(x)-\mu_t^\delta(x)}
{\max(s_t^\delta(x),s_{\min})}.
\]

\(s_{\min}\)用于避免平坦区域的除零或异常放大，其确定规则只使用训练来源，运行前固定。

**这里应叫“局部参照”，不能直接叫“纯背景估计”。** 环形区域可能包含其他目标，也可能跨过背景边缘；中位数并不能保证消除这些影响。

空间支持范围同样在训练前固定，可以依据训练标注中的目标尺寸确定一套规则，不使用开发或测试目标框逐对象调整。推理时仅依赖图像和固定运算。

### 3. 不只保留归一化结果

新分支输入同时保留：

\[
V_t=
\left[
I_t,\;
\{D_t^\delta,\mu_t^\delta,s_t^\delta,E_t^\delta,
m_t^\delta\}_{\delta\in\{1,4\}}
\right],
\]

其中 \(m\)为参考有效性掩码。

**不能只给模型一个 \(E\)，然后假定数值大就是目标。** 保留原差分、参照水平和离散程度，是为了允许模型学习：

- 当前变化是否只是邻域共同变化的一部分；
- 相对差异是否来自极小分母；
- 是否存在足够证据进行修正。

首版可用一个共享的、逐帧小型二维卷积编码器处理这些显式时间通道，不再增加新的注意力、ConvGRU或对应检索。

### 4. 与原表示联合读出，允许正、负修正

\[
Q_t=G_\theta(V_t),
\]

\[
\Delta z_t
=
W_o\,h_\phi\!\left([H_{0,t},Q_t]\right),
\qquad
z_t=z_{0,t}+\Delta z_t.
\]

只将最后输出投影 \(W_o\)零初始化，使初始预测与发布权重一致；其他新增层正常初始化。

**冻结原网络不保证最终检出保持。** 新分支仍可能错误压低目标、扩大背景或改变组件结构。因此修正允许有正有负，但成败必须由实际检测评价决定，不能靠结构宣称“安全增强”。

## 四、这与已失败方案的区别在哪里？

| 已结束的方案 | 本次候选 |
|---|---|
| 在已有深层特征中寻找跨帧对应 | 直接从输入构造显式时间变化及其局部参照 |
| 依赖当前弱特征具备匹配能力 | 不需要目标先被检测，也不需要先匹配到目标 |
| 通过双向概率控制信息注入 | 让检测读出同时看到变化量、参照水平与离散程度 |
| 改变送入TPro的特征 | 保留原TPro路径，在独立分支检验补充信息 |
| BC‑TPro学习背景参照并做关联抵消 | 不预测目标缺席背景，不做两路注意力相减 |

但也应说清楚：**本方案仍属于相对时序差异建模，而不是完全没有先例的新范式。** 区别足以构成一次新的受控实验，不足以自动构成论文新颖性。

此外，它有明确的适用边界：

**静止目标不一定产生差分证据；与邻域共同运动的目标可能被参照削弱；强视差、边缘扫过和密集目标可能使局部统计失真。**

因此，不能承诺恢复全部4,342个低响应目标，更不能把“低响应”直接当作“具有独立运动差异”。结题文件也明确保留了这一证据边界。CLOSEOUT

## 五、首轮实验：三组，共同设置完全一致

这次需要排除两个替代解释：**是不是仅仅重新学习输出就有收益？是不是普通差分已经足够？**

| 配置 | 新分支可使用的信息 | 回答的问题 |
|---|---|---|
| **N0：当前帧补充控制** | 当前图像＋原特征；新增时间证据通道置为规定的空值 | 收益是否只是新增空间读出或输出适配？ |
| **N1：普通差分控制** | 当前图像＋普通时间差分＋有效性掩码 | 时间差分本身是否已经足够？ |
| **N2：局部参照候选** | N1信息＋局部参照、离散程度及相对差分 | 局部参照是否带来独立的选择性恢复？ |

三组使用相同编码器、读出结构、通道接口及初始化规则。输入信息不同是实验因素，不能声称它们“有效容量绝对相同”，但应避免额外给N2更深的网络。

**N0也不能叫完整单帧模型。** 它仍读取原DeepPro‑Plus的时序特征，只是新增分支不获得额外显式时间证据。

### 训练协议

沿用已登记的数据曝光、seed、512步筛选预算和检查点规则。检测损失采用同一套已登记适配配方：有目标窗口与空标签窗口的处理、外层归约、负监督比例均保持一致。

本轮不增加辅助分割损失、蒸馏、伪标签或新的采样策略。尤其不把TEP‑SAM输出当作训练标签，也不按它恢复的407个开发对象重新采样训练数据。

**这不表示已有损失已经理想，而是让N0/N1/N2的差别可以解释。** 三组必须共同面对发布系统，不能只超过一个退化的微调模型。

## 六、正式运行前，做必要测试，不再开启大诊断

实现验收聚焦于这次新运算：

| 测试 | 预期性质 |
|---|---|
| 关闭输出修正 | 与原发布模型数值一致 |
| 所有位置具有相同时间亮度变化 | 相对项 \(D-\mu\)应接近零 |
| 局部变化不变、周围离散程度增大 | 相对差分幅度应下降，而原差分保持不变 |
| 全部差分为零或参考缺失 | 无NaN、无伪造时间证据 |
| 整图与分块 | 环形统计和卷积边界一致，非零修正下输出对齐 |

这些只是验证公式和代码，不是合成目标检测成绩，也不证明真实相机运动已经被消除。

环形统计需要实际计算成本。分块必须保留统计区域和卷积所需外围像素，不能仅因没有新注意力矩阵，就默认开销很低。

## 七、如何判断这次值得继续？

本轮最关键的是 **N2相对N1**，其次才是N2相对发布模型。

### 检测目标仍按原协议判断

阈值0.5、O/S各五窗、\(U\le4015\)、冻结4,342个低响应目标和原成功集合继续保留；这些是当前开发诊断口径，不是官方Pd/Fa。CLOSEOUT

需要同时报告：

**原失败恢复：** 恢复多少冻结低响应目标，涉及多少轨迹，连续漏检段是否缩短。

**原成功保持：** 相对发布O、S的新增丢失，以及646集合的保持情况。

**背景代价：** U、框外前景和未匹配组件面积，不能只挑一个变好的量。

**机制增量：** N2是否比N1、N0提供更好的检测取舍，而不是仅总体分数更高。

不再临时设定“恢复44帧就算成功”等新门槛。采用已经登记的约束，结合恢复规模、保持代价和轨迹分布作候选筛选。

### 提前写好去留规则

| 结果 | 决策 |
|---|---|
| N0已经解释大部分收益 | 主要是读出适配，不能主张新的时序证据有效 |
| N1有效，N2没有独立优势 | 普通差分有价值；停止局部参照的核心主张 |
| N2降低背景，但恢复目标也减少，未形成更好取舍 | 主要是压制作用，当前候选不通过 |
| N2在预算内恢复原失败、保持代价可接受，并优于N0/N1 | 进入成对重复实验和新来源验证 |
| 三组都未达到目标 | 归档本轮，不自动扫描环半径、时间间隔和归一化参数 |

固定512步只是本轮筛选协议，负结果不证明所有这种表示都无效；但足以决定不在当前版本上继续扩张投入。

## 八、这次怎样避免再次“加模块后才猜原因”？

新表示的输入量都能直接保存。训练时同步记录恢复对象和困难背景上的 \(D,\mu,s,E,\Delta z\)，不另训探针。

如果N2出现正向结果，再用**同检查点、局部参照被位置错配**的固定诊断，检查模型是否真正依赖相应位置的参照，而不只是利用更多输入通道。该诊断属于分布干预，只作辅助解释，不能单独完成因果证明。

最终要形成的证据链是：

> **某些原漏检在普通差分下仍难以区分 → 局部参照提供了额外判别信息 → 新分支利用这部分信息恢复目标 → 背景与保持代价受控 → 完整方案优于普通差分和读出控制。**

如果链条中间断了，就接受更简单的解释，不给模块补一个更强的故事。

---

**具体下一步是：实现一个带`current / difference / relative`三种输入模式的证据分支，完成公式与接入测试，再运行N0、N1、N2三组固定对照。**

这次不是复制TEP‑SAM，也不要求TEP‑SAM先通过你的预算。**借鉴的是“先产生可辨别时序线索”的研究思路；我们自己的候选命题是：局部变化参照能否让弱变化更有意义、让强背景变化不被轻易当成目标。** 只有这项命题在实际恢复与合理对照中得到支持，才值得进一步发展为论文方法。
