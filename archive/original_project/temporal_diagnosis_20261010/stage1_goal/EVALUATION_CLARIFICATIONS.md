# 预测前评价细节澄清

记录时间：2026-10-10。四组训练运行中；尚未产生新校准／确认推理结果。本文件补充冻结协议的计数定义，不改变训练和数据选择。

1. 官方发布权重的主参照阈值始终为0.5，不对该参照重新挑阈值。仅四个微调配置使用校准集按冻结规则选择阈值；确认集不重选。
2. 原版稳定窗口集合 S 定义为：严格小目标帧至少覆盖2个已测窗口，且所有覆盖窗均点匹配。最大值融合可能合并组件，所以 S 不必是原官方融合已匹配集合的子集。保护约束的“新增丢失”分母使用 **S∩原官方融合已匹配**，分子为其中候选官方融合未匹配者；另外单独报告 S 内原融合已存在的漏检数。分母为0时不可判定。
3. `boundary` 采样层表示允许接近边界，不等于必然边界暴露。实际1024对中：内部层512对全部双slot在8..31；允许边界层512对中444对至少一端在此区间外、68对仍双端内部。按实际slot分层，不把层名当因果标签。
4. 框监督改变后的响应峰可能漂移。中心误差与峰位移在原／候选共同匹配对象上报告，新增匹配与丢失单列，避免只看共同成功样本。
