# 固定局部分支前置检查：局部证据不能直接当作可靠保护路径

日期：2026-10-10。结论：**未经训练的固定局部投影能恢复部分抑制样本，但会丢失大量有利上下文带来的高响应。因此，当前结果不支持直接把固定局部分支或固定比例衰减作为第一阶段改进方法。** 这不否定训练后的内容选择机制，也不证明局部目标证据没有价值。

本实验不是新方法性能验证，没有训练、全图误报计算或官方maxfusion评估。响应变化统计不能写成新增/丢失检测数量。

## 协议与可复核性

[PROTOCOL.json](PROTOCOL.json) 与 [PROTOCOL.sha256](PROTOCOL.sha256) 在运行前冻结，hash 为 `5d84167148825d51d401eaed44ea6df42697ce4ea9f7148312f3ffd63755adbd`。只检查预先指定 `r∈{0,4}`、`g∈{0,0.5,1}`，未筛选更优半径。

- 全部1,417个原有严格小目标帧，每帧复用已选最低/最高响应真实40帧窗（以下称A/B）；不换样本，不改原图，不增加时间halo。
- 官方RGB-T权重、FP32、eval BN、seed46；原F固定，bbox+16空间halo原尺寸精确重放。
- 对当前输出slot，`q_local=Σ{|s-slot|≤r}w_s F_s/√40+b`，`q_g=q_local+g(q_full-q_local)`，经完全相同原后端得到响应。`g=1` 两个半径共用原投影。
- 局部按**特征时间索引**定义。前端已有±8帧感受野，因此r0也不是单帧模型，r4近邻的原始支持可达±12帧；靠近窗边还受原始padding影响。
- 24/42来自旧shared/exclusive支持诊断，并限于97强翻转组。新的near/far划分与旧shared/exclusive划分不同，不把远帧等同不利上下文。

GPU0全量运行完成、退出码0，运行脚本内计时33.34秒。原图响应最大重放误差3.28e-6；0.1/0.5/0.9阈值均零不一致；q分区重构最大误差4.77e-7；原后端概率重放最大误差9.24e-6。模型权重hash前后相同。逐例结果和源hash见 [full/results.csv](full/results.csv)、[full/metadata.json](full/metadata.json)。[SUMMARY.csv](SUMMARY.csv) / [SUMMARY.json](SUMMARY.json) 保存全部条件及分层，汇总脚本检查了全部行唯一性、原选择一致性和阈值重放；尚未声称由独立执行者完成复核。

## 主要结果

下表“恢复”只表示原A框内最大响应从低于0.1升到指定阈值；“保留”表示原B框内强响应仍达到指定阈值。括号内是不低于0.9的数量，括号外是不低于0.5的数量。

| 原F上的内部条件 | 24个抑制例A恢复 | 42个受益例B保留 | 97例原B响应跌破0.5 | 502稳定高例至少一个端点跌破0.5 |
|---|---:|---:|---:|---:|
| 原完整投影g1 | 0（0） | 42（42） | 0 | 0 |
| r0，g0 | 8（8） | 0（0） | 84 | 162 |
| r0，g0.5 | 4（4） | 3（2） | 72 | 69 |
| r4，g0 | 21（18） | 10（7） | 52 | 29 |
| r4，g0.5 | 15（10） | 16（12） | 34 | 22 |

具体含义：

1. **当前特征一项不足以充当默认保护路径。** r0/g0使42个受益例B全部跌破0.5，还使稳定高组162/502在至少一个已选端点跌破0.5。
2. **r4局部投影确实能保留某些有用信息，但不能作为统一解法。** r4/g0在24个抑制例A恢复21个，同时使42个受益例B丢失32个高响应；该组B保留10个，其中仅7个仍≥0.9。
3. **g0.5没有自动取得所需两端平衡。** r4/g0.5在24个抑制例A恢复15个、该组B损失2个；在另一组42个受益例中B损失26个。全部97强翻转例A恢复17个、B损失34个；原502稳定高例至少一端损失22个。
4. **框内峰值转移会影响恢复数量。** 在原B峰值固定位置读A输出，r4/g0和g0.5的24例恢复分别为15和8（框内最大值分别21和15）。报告不把整框最大值升高直接等同原目标位置响应恢复。

受益例B损失发生在三个原有片段。r4/g0.5在 `DJI_0028_4` 的6个受益例保留0个，在 `DJI_0032_5` 的13个保留7个，在 `DJI_0047_3` 的23个保留9个；不是单一片段现象。片段/轨迹内目标帧相关，数量不能作为独立样本统计显著性。

持续低响应778的定义是所有已测窗均低于0.5，不能描述为全部低于0.1。本次只干预其预选两个端点；103或33不是对所有新窗口的复测结果，更不是新增正确检出。投影消融也可能把背景响应抬高；缺少整图输出和误报约束时，不能用某列净增作为选型胜出依据。

## 对下一步 idea 的约束

目前应拒绝的具体假设是：**“固定近邻投影已经可靠，所以只要把远处上下文统一削弱，就能兼顾抑制恢复和时序收益。”** 两种半径、两种削弱强度均出现明显交换。

仍可检验的模型假设是：在同一原投影之上，根据目标位置与上下文内容学习选择，使用g1作为严格原模型控制；训练与评价要分别检查抑制组和受益组，不能只优化恢复案例。若引入新的保护分支，需要对它进行有效监督并验证其可靠性，不能把本次被截断的预训练投影当作已成立的保护证据。

数据/监督候选也仍成立为待测假设：对同一目标跨真实窗的较弱响应提供有针对性的真实标注监督，保留完整上下文运算。它能否较模型修改更有效，必须经过同初始化、同更新预算、相同BN模式和误报约束的真实训练对照；本内部探针不提供训练优劣结论。

本轮前置检查为模型候选提供了可证伪条件与反例，**不满足第一阶段完整目标的检测验证要求**。
