# 本阶段具体idea及其结果边界

## 可检验的idea

**同一目标帧的困难上下文监督：在不改变推理架构和时间访问预算的情况下，优先降低同一目标在真实窗口中较差一路的检测损失，并同时验收背景控制和原有检出保留。**

同一个当前帧、同一个目标框可以在窗口A强响应、在窗口B低响应。原训练已有多个窗口起点，因此需要检验的是“把两路作为同一对象的比较单元是否有用”，而不是简单增加随机起点。也不要求两路数值相等：两路都低也可能数值一致，不能解决漏检。

设两路同对象正损失为 \(\ell_i^A,\ell_i^B\)，本阶段主候选是

\[
L=L_{\mathrm{shared}}+\frac1N\sum_i\max(\ell_i^A,\ell_i^B).
\]

上式在N≥2时使用；N<2时四组额外项统一置0，共发生113/512步，仍保留共享底损失。共享项保留所有帧的目标和背景监督；额外项只选择两路中较差的一路。当前实际实现用框内最大logit的正损失，属于弱框版本，原像素mask版本没有测试。平均两路、全局困难样本和随机重新配对提供必要对照。公式、数据选择与配置冻结在[PILOT_PROTOCOL.md](PILOT_PROTOCOL.md)，实现见[冻结损失源码](pilot/frozen_v1/losses.py)。

## 为什么首轮没有直接加一个门控模块

RFR的相关性调制和TF-Blender的空间/通道时序关系可以借鉴，但必须检验它们接入当前40入40出结构后的实际行为。RFR本身通过对齐和特征调制利用历史信息；这并不提供目标响应不下降的保证。[RFR原论文](https://arxiv.org/html/2409.12448v3)

已有冻结模型的局部分支实验给出了更直接的约束：保留当前槽位±4个特征帧（r=4），对其余时序投影贡献统一乘0.5（g=0.5），虽然在24个内部抑制例中恢复15例到0.5，却让42个受益例中26例的原高响应跌破0.5。因此“统一少用远帧”没有依据。这里的特征仍有前端时间感受野，不能把±4特征帧当作仅依赖±4原始帧。这个结果不否定经过训练的动态选择，仅说明需要验证选择依据与局部分支可靠性。见[局部分支实测](local_branch_probe/REPORT.md)和[文献机制对照](DESIGN_DECISION.md)。

## 当前实验给idea的判决

**当前全网弱框MIL版本不成立为有效改进，不建议直接扩大训练或进入完整基准。** 四个512步配置全部校准失败；主候选最少未匹配组件仍为官方预算的3.41倍。旧开发集上，24个低窗都能变成强响应，但强响应不等于正确匹配，原稳定检出集合还有8/463个新增丢失。

所以目前只有一个具体、可实施且已被检验过的候选，以及对其当前实现的否定结果；**没有具有正向性能证据的最终方法**。失败不否定同帧最差上下文监督的一般假说，也不证明改模型或改数据必然优于另一条路线。

## 下一步要先回答的问题

在共同监督能够保持背景控制之后，同对象最差上下文监督是否仍比平均监督、普通困难样本更有效？

先以同计划、同预算的λ=0底损失控制区分公共适配失败与额外正项影响；检查固定开发背景的高分尾部及框内峰位置。只有证据支持困难背景被稀释时，才把困难背景约束作为一项共同修订，复跑受影响的mean/max及必要控制；若证据指向目标位置标签，则优先取得原mask协议或补充可审查的目标位置监督。不能把多个改动一起加入后归功于上下文配对。

新的共同底座先通过校准，再以冻结阈值检查保留确认集。继续条件仍是相同组件约束下少漏检、有利检出保留、优于同预算相关控制。这个后续修订尚未运行，不列作本阶段成果。
