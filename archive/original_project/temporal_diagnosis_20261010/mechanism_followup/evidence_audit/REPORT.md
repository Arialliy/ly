# 已存结果的独立机制证据补查

日期：2026-10-10。只读取已有CSV，用CPU复算；未运行新推理、训练或修改原结果。

## 可以进一步收窄的问题

**当前官方方法对同一目标帧的响应变化具有目标局部差异：同一张图像、同一个真实窗口变更，可以让一个目标恢复强响应，同时让另一个目标从强响应降为近零。** 因而，需要解释的是不同目标如何从时序上下文获得或失去支持，不能仅给整帧选一个更好的时间位置。

这仍是结果层面的能力缺口，尚未定位网络中的原因，也未证明任何改法有效。

## 1. 强翻转不只出现在当前帧位于窗口端点时

从上游独立连接的严格小目标集为1,417个目标帧，97个满足某已测窗口响应<0.1、另一窗口响应≥0.9，共18个标注轨迹ID。

限定两个比较窗口中当前帧的位置均在内部后，仍有以下强翻转。slot从0开始。

|允许的slot范围|至少有两个可用窗口的目标帧|强翻转目标帧|涉及轨迹ID|
|---|---:|---:|---:|
|0–39|1,417|97|18|
|4–35|1,329|57|15|
|8–31|1,237|21|10|
|12–27|409|3|3|

这排除了“所有明显翻转仅发生在当前帧恰好位于前后4帧”的解释。它没有排除位置与上下文交互，也没有排除边界通过全窗口运算间接影响内部帧。各行窗口数及可比较样本改变，不能将比例差直接解释为边界效应大小。

97个目标帧组成58个轨迹内连续区间，最长6帧；前三个轨迹贡献52/97。重复帧、相邻窗口和同场景之间有关联，这些不是97次独立试验。

## 2. 六组同帧同窗口对出现目标间相反变化

共发现6组当前图像与窗口对完全相同、不同目标出现相反强翻转，其中2组的两个slot均在4–35。最清楚的例子是`DJI_0047_3`第17帧：

|目标|窗口start=0，slot=17|窗口start=12，slot=5|诊断点匹配|
|---|---:|---:|---|
|car，track 4500503，7×7像素|0.050308|0.990087|0→1|
|pedestrian，track 4621500，5×9像素|0.999830|0.00000229|1→0|

当前图像相同，两个目标的时间位置变化也完全相同；目标位置不同。两个真实40帧窗口共享第12–39帧，但退出的第0–11帧与进入的第40–51帧不同。它提供了一个机制定位探针：同一段上下文变化为何帮助车、同时抑制行人？

另一组内部例子为第45帧，窗口start=12/36、slot=33/9：car 4500503由约1e-6升到0.989292，而cyclist 4501000由0.997498降到0.000296。车的高响应在两个窗口中仍均未点匹配，说明只看框内峰值会漏掉定位/组件问题。

这里的反例不否认可以训练出目标相关的位置作用；它只否定“选择同一更优窗口/slot即可让所有目标同时变好”这一充分解释。它也不证明某两个目标互相竞争或某个具体层压制目标。

## 3. 两个“97”集合不同，且强响应机会不等于原基线收益

- 任意已测窗口中的强响应翻转为97个目标帧。
- EARLIEST/LATEST之间的点匹配翻转恰好也为97个目标帧；两者交集只有65个。旧`context_covariates/matched_flip_context_pairs.csv`的协变量结论对应后者，不能自动当作前者的解释。
- 强翻转97个中，60个已由原始官方融合结果点匹配。
- 剩余37个原始融合未匹配的强翻转目标帧，只有19个在任一已测窗口获得诊断点匹配。

因此，97个强响应翻转只是现象规模；19个也只是已测窗口集合中的GT辅助机会数量，仍不是可部署性能改善。所有值均不是论文Pd/Fa。

## 4. 位置相关性与最小验证建议

强翻转目标帧产生179对强翻转窗口比较（同一目标帧可出现多对）：较成功窗口更接近中心118对、较失败窗口更接近中心61对；较成功窗口起点更晚127对、更早52对。存在总体倾向和明确反例，但内容、位置、样本组成耦合，不可作为因果结论。

所有旧窗口起点间隔12帧。它们无法检验周期整除12的时间相位效应（例如period=2/3/4/6/12）；比较中slot模这些周期的值不变。若源码存在对应的分块/采样，应单独加入非12倍数的位移。

最值得验证的机制问题：**目标局部时序证据经窗口内混合后，当前帧的小目标是否被某个处理阶段从“可检出”推到“近零”？** 推荐以第17帧的反向目标对为共同探针，记录阶段响应并追踪差异首次出现的位置，再做受控干预。不要先命名新模型。这里不假定网络存在随窗口变化的统计归一化，也不假定具体机制已获证实。

必须保留的反例/控制：

1. 同帧车恢复、行人丢失的反向目标对，检查改动有无转移错误。
2. 内部slot仍翻转的例子，避免只修padding后就宣称问题解决。
3. 原始融合已匹配的60个强翻转目标帧，检查改法是否破坏已获收益。
4. 始终低响应的778帧，作为另一类缺口分别报告，不强行计入上下文可恢复收益。

固定输入帧集合后做循环移位或倒序可作为算子诊断，但会改变时序邻接或方向；如果采用这类干预，必须报告人工接缝/运动方向变化，不可直接称“仅改变位置”的自然视频因果试验。

## 工件

`analyze_existing.py`可复算本报告，输入SHA256保存在`INPUT_SHA256.json`。输出包括`SUMMARY.json`、内部slot统计、18条轨迹的强翻转分布、58个连续区间、179个强翻转窗口对及6组同图像相反变化的精确响应与框位置。

追加的原始图像审视工件由`render_visibility.py`产生：`visibility_first_flip_page1.png`与`visibility_first_flip_page2.png`确定性选择每条轨迹首次强翻转帧，共18条轨迹；每格左为原始灰度crop，右仅加GT框，64×64像素以最近邻放大4倍，无对比度增强。`opposite_frame017_whole_and_crops.png`与`opposite_frame045_whole_and_crops.png`展示同帧相反响应的整图和局部。`VISIBILITY_MAPPING.json`保存每个面板对应的轨迹、原帧、框、crop范围、原JPEG路径和SHA256。图像已与原获取manifest的哈希匹配；这些面板是供可见性审查的材料，尚不构成目标可见性的独立标注。
