# 独立复核：分层结果与同帧上下文

结论：主阈值 0.5 的清洁计数、类别/尺度分层、连续低框响应、图像对比度与运动连接、固定同帧窗口选择均与独立复算一致；最终 `INDEPENDENT_CHECKS.json` 的 `error_count=0`。结论应限定在这四个预筛片段的条件性能力缺口，不能升级为普遍类别规律或已查明的模型失效原因。

审计脚本只用主机 Python 标准库，无 GPU、安装或模型运行，也未导入 response/context 分析模块。它从原始 `analysis/*/per_track_frame.csv`、原标注 JSON、`motion/**/TRACK_FRAME_DIAGNOSTICS.csv`、`LAG5_TRACK_MOTION.csv` 和 `window_offset_experiment/analysis/*/per_context_all_tracks.csv` 重新计算，再比较分层输出。输入 SHA256 在 JSON 中。这里核查的是保存结果到分层统计的链条，未再次从像素重新计算模型概率或图像配准。

## 核实的主数值

| 条件 | 目标帧 | 轨迹 ID | 框响应 ≥0.5 | 点匹配 | 低框响应 |
|---|---:|---:|---:|---:|---:|
| 全部原始标注 | 4973 | 84 | 2007 | 1808 | 2966 |
| 原框完整在图内、无 GT 框重叠 | 3553 | 80 | 1605 | 1548 | 1948 |
| 上述且原融合/任一自然窗口无关联歧义 | 2891 | 76 | 1006 | 950 | 1885 |

清洁子集有 57 帧框内存在 ≥0.5 的预测像素但未完成点匹配；二者不可混称无响应。清洁连续低框响应 ≥20/40/80 帧分别涉及 15/8/7 个 ID。至少40帧的八个 ID 来自两个 DJI_0028 片段及 DJI_0047_3；≥20帧才覆盖全部四片段，不能写成每片均有≥40帧的长失败。

复算完整比较了主阈值下 1,218 条低响应区间记录（跨两种轨迹集、三种过滤条件）。每个区间都按真实 source_frame 连续编号建立：标注缺帧、过滤掉的重叠/越界/歧义帧以及一次非低响应都会断开区间，没有桥接这些空缺。

图像对比度独立连接自 motion 图像诊断，等于 `abs(image_box_mean-image_ring_mean)/max(image_ring_std,1)`；标准差下限来自既存 motion 协议。预测 `box_mean` 没有被当成图像灰度或对比度。运动连接在 `raw_frame_from=t`，终点均为 `t+5`，无效配准/无效目标局部支持的数值未作为有效残差速度。

## 同当前帧的固定窗口对照

已逐行核对全部 4,973 个 GT×帧的可用窗口集合与选择：起点为0,12,…,120，长度40；earliest取最小起点，latest取最大起点，center取距离slot19.5最近者、平局取较早起点。选择没有使用 GT 成败或预测分数。

严格子集、至少两个上下文、当前框最大边≤16、阈值0.5，独立结果如下。

| 检查量 | 结果 |
|---|---:|
| 目标帧 / ID | 1417 / 33 |
| 任一上下文框max跨0.5 / 涉及ID | 137 / 20 |
| 最低框max<0.1且最高≥0.9 / 涉及ID | 97 / 18 |
| earliest→center 点匹配增益 / 损失 | 50 / 30 |
| latest→center 点匹配增益 / 损失 | 31 / 42 |
| 所有本次可用窗口框max<0.5 | 778 / 1417 |

这支持当前图像相同而输出会随可用上下文与slot联合变化的描述。跨越很大，不能全部归为0.5附近的阈值抖动。但固定居中规则相对不同基准的收益方向不同；本次窗口集合仍有778个目标帧全低响应，选择窗口无法补齐这部分缺口。没有单独改变slot而保持上下文不变，因此也没有识别padding、slot或某种融合机理的独立因果效应。

## 必须保留的解释边界

1. 尺寸关系不单调。清洁≤8的响应为475/650，(8,12]为292/1033；船类≤8为369/369，而船类>16为17/672。不能概括为越小越差。原框尺度、类别、背景和运动混合改变。
2. 类别不是已识别原因。船类只在两个DJI_0028片段，公交只有一个片段。清洁行人总体254个低响应帧中143来自DJI_0047_3唯一行人ID；该片段17/160有响应，另一道路片段为201/312。不能用汇总率声称一般性的行人失败。
3. 后加探索切片“清洁、最大边≤16、有效位置残差>0.5、原始均值差>10”独立核实为315帧/125低响应；行人为203帧/112低响应，覆盖6个有低响应的ID、两个道路片段。112次中101次的标准化均值差仍<1；正灰度差不等于清晰、强对比或已人工确认可见。该组合不是独立验证集，也不证明所有条件在整段连续失败期间保持不变。
4. 原始84个track ID不是84个独立物体。43个ID在首末标注间有缺帧；39个ID达到40个标注帧。多个同类别source tracking标签对应多个处理后ID，且有source tracking标签在不同类别重复。应保留ID统计及映射警示，不擅自合并或当独立样本检验。
5. 主清洁集与去关联歧义集的组成不同：后者删去662帧，其中599帧原本有框响应。两者响应率差不能当作模型性能变差。相邻目标帧同样不能充当独立重复。
6. 本审计没有发现从这些统计到“训练没有行人”或“模型某模块缺失”的证据。公开训练元数据中的类别只证明所列训练序列有同名类别标注，不证明实际训练mask或checkpoint接触了那些目标。

目前足够形成的缺口表述是：在已测数据中，一部分小框目标的响应对联合窗口上下文敏感，同时还存在有限可用窗口均无法恢复的持续或反复低响应。一般类别规律、可见性、原因与模型/数据修改尚未由这些表识别。

若继续定位原因，最窄的有用比较是利用现有道路行人切片，在同片段、同轨迹的近时段内对照低响应与有响应帧，检查已保存标准化对比度及可见性/遮挡证据，保留相近尺度和有效运动条件。先报告能否形成这样的对照；没有共同支持时直接标注无法区分。无需由本轮统计自动推导新模块或大批新增实验。

复现：运行同目录 `python3 independent_checks.py`。脚本、JSON和run.log均在本audit目录；审计在上述主计数及风险核实后停止。
