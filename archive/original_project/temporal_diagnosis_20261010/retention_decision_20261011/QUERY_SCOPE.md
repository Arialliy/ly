# 已有穷举结果的保持与背景取舍查询

本轮只读取 `../combination_feasibility_20261011` 已冻结结果；不重新融合、不模型前向、不训练、不换阈值、不增加窗口。延续0.5、五窗完整覆盖、固定11窗池、5200小目标帧与池化U≤4015。

这是一份看到已有组合结果后的描述性查询记录，不宣称新增实验预注册，也不把查询容限变成新的方法成功标准。

1. 分别查询共用与逐片事后组合中，M≥720且U预算可行时的最小新增丢失；同时输出全部可行组合。
2. 查询丢失=0且U预算可行时的最大M及全部可行组合。
3. 为避免“相近”由个别案例决定，输出整个已达M范围的M下界—最小丢失曲线，以及所有整数丢失容限—最大M曲线。每个查询只使用一组实际组合，不拼接不同组合的最优值。并列代表依次按更大M/更小丢失、更小U、更少框外像素和起点字典序选择；全部并列行另存。
4. 对每个预算可行共用安排，列出M和丢失都不差的全部逐片组合；分别查询U和框外像素最小点并保留完整向量。还输出M和丢失完全相同的比较，以及两者各相差至多1的近邻。近邻规则仅为描述网格，报告精确差额，不称统计显著。
5. 直接枚举四目标非支配集：M最大、丢失最少、U最少、框外像素最少；组件总数、前景总数和面积分布辅助解释，不将其事后升级为硬预算。
6. 主要比较以已有共用S为高匹配控制、O为零丢失控制。较差共用安排被逐片组合超越不等于超越最强简单控制。选择均使用开发标注，是事后潜在空间，不是可部署选择器或独立泛化证据。

本轮决策只回答是否继续投入当前固定候选池的自适应选窗主线。后续低响应主诊断保留为目标—背景区分问题；本轮不执行新的原始logit前向或受控训练。
