# 问题成立性验证：窗口变化究竟留下多少最终检测损失

日期：2026-10-11。只使用官方发布权重，未训练新模型。完整连接6段视频的21,270个合法目标帧，阈值固定0.5；另对2段开发材料执行预先登记的同预算简单控制。全部为诊断点匹配及未匹配组件，不是论文Pd/Fa。

**结论：已确认窗口安排会改变最终系统的实际匹配，并在两段开发材料上存在小幅、同组件预算下可实现的净改善；但目前不能将大部分漏检归因于窗口敏感性，也不足以将“有害上下文造成大量可避免漏检”定为论文主问题。** 原五窗已成功而融合失配，与额外窗口才获得成功，是不同问题。简单安排已能解释一部分收益，复杂方法的必要性还未成立。

因此，原97例准确分解是：**60个最终已检出、19个仅额外窗口实际匹配、18个所有窗口均未匹配。** 它们并未提供原五窗融合后丢失的案例，不能再把97当成最终系统漏检规模。

补充2段中，109个候选机会占全部5,200小目标帧的2.10%，占原4,500个最终未匹配帧的2.42%。其中只有5个（0.096%全部小目标帧）在原系统已经计算的五窗内有匹配；104个依赖额外六窗。**11窗任一成功是GT辅助机会统计，不是五窗预算下可以全部实现的收益。**

原五窗已匹配而融合失败的例，在逐像素max下必然仍保留该窗的高响应像素，所以其失配不能解释为框内最大响应被融合压低。组件合并、峰位置或匹配关系的变化需要进一步区分。旧5个小目标例都来自同一船只轨迹，融合框响应全部为1.0，且不在97强翻转层。

## 4. 同预算简单控制留下了什么结果

预先固定两个控制：原五窗概率均值；对称五窗[0,24,60,96,120]概率max。二者都只需5次40帧前向、相同原生分辨率、同一原权重，完整覆盖160帧。缓存来自已完成11窗推理，只节省本次重算，不把11窗计算冒称5窗成本。

对称方案改变可用参考帧，仍在同一离线160帧访问范围内；每个预测来自包含当前帧的40帧窗。不声称逐帧参考集合或在线延迟与原方案相同。

### 固定官方阈值0.5，两段开发材料

|系统|小目标匹配/5,200|相对原系统新增|相对原系统丢失|净变化|未匹配组件|
|---|---:|---:|---:|---:|---:|
|原五窗max|700|0|0|0|4,015|
|原五窗均值|659|1|42|−41|3,490|
|固定对称五窗max|720|74|54|+20|3,967|

对称安排在两段分别净增6和14个，组件分别由741降至707、3,274降至3,260。因此这里有一个**实际可执行的同前向预算、同阈值且组件预算内的小幅净改善**，不只是GT任一窗上界。+20相当于小目标匹配率增加0.3846个百分点，或相对原700个匹配增加2.86%；不是增加20个百分点。框外正像素则从38,368增至38,641，所以这里通过的是预定未匹配组件预算，不能称所有背景指标均改善。

但它在130条小目标序列—轨迹中，14条净增、13条净失、103条净零。74个新增由73个“额外窗机会”与1个“原五窗融合损失”组成；109个候选机会中仍剩35个未匹配，还新丢失54个原成功对象帧。

原本至少有2个可用窗口、且所有11网格可用窗口及原融合均匹配的保护集合为422例，两种控制在0.5均无新增丢失。54个对称安排损失在这一稳定集合之外。这说明简单安排保护了这部分稳定检出，但没有保住所有依赖原窗口选择的成功样本；不能把“保护集合全保留”说成“没有代价”。保护集合、内部槽位与轨迹净变化的独立复算见[补充诊断](supplemental_diagnostics/README.md)。

## 5. 现在支持什么问题，下一步先验证什么

|层次|本轮后的状态|
|---|---|
|同帧跨窗响应/判决变化|已观察，且与最终检测联查。|
|现有系统中的实际匹配代价|已确认少量原输入融合损失，以及更多额外窗口机会；在两段材料上简单同预算安排有+20净改善。|
|大规模、可推广且值得专门建模的检测瓶颈|尚未确立。机会只覆盖补充组最终漏检的2.42%，剩余4,391例在所有已测窗口均未匹配；简单安排已解释部分收益。|
|损失由有害内容/位置/特定结构造成|尚未确定。自然内容差别可能提供合理的不同证据；融合后失配也不同于响应塌缩。|
|paired_max为有效解法|当前实现仍是第一阶段校准失败，未被本轮简单控制结果改变。|

下一步保留候选问题：**在固定离线时间访问范围、窗口预算及背景约束下，如何让有限窗口覆盖更多可检出目标，同时减少切换安排带来的原成功样本损失？** 这仍是待验证的问题表述，不是已成立的方法或CVPR贡献。

在开始新复杂方法前，应冻结上述原方案/对称安排和阈值规则，在更多预定、未按响应筛选且来源隔离的开发材料上确认：净改善是否跨轨迹/场景稳定、简单控制后还有多少实际剩余空间、哪些样本只能靠确实新增的有效证据检出。涉及可见性或运动阶段的判断需要看原图并核实，不能只用标注存在替代。若扩展后净收益很小或简单控制已足够，应收窄/停止该建模路线。

λ=0和原始logit排错解释的是训练失败，可另行安排，不能代替以上问题成立性证据。本轮已完成用户要求的首张联表和有限简单控制；没有以这一轮替代独立确认、完整基准或自然输入因果验证。
