以(sequence, absolute local frame, annotation ID)连接，逐项核对轨迹ID、source frame及bbox。设F为原最终融合是否匹配，A为任一11窗是否实际匹配，B为任一原五窗是否实际匹配。输出完整2×2(F,A)，并将F=0,A=1拆成：

1. B=1：原系统已计算的某窗匹配，但融合结果未匹配。记录为融合后匹配损失，需要进一步核查组件合并/峰位置/关联；不自动断言损失由有害内容造成。
2. B=0：只有额外六窗中的窗口匹配。记录为额外窗口发现的机会；11窗用了更多计算，不能把A当作可部署同预算收益。

F=0,A=0再拆成任一窗口框响应≥0.5与所有窗口框响应<0.5，区分高响应未匹配和持续低响应。F=1也报告分数翻转/窗口匹配翻转，避免将已被融合解决的变化计作系统漏检。F=1,A=0保留为融合新增匹配，不能假设为空。

按片段、轨迹汇总次数和比率，分母同时给全部对象帧及最终未匹配帧；不将相邻对象帧当独立重复做显著性检验。保存逐对象、逐窗口对照。记录匹配窗口起点、当前帧槽位、类别、尺度和源帧范围。自然窗口的内容与位置共同变化，不在本轮以这些描述证明因果机制。
