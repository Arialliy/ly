# 同一 E2 检查点的残差开关验证

本次验证确认：新增分支确实参与计算并改变原始输出，但在冻结的两个开发片段上，打开分支没有新增小目标匹配，只小幅减少背景成本，同时损失少量已有匹配。此结果不改变 E2 已停止的判定，也不是新训练结果。

比较仅将最终 E2 的新增残差关闭或打开。关闭时保留 E2 已训练的全部原网络参数，不使用 E0。阈值仍为 0.5，O、S 均为固定五窗安排，实际融合与点匹配沿用原实现。检查点、输入、预处理、BN 状态和参数值保持一致。

| 指标 | O：开启 / 关闭 | S：开启 / 关闭 |
|---|---:|---:|
| 5,200 个小目标帧的实际匹配 M | 1,060 / 1,064 | 1,115 / 1,118 |
| 开启后新增 / 丢失 | 0 / 4 | 0 / 3 |
| 未匹配组件 U | 11,863 / 11,967 | 12,169 / 12,300 |
| 框外前景像素 A | 128,754 / 129,097 | 131,218 / 131,578 |
| 4,342 个冻结低响应目标帧的恢复 | 343 / 347 | 375 / 377 |
| 4,170 个极低响应目标帧的恢复 | 244 / 246 | 271 / 272 |

两个安排的匹配丢失均来自 DJI_0067_2；DJI_0026_2 的小目标匹配没有变化。新增匹配为零，因此不是新增与丢失相互抵消。两种开关状态的 U 均明显超过冻结预算 4,015；U 是诊断未匹配组件数，不是论文 Fa。

646 个原始双安排成功对象中，开启分支时双成功 / 仅 O / 仅 S / 双失败为 603 / 11 / 11 / 21；关闭时为 604 / 10 / 11 / 21。原成功集合没有从打开分支中获得保持收益。

原始 logit 与特征残差也显示了真实作用。以下都是开启减去关闭；困难背景块在推理前按发布模型分数选定，未按本轮结果选块。

| 冻结低响应集合中的区域 | O：区域最大 logit 差均值 | S：区域最大 logit 差均值 |
|---|---:|---:|
| 目标框 | −0.02177 | −0.02288 |
| 同尺寸局部困难背景 | −0.01155 | −0.01260 |
| 同尺寸全图困难背景 | −0.11952 | −0.12950 |

低响应目标框最大 logit 差的中位数为 −0.00924 / −0.00990；实际输出残差相对输入特征的范数比，先在合法覆盖窗口间平均，再按目标帧平均，为 0.003874 / 0.003905。全图逐像素绝对 logit 差的中位数按片段和安排为 0.00069–0.00186，99% 分位为 0.0205–0.0486；个别像素差可达到 3.44。因此可以说典型变化较小，不能说模块完全无作用。

这里区域最大值是各自取最大后相减，不代表同一像素的变化；固定发布峰、关闭状态峰处的变化以及区域均值均保留在逐区域 CSV。检测始终使用各窗口 sigmoid 概率的 max 融合，原始 logit 的 max 汇总仅用于本次解释。

困难背景的行数不是独立背景样本数。低响应组每个安排有 4,342 个全图背景配对记录，但只有 3,709 个不同的 `(片段, 帧, 区域)`。局部背景每个安排有效 4,341 行，O / S 分别对应 4,338 / 4,339 个不同区域；缺失行保留。没有进行独立样本显著性推断。

实现与执行检查通过：两片各 8 个窗口的新开启概率与旧 E2 缓存逐位相同；加载状态与最终 E2 一致，推理前后参数状态不变；直接捕获输出投影的实际残差为非零；两个 GPU 容器均正常退出。训练更新证据复用旧训练审计。特征只保存区域平方和，后续可独立核对范数比，但不能声称从未保存的完整特征张量重新计算了残差。

这项开关对照回答的是最终共同适配检查点上残差的边际作用，不能代替重训对照，也不能证明邻帧信息本身无用。当前证据支持的是：该已训练分支没有将其作用转化为本次所需的弱目标恢复与原成功保持；它的小幅背景减少不足以形成预算内改善。
