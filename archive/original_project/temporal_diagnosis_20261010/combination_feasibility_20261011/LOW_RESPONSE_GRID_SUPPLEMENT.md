# 低响应阈值网格补充：探索性精度核查

本补充是在已看到原23点曲线和五窗组合结果后提出，属于开发样本上的探索性诊断，不是预先独立验证，也不改变主实验0.5阈值、候选池、U<=4015或五窗最优性范围。

动机：S在0.4时U=4055、0.5时U=3967。旧网格不足以排除两点之间存在少量低响应目标的预算内恢复；不可将23点无恢复外推为所有阈值无恢复。

在查看新阈值输出前固定补充阈值为0.41,0.42,...,0.49，且同时计算O/S两个已冻结安排，不按本轮最优片段组合扩展扫描。复用保存的概率图；每个阈值对全部320帧重做原组件峰值匹配；保存逐对象匹配和逐帧计数。与已有0.4、0.5端点对照。主对象为固定5200，其中低响应组仍由全11窗max<0.5定义为4342；以原O/.5的700成功定义gain/loss。

报告所有新增阈值的总体匹配、低响应恢复、原成功新增丢失、U、总组件、前景/框外像素及是否满足原池化U预算；每片预算仍只作副标记。选择最优仅作事后可行性描述，不算训练方法或独立确认结果。完成该固定9点补充即停止，不自适应追阈值；仍不宣称遍历连续阈值或不存在更细网格改进。

结果用于判断简单分数校准可解释多少，并保留未测低阈值细节、逐片/逐空间自适应阈值、原始logit/困难背景可分性为未决。
