**下一步建议启动一个独立的“近期方法恢复对照”阶段：用 TEP‑SAM 的作者发布权重，检查它能否在完整画面中实际恢复你已经确认的漏检，再决定借鉴哪一种机制改进 DeepPro‑Plus。**

**本轮不训练第三个模块，不重新检查E2，也不扩大原来的信息探针。** 目标从“解释旧模块为什么失败”，转为：

> **近期方法是否已经提供了一种可重复、背景代价可接受的恢复方式？它的哪些处理机制，值得在 DeepPro‑Plus 上接受最小化验证？**

这与现有结题边界一致：研究目标和baseline保留，下一种结构应由区别于旧方案的新证据启动，而不是由旧方案失败自动触发。CLOSEOUT

## 一、为什么这次选择TEP‑SAM，而不是再设计一个聚合模块？

我核对了近期工作。**TEP‑SAM发表于ICML 2026，其主要思路是先形成能够区分目标与背景的时序线索，再用这些线索引导分割。** 它并不是仅在已有特征上增强帧间关联。这个切入点与你已经结束的“同层局部检索—双向核验—残差聚合”不同。[Proceedings of Machine Learning Research](https://proceedings.mlr.press/v306/xing26b.html?utm_source=chatgpt.com)

具体来说，它包含时序编码、特征注入和自动提示生成；时序编码结合全局背景动态、局部变化及当前帧与邻帧的差异。**我们可以借鉴的是“如何形成可辨别证据”，而不是把SAM、提示和多个分支一起拼到DeepPro‑Plus上。** [arXiv](https://arxiv.org/html/2606.27655v1)

还有两个实际理由：

**有可直接评估的权重。** 官方仓库列出了NUDT‑MIRSDT和TSIRMT训练权重，以及输出IoU、Pd、Fa等指标的测试入口。因此可以先做冻结权重推理，不必重新训练一个完整大模型。这里确认的是作者提供了下载入口，尚未下载或验证权重本身。[GitHub](https://raw.githubusercontent.com/cdh8285/TEP-SAM/main/README.md)

**输出是密集分割结果。** 可以在恢复到原图坐标后，接入你现有的组件峰值与点匹配诊断，而不必先把框检测输出转换成另一种检测对象。[arXiv](https://arxiv.org/html/2606.27655v1)

但必须事先承认：**TEP‑SAM在你的材料上是否有效，现在不知道。即使有效，也不能直接归因于它的时序编码器，因为模型容量、预训练、监督和解码方式都不同。**

本轮将它作为**寻找实际恢复证据的参照**，不是替换baseline，也不是用跨模型成绩直接证明某个机制。

## 二、本轮范围：一个参考模型、零次检测器训练

建议只执行下面这一轮，不同时启动CHAL、TDCNet、NS‑FPN等多套模型。

| 项目 | 本轮固定安排 |
|---|---|
| 保留的baseline | 当前冻结的DeepPro‑Plus发布权重 |
| 新增参考 | TEP‑SAM作者发布的一套权重 |
| 首选权重 | NUDT‑MIRSDT版本：你已有该数据上的发布权重推理核对基础，便于检查运行口径 |
| 训练 | **不进行微调、不更新参数** |
| 数据 | 先核查作者原生测试流程，再评价已有两个开发片段的完整画面 |
| 不动的部分 | 四个保留确认片段、E0/E1/E2工件、旧阈值与旧结论 |

首选权重的理由是运行条件可核查，**不是预先认定NUDT权重最适合真实RGBT‑Tiny场景**。跨数据集适用性正是结果解释中的一个限制。

### 先通过一次原生运行检查

固定仓库版本、检查点哈希、预处理和预测输出方式。在作者规定的数据与评价流程上，确认加载、推理、坐标还原及指标计算可信。

如果只核对一个预定小子集，就称为**运行检查**；完成官方完整划分并与报告结果对齐，才称为对应的**发布权重推理复核**。两者都不是从头训练复现。

**权重或运行配置无法对齐时，本轮记为执行受阻，不转而自行训练一套“近似TEP‑SAM”。** 否则又会把“方法有没有用”与“适配配方是否可靠”混在一起。

## 三、用完整检测输出判断，不再用小样本AUROC代替恢复

你已经明确了上一轮探针的边界。这次的主要证据应直接来自：

> **完整画面上的预测 → 固定后处理 → 实际目标匹配 → 背景成本及连续漏检变化。**

### 1. 数据对象全部沿用，不能围着参考模型挑样本

已有两个开发片段、5,200个严格小目标帧、130条轨迹，以及冻结的4,342个低响应目标帧继续使用。它们的定义和原评价边界已经登记，不重新选择“TEP‑SAM容易恢复”的子集。CLOSEOUT

完整画面中的背景和所有已标注目标都保留。不能只在目标框附近评估，否则又会绕开背景代价。

### 2. 评价结果至少回答四件事

| 问题 | 直接统计 |
|---|---|
| **原漏检是否恢复？** | 冻结低响应集合中的实际匹配，以及相对发布O、S的新增 |
| **持续漏检是否减少？** | 相同轨迹观察范围内，连续漏检段的变化 |
| **原成功是否受损？** | 相对发布O、S的丢失；646个原双侧成功对象的保留情况 |
| **恢复花费多大代价？** | 未匹配组件U、框外前景像素、未匹配组件面积及实际计算成本 |

TEP‑SAM若每个当前帧只输出一次预测，646集合这一列应叫**“原双侧成功对象中本模型仍检出的数量”**，不能叫“TEP‑SAM双侧成功”。不能为了套用O/S表格，虚构两种相同的推理安排。

同样，**不要把两个模型成功集合的并集当成一个新系统的成绩**。事后知道哪个模型成功再选择结果，只能描述互补空间。

### 3. 主诊断继续固定0.5，但不要把相同阈值等同于完全公平

在恢复原图坐标、确认概率含义后，使用固定0.5和既有组件匹配规则，作为本项目的主诊断行。

作者原生评价单独保留，不和项目诊断混写。**相同的0.5不保证两个模型分数经过同等校准**；因此，参考方法在这个工作点失败，只能说明本次设置没有提供所需的正向证据，不能证明它在所有工作点无效。

本轮不通过改阈值把结果调进预算。对于相同320帧、相同组件定义的完整评价，继续面对 \(U\le4015\)；框外面积等代价仍然同时报告。

### 4. 时间访问与计算必须单列

TEP‑SAM采用以当前帧为中心的短时序输入；作者也明确，它更适用于背景运动相对连贯的短窗口场景。[arXiv](https://arxiv.org/html/2606.27655v1)

在实施中，应保证它不读取项目禁止的帧，并预先固定边界处理。若原生输入规则与当前允许范围不兼容，就明确记为**协议不兼容**，不能悄悄增加未来信息。

此外，它不是DeepPro‑Plus的同计算量替换。**本轮允许它作为较重的机制参照，但参数、前向次数、显存和耗时必须记录，不能称为同预算方法提升。**

## 四、利用作者已有辅助输出，避免再次新训探针

TEP‑SAM论文在时序编码器后设有一个经过监督的辅助预测头，用于支持时序特征学习。[arXiv](https://arxiv.org/html/2606.27655v1)

**如果发布检查点确实保留该头及其训练参数，建议在同一次前向中另存它的密集输出。** 不新建读出器，不重新训练，也不在小目标框上单独分类。

这份输出只作辅助解释：

- 完整模型恢复了哪些对象？
- 时序分支自身是否也在这些对象位置形成实际可用的预测？
- 它是否同时对困难背景产生大量响应？

如果检查点不包含这个头，就记录“不可评价”，**不为补齐它再训练一轮**。

即使辅助输出表现较好，也不能直接证明收益纯粹来自运动差异：该分支本身包含空间与时间处理。它的价值是把“整个SAM系统有效”进一步缩小为“这个具体表征分支可能值得迁移”，而不是完成最终因果归因。

## 五、结果出来后，直接决定下一种设计是否启动

这一轮不能又只留下“有一点线索，继续观察”。建议按以下规则作决定：

| 本轮结果 | 下一步决定 |
|---|---|
| **完整TEP‑SAM在背景受控时恢复原漏检，并缩短多个轨迹的漏检段** | 获得实际解法参照，可以开始针对性迁移设计；但暂不把收益归因于某个模块 |
| **完整模型有效，时序辅助输出也有对应的恢复证据** | 优先检验“显式形成时序可辨别特征”这一设计方向 |
| **完整模型有效，但辅助输出不可用或没有对应优势** | 保留正向参照；不能直接决定搬时序编码器，可能需要考虑预训练、空间表示或解码作用 |
| **只提高匹配，同时背景扩张或原成功显著丢失** | 未提供符合研究目标的解法，不据此启动新结构 |
| **在核查可信的运行条件下仍没有有意义的恢复** | 结束本轮参照；不把它写成全方向无解，也不自动再跑一串模型 |

“有意义的恢复”仍应面对**目标帧、轨迹、片段和连续漏检**四个层级。只在一条轨迹上恢复几个离散帧，不足以据此启动复杂模型；也不应只因一个总体百分比提高，就忽略背景和保持退化。

这里不新增未经登记的“必须恢复44帧”等硬数字。沿用实际协议和投入标准，**不要让一个临时整数取代完整的检测取舍**。

## 六、通过后，怎样回到“在DeepPro‑Plus上设计自己的模型”？

**只有取得上述正向证据后，才进入下一版结构设计；而且不是复制TEP‑SAM。**

优先考虑的设计对象将从：

> **在已有弱特征中寻找更可靠的对应。**

转为：

> **从原始时间窗口或浅层特征中，形成原baseline缺少的目标—背景区分线索，再供原TPro使用。**

这两者有实质区别：前者依赖现成描述子能够进行匹配；后者研究的是**可辨别特征怎样形成**。但这只是下一阶段的候选方向，不是现在已经确认的原因。

届时的结构对照应包括：

| 对照 | 作用 |
|---|---|
| 同监督的原DeepPro‑Plus | 判断新结构是否有实际增量 |
| 一个明确归属于近期工作的最小机制移植 | 判断已有机制是否已经足够 |
| 针对你剩余失败条件设计的改动 | 判断自己的约束是否有独立价值 |

不能把“增加时间差分”本身当成新贡献。AAAI 2026的TDCNet已经研究时间差分与3D卷积结合、不同时间范围的上下文提取；这应作为设计边界，而不是直接再接一个差分卷积就声称创新。[AAAI Publications](https://ojs.aaai.org/index.php/AAAI/article/view/37385?utm_source=chatgpt.com)

同样，TEP‑SAM已明确讨论强相机运动、复杂视差，以及极慢或静止目标时的限制。**这些是可以核对的候选条件，不是自动属于你的失败根因。** 下一次自己的设计，应围绕其中实际在数据上重复出现、现有解法仍未覆盖的条件提出。[arXiv](https://arxiv.org/html/2606.27655v1)
