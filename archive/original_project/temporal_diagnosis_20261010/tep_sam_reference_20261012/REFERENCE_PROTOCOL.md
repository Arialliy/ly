## 固定完整画面输入与输出

| 项目 | 预先固定值 |
|---|---|
| 开发对象 | DJI_0026_2、DJI_0067_2，各 160 帧；原图 512×640 |
| 全量分析 | 5,200 个严格小目标帧、130 条轨迹；4,342 低响应、其中 4,170 极低响应、646 原 O/S 双侧成功 |
| 输入时间 | 当前帧及前后各 3 帧；片段边界截断索引并重复边界帧 |
| 空间输入 | 完整图像转 RGB，PIL bilinear 拉伸至 1024×1024，ToTensor、ImageNet mean/std；无裁剪或分块 |
| 主预测 | 原模型 infer：logit 的原双线性还原到 1024，再 sigmoid，再 area 将概率还原至原图 |
| 辅助预测 | 同一次 image_encoder 前向捕获已有 middle_mask；按原 postprocess_masks 还原 logit，再 sigmoid、area 到原图 |
| 提示 | boxes=None；不读取目标标注生成提示或选择输入 |
| 数值设置 | seed=46、FP32、batch=1、无 AMP/TF32、cuDNN benchmark 关闭；不更新权重或 BN |

辅助头没有作者提供的独立测试入口，其还原链是**本项目预先登记的诊断适配**。主、辅各一套完整画面输出并分开报告，辅助成绩不能称作者正式成绩。作者代码内部重复调用时序编码的运算保留，不做缓存优化。

`TIME_ACCESS.csv` 逐帧登记 7 帧输入。320 帧全部通过：TEP 的参考帧均属于原 O、S 各自覆盖当前帧的窗口所能访问的帧并集；无片段外输入。该结果只证明时间访问合规，不代表同计算量或同预训练条件。

## 评价与决策

沿用已有概率 **>=0.5**、8 邻接组件峰、全部有效标注参与的一对一框内点匹配。作者原生采用 **>0.5**；分别保留并计数恰为 0.5 的像素。不改阈值、插值顺序、候选池、解码或匹配规则。

DeepPro 发布 O（700/4015）和 S（720/3967）继续作为两个固定参照。TEP 每帧只有一次输出；分别计算相对 O/S 的新增、丢失与最长连续漏检变化，不给 TEP 虚构 O/S。保护列称“原双侧成功对象中本模型仍检出的数量”。

背景约束为相同 320 帧下 U<=4015，同时报告框外前景、总组件与未匹配组件面积。U 不是官方 Fa；预算通过也不等于背景成本与 O 或 S 相同。连续性要求本地帧和来源帧均相邻，缺标及筛选空缺打断，范围仅为冻结观察区间。

通过后是否设计迁移，只据以下规则决定：

1. 完整模型在背景受控下恢复冻结漏检、缩短多条轨迹的漏检段，并有可接受的原成功保持，才获得可用于设计的正向参照。
2. 辅助输出有相应实际恢复时，才优先考虑显式形成可区分特征的假设；仍不能将完整模型收益归因于纯时间差分或某个模块。
3. 匹配增加伴随背景扩张或明显原成功丢失，不启动新结构；无有意义恢复则结束本轮，不自动试其他模型。
4. 不新增临时恢复帧数门槛；联合报告目标帧、轨迹、片段、连续漏检。成功集合并集只描述事后互补，不作为系统成绩。
