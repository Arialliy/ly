# 路线选择记录：从已定位的损失出发

日期：2026-10-11。目标是正确匹配、减少新增漏检并控制背景成本，不是单独提高框内响应。本轮不指定新模块或训练损失，不启动新训练。证据详见[总报告](REPORT.md)。

## 1. 当前优先级

**A：优先解释成功窗口依赖，随后才决定窗口安排或时序模型。** 54个丢失全部失去原成功窗，73个新增依赖新加入的窗；每次只替换一窗的覆盖完整路径也复现增损交换。这是流程级直接证据，但参考内容与当前帧槽位共同变化，尚未证明物理证据不足或结构位置依赖。

**B：持续低响应单独保留。** 4,391个全窗失败中4,170个最大响应仍<0.001，覆盖116条轨迹；它是比5个融合失配更大的输出缺口。不能由此认定应改数据、目标不可见、物理静止或模型没学会某类目标。需要先核对目标可判读性、与成功样本的条件差异及训练监督。

**融合/峰提取是明确但有限的支线。** 5例已有近饱和前景却失去点候选，2例是真实多组件连接，其余包括平局规则和近饱和排序。它们在固定区域命中指标中没有丢失；是否值得成为主线，取决于最终要求的输出规格和更广的实际代价。

## 3. 下一轮最小而有判别力的工作

1. **先固定主要检测输出。** 若目标是复现原论文Pd/Fa，需要取得作者实际RGB-T评价标签；若目标是公开bbox下的点/框检测，应明确其任务与协议，并保留官方兼容代理的差异。不能用组件预算替代像素误报预算。
2. **复查具体成功窗所含证据。** 从已经冻结、按轨迹合并的增损事件出发，核对局部图像时间信号、目标进入/离开标注范围、邻近目标/边缘；没有人工证据不赋“遮挡”或“静止”标签。内容与槽位分离的干预需另立协议，当前自然滑窗并没有完成分离。
3. **验证条件而不是盲目加片段。** 在查看新预测前按标注及来源规则冻结扩展材料、属性分组、阈值和背景口径；先问本轮定位的成功窗依赖及持续低响应是否重复。四段保留确认材料不作反复开发。

λ=0、真实logit、作者监督资料核查仍是并行训练诊断。它们可以帮助后续建立稳定底座，但不替代上述任务定义和故障条件证据。

## 4. 何时可以形成具体idea

只有在“失败环节—可重复条件—简单控制剩余空间”三者对应后，才选最小实现：需要保持同一时间证据时再研究表示/位置处理；需要在有限预算中覆盖不同证据时再研究窗口选择；只丢峰候选时先研究输出提取；训练条件确有缺口时再设计针对性数据或监督。

当前可以清楚提出的研究候选是：**固定时间与计算预算下，如何保留不同目标赖以检出的时间证据，避免恢复一批目标时丢失另一批目标？** 这是待收窄的问题，不是已证明的新模型idea；4,170个极低响应对象另保留为基本可检出性候选。若新来源不支持，或主要差异只来自评价定义，就收窄或停止相应路线。
