# 代理指标冻结协议

2026-10-11，在本轮代理指标计算前冻结。仅使用两个既有开发片段 DJI_0026_2、DJI_0067_2 的缓存概率，固定阈值 `>= 0.5`。不训练、不推理、不筛选阈值。

作者 RGB-T 测试读取 `segmentations/<sequence>/` 图像，先将非零值置 1，再把此完整标签作为 `centroid` 输入 ShootingRules；并不是由 bbox 中心自动产生标签。当前未获得作者实际评估用 segmentations 图像；论文只明确训练用由框生成 Gaussian mask，不能据此假定测试标签的确切支持域，也不能用公开矩形 segmentation 代替。因此以下量均为代理诊断，禁止标成作者 Pd/Fa 复现。

1. **框内像素命中**：沿用已冻结的半开 bbox 内像素中心定义，只要至少一个像素概率 >= 0.5 就记命中。该量不要求组件峰值或一对一匹配。
2. **bbox 中心邻域命中代理**：对每个有效标注取 `(floor(x+w/2), floor(y+h/2))` 为中心像素索引，再截到合法图像索引；以截断到图像内的中心 ±1 方形 3×3 区域任一像素 >= 0.5 为命中。独立计每个 annotation，不实行预测一对一分配。记录中心截断情况。
3. **bbox 中心背景代理**：从全部有效标注的中心 ±4 方形 9×9（边界截断）排除域外计算前景像素；分母为全图像素。它不同于框外像素，更不同于真实 Gaussian 支持域扩张后的作者背景域。
4. **官方函数适配核验**：同一中心像素构成合成二值 map，直接调用当前本地提交的 ShootingRules。在这项适配中保留作者负下标切片语义、不修正边界；8 连通相邻中心会合成一个 target region。另行独立实现该语义核对 FalseNum/TrueNum/TgtNum。此项仅证明函数调用一致，不能证明合成标签与作者标签一致。
5. **背景结构**：原五窗 max 与对称五窗 max 的全前景、所有有效框外前景、8 连通组件总数、未匹配组件数、组件面积分布；以原点匹配规则分配组件。按序列和 pooled 均报告，不选最有利指标作为总背景结论。
6. **固定标签单调性**：原五窗分别与其原 max 融合比较，逐像素验证 fused >= window；逐对象验证中心邻域命中、框内命中从 any 原五窗到融合没有丢失。重点列出 5 个小目标原窗口点匹配、融合点匹配失败例。比较 74 新增/54 丢失在中心代理与框内命中上的状态变更，保留与点匹配不一致的情况。

代理结果不用于选择新方法、阈值或重新定义成功集。原点匹配 74/54 和 5 例由上一轮固定 CSV 给定。所有指标仍受标注质量与作者标签缺失限制。
