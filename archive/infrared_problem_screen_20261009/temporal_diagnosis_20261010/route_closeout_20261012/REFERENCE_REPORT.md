日期：2026-10-12。**本轮完成代码交付和接口检查；没有取得新的检测性能结果。** 原研究目标、R0/R1/R2和此前候选的停止决定保持不变。

## 1. 本轮实际改动

在冻结本地DeepPro-Plus的`layer1`之后、唯一`TPro`之前加入逐帧空间参考，公式为`F + tanh(scale) * (P(F) - F)`。P使用显式Haar子带、低频条件化注意力和局部Gaussian过滤；不含新增时间运算。新参数100个（注意力98、sigma1、标量gate1），原70913参数及BN冻结。返回8通道特征与原始logit的契约不变。

这是依据LFP思路独立编写的参考控制，不能加载作者权重后假定等价，不是作者方法复现，也不是已成立的时序贡献。自写版本明确采用子带轴、右下复制填充与裁剪、sigma平方下限、初始注意力0.5等自己的约定。高频中可能包含目标信息，过滤并不自动等于背景抑制。

## 4. 失败记录及修正边界

整网第一版检查把参数冻结前的原模型，与参数冻结后的包装模型直接要求逐值相同，出现最大logit差3.24e-5。逐帧还原时改为连续BCTHW排列后，第二版仍出现相同差异，所以**不能把误差直接归因于内存排列**。

第三版显式增加冻结后的原模型参照：冻结后的原模型与零门控包装模型两路输出均逐值相同；冻结前后原模型的差异与此前差异一致。该结果支持在相同冻结状态下插入参考没有引入数值改变；尚未追踪底层算子选择，不将`requires_grad`标志或内存分配直接认定为唯一原因。冻结前后的差异仍在既定数值容差内，记录保留，不伪装成初始两次也通过。

两次失败及最终结果分别为`DEEPPRO_GPU3`、`DEEPPRO_GPU3_v2`、`DEEPPRO_GPU3_v3`启动和结果文件。CPU测试另有一次任务并发造成的重复（`ADAPTER_CPU`），如实保留；没有对应新增GPU训练。
