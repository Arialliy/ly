# 唯一后续适配检验：为空标签窗口补入既有背景负监督

登记日期：2026-10-12。状态：**仅设计，未实现、未训练、未推理**。本轮用户要求“先不新增训练”；本文件把下一步限定为一个有依据的因素，不代表当前已运行或获得收益。

## 证据与假设

近似控制385/2048窗最终目标质量为0；16个全空batch的loss恒1、当前损失梯度为0。相同计划下top1对应更新仍有负梯度。空窗贯穿训练；标签/实际日志可直接证明这个行为，不依赖终点猜测。这里“空标签／纯负窗”只指有效监督域没有正标签，不保证原图不存在未标注或被忽略的目标。

假设：在固定近似监督中，让这些空标签窗以已有负项参与优化，可能减少没有受到直接损失约束的背景响应，并改善检测取舍。**尚未证明这一缺口造成了开发背景退化；它也不能解释已具有该负监督的top1为什么失败。**

## 唯一改变与精确定义

对窗w，V_w为冻结有效域，B_w为原top1背景域，P_w=sum(y[V_w])。

- P_w>0：完全保留现有masked官方Soft-IoU，包括内部sigmoid、smooth=0、有效域和归约。
- P_w=0：将原常数1的窗口损失改成 `mean(TopK(softplus(z[B_w]), k_w))`，`k_w=max(1,ceil(.01*|B_w|))`。只复用既有top1实现及并列规则，系数固定1，不以预测0.5作筛选。
- 空B_w返回原实现的可微0；空V_w仍保留现有错误检查。现有计划中有效域、背景域均非空；空标签时V_w=B_w应由入口断言保障，若不成立不得偷偷更改掩码。
- 四窗仍等权平均。不跳过空窗、不重采样、不将有正窗重归一化、不在有正窗上增加任何项。

去掉原常数1改变了总loss的数值零点，不改变该常数的梯度。日志需分别保存原官方损失、实际空窗负项、空窗数和梯度，不能通过两个总loss的数值高低宣称改善。本控制检验一种固定负监督是否补上空窗信号，不单独区分困难位置选择和负梯度强度。
