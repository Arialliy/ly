# 冻结特征 P0/P1/P2：有限描述测量协议

2026-10-12。只检验已失败候选所依赖的信息前提，不重训DeepPro、不更新E2结题、不设计第三个网络。本轮执行一次18帧共同支持子集的有限描述测量；根代理统一冻结样本、源码及协议后启动特征提取与读出。

## 几何与样本

使用发布DeepPro-Plus的`layer1`输出，原32通道、FP32、eval及原归一化。输入是原160帧片段中的真实40帧窗口；每个对象帧只从O=[0,36,72,108,120]选择当前位置最接近19.5的窗口，较早起点破平局。合法参考只有该窗口内`t-1,t+1`；每条样本为一个对象帧与一个合法参考方向。

当前目标为原规则的严格小目标（最大边≤16、非ignore/crowd、不与其他有效框重叠、完整落图）。查询位置为粗框中心向下取整的像素索引；这不是精确质心。Q支持域为当前粗框像素中心区域与5×5查询邻域的交集。P1的R支持域为同一track在参考帧的唯一无重叠粗框与相同5×5邻域的交集。参考越界、缺标、source帧中断、同track多义、重叠或交集为空即拒绝该边。

P2的B必须在**P1同一个参考帧s**、同一r=2邻域内。按水平、垂直、双反射的固定顺序，将R围绕查询像素中心反射；尺寸、像素数量、逐点到查询的距离完全保持。选择首个能与正负配对共同成立的区域。B任何像素触及全部标注框（含ignore）及2像素缓冲都不允许。**不扩大半径、不缩缓冲、不把远处背景冒充同访问范围对照。**

对每条正样本，将Q/R/B三块同时平移同一个偏移d，得到负样本候选。D=4×该轨迹严格小目标整数框最大边；使用(D,0),(-D,0),(0,D),(0,-D),(D,D),(D,-D),(-D,D),(-D,-D)，再按相同顺序取2D，共16候选。三块均须完整落图且避相应帧全部GT+2。这样正负样本共享区域形状、大小、参考帧、相对位移；不存在正样本有参考、负样本填零的标签捷径。

冻结全部合法负候选后，用同一次发布模型前向的**查询ROI最大原始logit**选择最强背景；相等按上述候选顺序。三种探针共享这次选择。此分数、坐标、mask、像素数、是否缺标、轨迹或类别均不进入读出器。所谓背景仅指未落入已标注目标与缓冲；无法保证没有漏标目标。标注辅助区域选择本身属于oracle条件，不能宣称完全排除了所有选择偏置。

## 读出和容量边界

各区域对32维layer1特征作空间均值，输入P0=[q,0]、P1=[q,r]、P2=[q,b]。统一64维带截距线性logistic；无隐藏层。P0后32维固定零，**有效秩与有效容量低于P1/P2**，不能称严格等容量。因此同目标参考主张必须同时面对P2，单独P1优于P0不足以证明对应有用。选P0=[q,0]也避免重复q导致L2有效强度变化。

标准化只使用训练样本q（成对正负）的32通道均值/标准差；q/r/b均用同一组统计，std下限1e-6。训练按来源等权、来源内轨迹等权、轨迹内目标帧等权、帧内参考边等权、每边正负各半。目标是加权平均BCE+0.5×0.01×||w||²，截距不罚。权重和截距零初始化，CPU float64、确定性LBFGS，最多200迭代、strong-Wolfe、梯度容差1e-9/变化容差1e-12；保存迭代、最终梯度与收敛状态，不按dev改参数或增加迭代。

原8训练来源只能贡献几何共支持样本，2个dev来源只用于冻结读出后的检查。逐来源报告实际使用来源，不能把无样本来源计作训练覆盖。输出AUROC、正负成对排序/分差、探针分类BCE及逐轨迹结果；阈值或排序只属于探针，不改变原检测阈值0.5，不称Pd/Fa、实际检出恢复或U预算成绩。

## 已知几何覆盖限制（无特征和读出效果）

训练14,869个严格小目标帧中，共支持只有45条目标—参考边、43帧、15轨迹，来自8个来源中的3个。开发5,200帧中，共支持19条边、18帧、9轨迹、2来源；均属于冻结低响应集合，原双成功保护集合没有覆盖。完整分母及逐来源见`geometry/COVERAGE.csv`。这不是模型或读出效果，是严格同范围P2在r2和GT+2条件下难以存在的几何限制。

本轮读出只能报告这18帧的条件性测量；即使P1不优，也不能据此证明整个4,342低响应集合的同层参考没有价值。没有共支持的目标无法接受此三条件比较，不得填零或将其当负例。覆盖不足已经登记；本轮仍执行这个固定子集的描述测量，不补样本、不扩范围、不另开探针。结果不触发对全部4,342低响应对象的信息路径停止判断。

**表征混合限制：** P2称“标注框外区域参考”，不称纯背景特征。layer1前已经空间与时间混合，空间感受野半径约9，超过2像素背景缓冲；P2即使在原图几何上避GT+2，特征仍可能含目标信息。P1≈P2不能直接等同“对应无用”，还可能是当前层局部表示共享目标或上下文；不因此新增实验或改变本轮范围。
