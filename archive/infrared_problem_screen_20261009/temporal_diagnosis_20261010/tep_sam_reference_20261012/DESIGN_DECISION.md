# 一页设计决策：TEP-SAM 冻结权重参照

**决定：本轮结题，不启动 DeepPro-Plus 上的机制迁移设计或训练。** 保留研究目标；E2 及当前局部跨帧聚合的关闭决定不变。

固定作者 NUDT-MIRSDT 权重、seed46、两开发片段全部320帧、5200个小目标帧／130轨迹、阈值>=0.5。原生100帧运行检查通过；完整开发预测及原匹配口径均可复核。

| 决策问题 | 实际证据 | 判断 |
|---|---|---|
| 是否真的恢复原失败 | 4342低响应中恢复407帧，47轨迹／2片段；其中363来自极低响应子集 | 有实际恢复，不抹掉此观察 |
| 是否改善持续漏检 | 相对 S：28轨迹最长漏检缩短，16变长，86不变 | 收益与退化共存 |
| 背景能否接受 | U=4878>4015；框外前景235205，为 O 的6.13倍；未匹配组件面积289892，为 O 的6.41倍 | 未通过 |
| 原成功能否保持 | 原646双侧成功只保留304，丢失342；相对 S 新增451但丢失393 | 明显保持损害 |
| 辅助头能否缩小机制范围 | 低响应恢复580，但U=72991；与主输出共同恢复125 | 未形成背景受控分支证据 |
| 是否跨来源一致 | 0026 M=165，低于S的300；0067 M=613，高于S的420。407恢复中371来自0067，前五轨迹占280 | 不能主张来源一致的总体改善 |

**支持的结论：** 发布 TEP 完整输出确实可以匹配一部分 DeepPro 全已测窗低响应对象；同一冻结检测问题存在跨模型成功集合差异。这些恢复不是小样本 AUROC 的替代推断。

**尚不支持的结论：** 时序编码器提供了可直接迁移、背景受控的恢复机制；SAM 提示或空间预训练是收益来源；某个运算就是原漏检根因。主辅输出的联合匹配也不是一个可部署系统的成绩。

**下一步执行边界：** 本轮到此结束，零次检测器训练；不改阈值或权重挽救，不补训辅助读出器，不自动再跑模型，不重开 E2。新的提案仍需额外且可区分的机制证据，但这不是本轮追加待办。这里停止的是这套参考设置对“立即迁移”的支持，并未否定全部 TEP 权重、工作点、背景建模或时序表征路线。
