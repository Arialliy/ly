# 原生 logit 的目标与背景比较

`build_low_response_objects.py` 只读取冻结缓存和本轮补导出的原生 logit。它保留旧概率与匹配，不改变检测阈值，不调用模型，也不反算 sigmoid。所有新统计遵守父目录 `PROTOCOL.md`。

- `LOW_RESPONSE_OBJECTS.csv`：两片段 5,200 个目标帧 × O/S 两安排，共 10,400 行。
- `SCORE_SEPARATION.csv`：表一，7 个冻结组 × O/S × 合计/两片段，共 42 行。组可重叠，不可相加。`valid_ge20` 为对应背景至少 20 个块的主分母，`all_nonempty` 为至少 1 个块的辅助分母；四格比较使用两类背景都满足条件的交集。
- `REFERENCE_SELECTION.csv`：每个轨迹仅按几何有效帧数选择的固定背景偏移，包含全部 16 种候选的有效帧数。选择不读取响应。
- `COLUMN_SCHEMA.json`、`VALIDATION.json`：字段清单和输入指纹、冻结分层/匹配/概率一致性断言。

目标与背景块均取相同整数裁剪尺寸区域的最大原生 logit。目标框采用原 pixel-center 半开区间裁剪；局部网格以目标裁剪左上角为锚，全图网格以图像 (0,0) 为锚。所有有正面积且与画面相交的标注框（包括 ignore）外扩 2 像素，背景块不能碰该排除区。网格是不重叠的固定采样，所报分位数不是全部可能背景块或检测器 ROC。

局部极大峰来自原生 logit 的 3×3 局部极大值。8 连通等值极大平台只计一个点，行优先破平局；**若平台任何部分触及 GT 缓冲区，则整个平台剔除**，不是仅按代表点剔除。高于目标和不低于目标均分别记录，此计数不是官方 Fa，也不是 0.5 下未匹配组件 U。

背景参照每条轨迹固定一个几何偏移。尺寸仍跟随该帧目标框；每帧记录是否完整落图且不碰标注缓冲。自身局部参照再排除背景参照块及其 2 像素缓冲；全图参照剔除与该块相交的网格块。因此背景参照不会直接与自身分数比较。其运动不是独立背景物体的真实轨迹，不能用相似运动直接证明目标归属。

`target_logit_peak_*` 和 `neighborhood_peak_*` 是诊断分数峰，`matched_peak_*` 才是旧 0.5 概率组件匹配峰。高响应 sigmoid 饱和平局可能使两者不同。框外邻域最高峰不自动等于目标定位错误，人工归属只在 `visual/` 的冻结样本中核查。
