# Object-level temporal response decoder: first controlled prototype

2026-10-12. Engineering protocol fixed before development inference. User request is archived in USER_REQUEST.md. Hypothesis, not a demonstrated failure mechanism or established novelty.

- Backbone: unchanged frozen released DeepPro-Plus (70913 parameters), all parameters and BN buffers frozen/eval. Reuse exact input normalization, legal 40-frame windows, original 128px crop exposure. New independent response; no original-output residual, union, thresholded query generation, interpolation, or GT at inference.
- Common architecture: raw encoder 1→8→8 (two 3×3/ReLU), concatenate frozen 8-channel feature, project 16→32. Absolute original-image xy positional encoding; crop origins retained. 100 queries on fixed 10×10 full-image anchors (training max 79 canonical / 91 numeric identities per legal window). Two d32/4-head/FFN64 decoder layers, spatial cross-attention to stride4 pooled image features and optional same-query temporal attention. Zero dropout. Dynamic 32-channel mask readout plus existence logit. Independent output max_k(sigmoid(a)*sigmoid(m)).
- R0: new temporal interaction OFF, frame assignment. R1: ON, frame assignment. R2: ON, window track assignment. All receive the same initialization and original temporal features; R0 is not a single-frame detector. R2 adds identity supervision, not extra parameters.
- Labels: original author key (sequence, category_id, str(tracking_id)); original numeric evaluation track ID unchanged. Reuse already registered bbox-derived floor(255*Gaussian)>0 support, sigma=w/6,h/6, bbox truncation, core9 eligibility, all-GT guard2 exclusions. Not continuous Gaussian regression, author mask reproduction, or physical centroid. Five direct logit terms coefficient1: existence positive/negative, matched spatial positive/instance negative, unmatched physical-background negative. Separate means; four windows equally weighted. All configurations share conservative unknown/negative eligibility. Details in LOSS_DESIGN.md and tested targets.py/losses.py.
- Exposure: old immutable 512-step plan repeated four times, exactly 2048 updates / 8192 window exposures. No new randomly sampled crops. Seed46; fresh Adam lr1e-4, wd1e-4, betas(.9,.999), eps1e-8; FP32, deterministic, no AMP/TF32. Four sequential microbatches divided by4 before one optimizer update. All newly introduced parameters trainable except unused temporal parameters receive no gradient in R0. No scheduler, clipping or extra objective.
- Snapshots 0/512/1024/2048; main endpoint2048 only. Process snapshots are not selected against development results. Previous 512-step failures unchanged.
- Preflight: synthetic label/assignment/gradient checks, frozen-state checks, dense/chunk response equality, feature tiling equality. One finite train-only learnability check, 64 updates on a fixed positive window plus fixed empty window, R2 direct losses; this tests trainability and does not select architecture from development results. Reinitialize before formal training. Failure is recorded before any formal run.
- Inference: global shared query states computed once per full image window. Only local feature extraction and dynamic mask readout are spatially chunked. Full-image xy coordinates never reset per tile. Original temporal dependency and legal40 access retained. Tile core128/halo16; same global q reused for response chunks. Crop training exposes less surrounding context than full-image inference; coordinates are aligned but this distribution change remains a limitation.
- Development: unchanged two clips, 5200 strict-small object-frames, frozen4342 low/4170 extreme/646 protected. O=[0,36,72,108,120], S=[0,24,60,96,120], threshold0.5, original probability max and component/point matching. U≤4015 is diagnostic component budget, not official Fa; also report outside-box foreground and unmatched component area. No GT-triggered output processing or threshold tuning.
- Decisions use actual restored/lost sets, longest missing runs, multi-track/source support, background and protected set. R2 must add value over R1 and R0; accept a simpler effective control. A further 1–3 near-threshold recoveries is not sufficient to start confirmation. If all fail, stop prototype; no rescue modules, extra steps, new threshold or selected snapshot. Extra seeds/new-source confirmation only after substantive positive evidence.
- This is controlled engineering screening on reused development sources, not independent test or official training reproduction. BC-TPro/E2/N2 remain closed.
