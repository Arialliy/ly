# 第一阶段设计决策草案

日期：2026-10-10。状态：**供主线程依据数据可用性冻结，尚未作为训练执行协议；没有新性能结果。**

## 1. 暂定选择与理由

**优先检验“同帧跨真实窗口的困难正样本监督”，把“局部投影 + 内容条件门控”保留为第二候选。** 只保留这两条路线，首次试验不将它们叠加。

顺序依据是：自然窗口诊断直接提供“同一目标帧在不同上下文下，一路明显更难”的可训练结构；而现有 24 个内部抑制案例用的是两窗共同槽，并未证明固定近邻路径已经足够可靠。先检验监督更少依赖未验证的局部充分性假设。它不证明训练不足是根因，也不意味着模型改动不值得研究。

**冻结条件：**数据审计须确认原标签或一个可比、可追溯的替代监督版本，且有独立确认场景。若这些条件不成立，应记录具体缺口并继续获取或修正协议，不以伪造 mask 或开发集训练来取得正结果。若固定局部检查提供更强模型证据，允许在查看确认集结果前调整主次。

## 2. 候选 D：同帧跨窗口困难正样本监督

复用[既有完整设计](../mechanism_followup/IDEA.md)，保持原网络、40→40 输出和原最大值推理融合。

同一真实目标帧放入两个连续 40 帧窗口 A、B，空间增强同步。两路都有原检测监督；在真实正像素上，给同一目标较差一路更强监督。设每目标原标注支持为 `M_i`，正 BCE 为 `l_i,w^+`，则：

```text
L_D = 0.5 * (L_official(A) + L_official(B))
      + lambda * mean_i max(l_i,A^+, l_i,B^+)
      + mu * 0.5 * (L_background(A) + L_background(B)).
```

用 logit softplus 实现正 BCE；无合格目标时该项为零。两窗高分不作真值，双低但真实可见的目标也不被高分教师过滤。所有配置共用背景处理及目标支持。若作者训练 mask 缺失，只能在显式标记的框/点监督变体中比较全部配置；公开框不自动等于像素真值，也不得以实心填框结果冒称官方复现。

训练内部层保留当前帧 ±8 原图邻域，边界层单独保留真实窗口截断；使用训练划分的真实窗口，不从四个诊断片段挖训练样本。覆盖比例、起点差、每轨迹采样上限和可见性规则在执行协议中冻结。

**可被否定的预测：**在相同误报约束下，困难一路新增漏检减少且有利上下文的已有检出保留；并相对普通 OHEM 或 mean 对照呈现可复核差异。若仅整体分数提高、只超过发布权重却不超过同预算原配方，或与简单控制相同，不支持相应机制主张。

## 3. 候选 M：原 TPro 的局部投影与内容条件门控

### 3.1 与官方兼容的最小公式

对前端 `F[B,32,40,H,W]` 分成 8 头，每头 4 通道。`W[h,t,s]` 和 `b[h,t]` 为原 `Linear(40,40)`；`u=(x,y)` 为像素。输出槽 t 的原投影为：

```text
q[h,c,t,u] = b[h,t] + sum_s W[h,t,s] * F[h,c,s,u] / sqrt(40)
```

先固定一个与 GT 无关的近邻集合 `N_r(t)={s: |s-t|<=r, 0<=s<40}`，分解为：

```text
L[h,c,t,u] = b[h,t] + sum_{s in N_r(t)} W[h,t,s] * F[h,c,s,u] / sqrt(40)
C[h,c,t,u] = sum_{s not in N_r(t)} W[h,t,s] * F[h,c,s,u] / sqrt(40)
q = L + C
g[h,t,u] = sigmoid(MLP([F[h,:,t,u], L[h,:,t,u], C[h,:,t,u], L[h,:,t,u]-C[h,:,t,u]]))
q_new = L + g * C
```

一头的输入描述 16 维，1×1 MLP 给出每头、每槽、每像素的一个门，共享给该头 4 通道；8 头参数分别学习或统一共享须在实现前固定，首版建议分别学习且不引入时空卷积。此处不要求候选框、不用测试 GT、不新增输出槽，不把它命名为 attention。

接入点为原 TPro 线性投影之后、`norm1` 之前；后续 BN、ReLU、TPro 点式卷积和检测头保持原顺序。`b` 仅进入 L 一次且不除 `sqrt(40)`。原有有符号权重保留，不能照搬其他方法的 ReLU 去截断原矩阵负权重，因为它们也可能承担背景抑制。

### 3.2 可验证的不变量与不能保证的性质

- **强制 g=1 时，数学上精确恢复官方 q。** 工程可实现为 `q_new=q+(g-1)*C`，并在硬覆盖 g=1 时直接走原 q 路径，避免“拆分重加”的浮点求和差异。必须用原 checkpoint 和同一 FP32 输入验证最终 logit/概率；不能仅看标签是否相同。
- **强制 g=0 时，q_new=L。** 它回退到局部投影，仍包含前端 ±8 帧上下文；不是单帧模型。硬覆盖可直接返回 L，明确浮点对照。
- 有限参数的 sigmoid 不能恰好输出 0 或 1。正式门初始化接近 1，并不等于精确恢复；若要保持初始函数相同，需另外规定可精确置 1 的参数化/暖启动并控制所有比较。两个硬覆盖只用于不变量和局部检查。
- 残差/近邻保留不提供目标分数下界。后端非线性、通道混合、局部分支自身不足和门判断错误都可能产生漏检。
- r 固定也不提供跨窗一致性：原 W 的槽位行仍变化，边界会截断近邻；局部分支还依赖原图 `[t-r-8,t+r+8]`。必须按内部/边界分层。
- 一个门只能抑制该头已聚合的整段 C，不能分开 C 内同时存在的有益和有害帧。若这成为明确失败来源，才考虑逐帧关系门；不首轮计算全部 40×40 密集关系。

### 3.3 该接法的证据缺口和前置检查

`N_r(t)` 与此前两窗交集是不同集合；非重叠窗口成员也不等于远帧。不能用 24 个抑制例子证明上述 L 可用，或把 r 设成某个数当作已找到机制。

首个有限检查可预先指定 **r=0**：局部路径只含当前特征槽，但该槽已看见 ±8 原图帧；这是最小可解释端点，而非已验证最优半径。对原开发分层及完整背景场景，比较 `g=0,0.25,0.5,0.75,1`。冻结 r 和五个常量后再读取结果；不可按每个测试 GT 选择门。该检查只回答“这个接口有无可保留证据与固定缩放权衡”，不产出新模型性能或可部署 oracle。

若局部路径几乎没有可恢复的真匹配，或缩放收益主要来自放大背景，本次固定局部设计缺少优先训练依据；保留该负结果，继续 D。若同一固定接口在不同空间位置呈现确实不同的最佳权衡，且有可追溯真匹配，则可以进入 M 的内容门训练。无需要求 g=0 总体优于 g=1；门的用途本来就是保留 C 的收益。

文献对应：RFR 为相关性调制对照，TF-Blender 为位置相关条件化提供依据，NeurIPS Gated Attention 提供聚合后控制写入幅度的原则。上述具体公式是**本项目适配候选**，不是三个原论文模型的复现，也没有已验证红外收益。

## 4. 必要控制：按主张选择，不把差异包装为结论

所有训练从相同初始化出发、相同数据版本与预处理，固定优化器、更新次数、曝光量与 checkpoint 选择规则；实际 FLOPs/显存/时间另外报告。若预算维度无法同时相同，明确各维度差异，不能仅用“同 epoch”冒称同预算。BN 更新/冻结规则全部统一。

数据路线优先时，建议冻结以下五个训练配置；发布 checkpoint 是额外的零训练参照：

|ID|网络与输入|额外正项|解决的比较问题|
|---|---|---|---|
|D0|原网络，同预算原采样和原损失；两个 forward 的梯度累积以匹配曝光|无|发布权重 → 更多训练的影响。|
|D1|原网络，同帧配对|两路 mean + 相同背景项|与 D2 仅改变较弱一路加权。|
|D2|原网络，同帧配对|同目标 max + 相同背景项|主候选。|
|D3|原网络，与 D2 完全相同两窗及 2N 个目标窗项|跨目标选 top N 普通 OHEM + 相同背景项|困难加权是否只是普通难例挖掘。|
|D4|原网络，非配对两窗；目标数、轨迹曝光匹配|mean + 相同背景项|与 D1 检验配对数据组织的额外价值。|

这里 D3 与 D2 梯度都选择 N 个目标窗项，不能一个选 top N、另一个监督 2N 而把差异全归为配对。D1/D4 的配对解释还受可匹配样本分布影响，应记录匹配误差。D0 和 D1 的差异同时包括采样和额外监督，不能仅靠它们证明哪一项有效。

模型路线若被前置检查提升为主候选，采用同一原监督、同一数据流和原配方控制，另需：

|控制|与内容门一致之处|区分什么|
|---|---|---|
|M0 常量门|同一 L/C、训练参数范围与输出协议；每头一个可训练常量门|收益是否只来自整体缩放/正则化。仅拿推理期扫常量与重新训练动态门相比不足以排除该解释。|
|M1 内容门|按上式读取当前、局部、实际上下文|候选内容选择是否优于常量门。|
|M2 容量控制，按需|相同参数量的点式残差适配或同门网络但上下文描述跨样本打乱；选择一种预注册|若要宣称上下文条件化而非新增容量/通用适配，需要该控制。打乱输入有分布改变，只能作为辅助。|

第一阶段不需把 D0–D4 与 M0–M2 全部一次训练。优先 D 的五配置并做 M 的零训练前置检查；结果要求转向 M 时，再冻结替代小批次并记录预算变化。4–6 配置是控制规模的目标，不能为了凑数字省去支持实际主张所必需的控制。若只完成较少控制，结论相应限于经验可行性。

## 5. 共同验收与退出条件

1. 先对齐作者评价协议；若尚不能，使用明确命名的诊断匹配和未匹配组件指标，不称官方 Pd/Fa。
2. 在校准场景确定每方法阈值、共同误报约束和有利样本允许退化容差；确认集不参与这些选择。报告整条检测—误报曲线以及预注册操作点。
3. 对比官方原融合与同预算原配方，报告新增、丢失、净检出、连续漏检和原有受益样本保留；24/42 是开发诊断分层，不是统计独立确认集，也不要求其全部修复。
4. 固定四类开发诊断层：内部抑制、上下文受益、稳定高、778 持续低；确认集按冻结规则重新分层，不根据新方法输出挑容易展示的例子。
5. 双低带来的稳定、抬高背景换取高响应、只有开发案例改善、不超过同预算基线、明显丢失有利上下文检出，均不通过正向验收。
6. 若 D2 与 D3 等效，记录普通困难挖掘已足够；若 M1 与 M0 等效，记录固定调制已足够。已有或简单方法有效是可交付结果，不是需要隐藏的失败。

通过时收敛一个主 idea 和有限初步证据；未通过时给明确负结果或尚缺数据/控制的结论。这里仅冻结选型逻辑，不预写第一阶段性能结论。

## 6. 数据审计反馈后的接口修订建议：弱框监督版本

主线程反馈原 RGB-T Gaussian/segmentations mask 及其生成参数尚未找到，本地公开标签是 bbox/矩形 polygon；若后续仍不能取得原 mask，可采用下面明确命名的**弱框监督微调协议**。这是对候选 D 的监督接口修订，不是旧像素 mask 版本已经运行，也不是官方训练复现。实验开始前应由正式 `DESIGN_DECISION.md` 与 `PILOT_PROTOCOL.md` 固定最终选项。

对训练框 `B_i` 与当前帧 t，取 logit 的框内最大值：

```text
s_i,w = max_{u in B_i} z_w(t,u)
ell_i,w = softplus(-s_i,w)
L_negative,w = mean_{u in background(t)} softplus(z_w(t,u))
```

`background(t)` 必须排除该帧**所有标注目标框**的并集，包括非小目标、重叠框、没有入选正项的目标以及裁剪后可见的框区域。正项不能仅选高 checkpoint 响应目标；也不能把未选入训练正项的已标注对象当背景。对裁剪边界的完整/截断目标规则、背景安全边距、采样或全像素均值规则均需固定，不按候选效果改变。

采用 MIL（多实例正标签）意味着“框内至少一处应有响应”，不要求框内每个像素都是目标。其主要风险是最大值来自框内背景、边缘或其他热源；两窗的峰也可能落在不同位置。真实预测组件的诊断匹配、框内峰位置/偏移、完整背景的未匹配组件都要检查，不能把本身优化的框内最大响应作为唯一验收。缺少真实像素 mask 时，不能宣称学会了正确目标形状或复制了作者 Gaussian 标签。

统一框监督的三个直接控制为：

```text
paired_mean = sum_i(ell_i,A + ell_i,B) / (2*N)
paired_max  = sum_i max(ell_i,A, ell_i,B) / N
ordinary_OHEM = sum(topN({ell_i,A, ell_i,B}_{i=1..N})) / N
```

三者使用同一 batch 的相同 2N 项、相同原图窗口、增强及负项。每对象先独立计算一个标量，随后对象等权平均，避免大框因正像素更多获得更多权重。三者正项总标量权重相同；mean 的每项梯度系数为 `1/(2N)`，max/OHEM 为被选中项的 `1/N`。这控制了正项总权重和 max/OHEM 的选中项数量，但不保证实际梯度范数相同，也不应该声称如此。

原发布权重仍是主要外部参照。继续训练的公平控制此时应叫**相同弱框监督的同预算微调控制**；不能写作已复现原 SoftIoU 配方。若像素 `L_official` 不可计算，应在所有对照中一致替换并明确公式，不保留名义上的 `L_official` 而暗中用填框标签。

关于非配对控制要特别避免恒等实验：对同一批 2N 损失仅改变配对关系，mean 数学上不变。可根据实际主张选一种不同控制：

- **独立非配对采样 + mean：**真正更改两路窗口/当前帧抽样，匹配训练序列、目标尺度、对象数、轨迹曝光和总 forward；它检验同帧重复曝光/配对数据组织，需记录抽样边际差异。
- **随机重配 + max：**同一批 2N 目标窗项随机组成 N 对，并禁止原同目标两路相配；每随机对取 max。它与 paired-max 共享精确图像曝光和选中项数，检验“同一对象两种上下文”的配对结构是否比任意分组更有用。它不是独立非配对采样，不能混称。

普通 OHEM 与以上配对结构控制仍不相同：前者全局选最难 N 项；后者每个组只选一路。首轮可先运行 paired-mean、paired-max、OHEM 加原发布权重，并按拟作主张补一个真正有辨别力的数据控制；这比重复无效的 mean 重排更可靠。

该修订仍针对真实同帧上下文的弱一路，研究问题与核心采样不变；但弱框监督本身会改变可证明的范围，必须与原像素监督 idea 的结果分别命名和保存。不因缺 mask 转去不同数据域以换取容易运行的正结果。
