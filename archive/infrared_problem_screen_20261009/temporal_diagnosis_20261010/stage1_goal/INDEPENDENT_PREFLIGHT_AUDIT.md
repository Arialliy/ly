## Pilot 实现只读审查

- **MIL：** `losses.py:10` 使用 `softplus(-amax(box_logits))`，没有把矩形填成像素正标签。共享底正项先在窗内对对象帧平均，再对四窗平均；负项逐窗背景像素平均后四窗平均，与协议一致。
- **监督边界：** `train_pilot.py:244` 只在 `[9,119)` 空间 core 监督；所有合法框，包括非小目标、其他类别及 ignore/crowd 框，都从背景中排除并扩张2像素。正框须完整落在 core。对于已审计半径9的原模型，core 足以避免人工空间裁剪边界进入被监督像素的感受野。
- **额外正项：** 两路使用同一 anchor 绝对帧、共同 crop，slots 为 `anchor-start`；额外对象取该帧 core 内全部合法、无重叠且最大边≤16的框。N<2时四组统一关闭额外项。
- **随机配对：** 独立 RNG 不影响图像采样流；每个2N项使用一次，禁止同原对象帧的两路重新成对。随机对先逐对 max 再平均，代码并未实现为普通 OHEM。
- **BN：** 全模型参数及 BN affine 均可训练；`model.train()` 后所有 BN 进入 eval，每次更新后精确核对 running mean/var/counter。该实现可以执行共享 BN 控制；实际运行是否通过须以运行日志确认。
- **同预算控制：** 脚本检查 plan、数据及选择哈希，严格加载权重并新建 Adam。四次实际调用的 lr、初始化权重与脚本哈希是否相同，仍须对照四份 `RUN.json`，当前没有这些运行证据。
