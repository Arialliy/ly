# 原结构监督对齐近似控制：匹配增加，背景控制未通过

完成日期：2026-10-12，北京时间。训练前规则：[PROTOCOL.md](PROTOCOL.md)，代码及检查绑定：[PROTOCOL_FREEZE.json](PROTOCOL_FREEZE.json)。

**一次固定512步控制已完成。Gaussian派生二值标签＋官方Soft-IoU有效域适配，使原DeepPro-Plus的O/S匹配增加到1,568/1,656，但未匹配组件升至19,048/19,446，框外前景和未匹配组件面积也大幅增加。它没有建立可靠的训练基础，不能用总匹配上涨宣称解决了检测问题。**

按预注册判定，本轮属于“原结构仍出现背景退化”：不将其升级为新训练基线，不宣布监督根因已找到，不在本结果上启动结构扩展、确认实验或参数扫描。BC-TPro首版继续保持[未通过、停止扩展](../bc_tpro_pilot_20261011/STOP_DECISION_20261012.json)，不因监督变化自动重跑。

## 1. 官方成绩与本轮目标的区别

官方发布权重在NUDT-MIRSDT完整20序列/2,000帧上的推理已复现：本地Pd99.710816%、Fa2.689157×10⁻⁵、AUC0.9977783921，与[论文表VIII](https://arxiv.org/html/2506.12766v5#S4.T8)的99.71/2.69/0.9978在报告精度一致。不是从头训练复现。原记录见[官方推理报告](../../official_reproduction/REPORT.md)。

论文在真实RGBT-Tiny选定场景上报告的Pd是77.83%（表X），不是99.71%。本项目两个真实开发片段、严格小目标、峰值点入框诊断又是不同口径。不能拿M/5200与论文Pd直接比较，也不能以合成基准高分否定特定真实条件下的失败。

本轮检查的不是“能否刷高M”，而是原结构在替换监督后能否保持实际检出并控制背景；剩余的低响应、原成功丢失和窗口依赖才是后续候选研究对象。对这两个用户问题的完整说明见[复现与研究范围](REPRODUCTION_AND_RESEARCH_SCOPE.md)。

## 2. 实际改变了什么

保留发布权重对应的原DeepPro-Plus，70,913参数，没有BC、新预测头或任何新增参数。复用相同8条训练来源、全部512步采样计划、seed46、原初始化、4×40×128²输入、Adam lr1e−4/weight_decay1e−4、FP32以及BN运行统计冻结规则。最终512步权重为唯一主检查点。

监督从框内max-logit正项＋top1%背景负项，整体替换为：

1. 原始浮点框几何中心；σx=w/6、σy=h/6；在像素中心采样，框外截断为0。
2. `floor(255*g)`量化为uint8，然后`>0`生成二值标签，多框max合并。
3. 沿用core9和原背景保护；完整正框纳入有效域，ignore/crowd/partial及其2px保护区优先忽略。
4. 每窗口gather有效logits和标签，直接调用冻结官方`SoftLoUloss`，四窗等权平均。该类内部sigmoid，smooth=0；没有重复sigmoid，也没有额外BCE、top1或paired项。

公开loader确实会把非零mask置1。因此本轮是**Gaussian派生前景支撑**，不是连续峰形状回归。作者精确Gaussian生成参数未知；本轮σ/量化/忽略域是预先冻结的近似，不能称原训练配方复现。已知官方二值化和内部sigmoid本身并不足以证明代码错误。证据：[SOURCE_ALIGNMENT.md](SOURCE_ALIGNMENT.md)，实现：[gaussian_labels.py](code/gaussian_labels.py)、[train_supervision.py](code/train_supervision.py)。

标签/损失/有效域是一个监督组合改变，所得差异不能单独归因于Gaussian形状、IoU或某个梯度性质。

## 3. 固定0.5主结果：匹配与背景必须一起读

## 7. 明确停止点与研究决策

1. **本近似控制未通过，暂不作为结构比较的可靠训练基线。** 不能用1,656个匹配掩盖19,446个未匹配组件、336,695个框外前景像素及原成功损失。
2. **不能声称监督根因已确认。** 本轮只排除了“这一固定Gaussian派生标签＋masked Soft-IoU微调配方已足够修复背景控制”的可能；既不证明官方代码写错，也不证明所有监督对齐路线无效。
3. **当前不继续设计第二个模块，不重跑BC-TPro，不进入确认来源。** 下一阶段应重新评估当前适配设置能否构成公平训练基础；研究对象应是发布系统及可信训练控制上剩余的真实失败，而不是把我们微调制造的退化包装成官方时序机制缺陷。

两份问题材料仍保留：窗口选择造成的实际成功交换、全窗低响应的大组失败。当前没有证据将它们统一归为同一个机制，也没有因为更换监督就撤销原模型失败证据。只有在背景受控和原成功保持的条件下改善这些冻结对象，才有理由主张解决了研究问题。
