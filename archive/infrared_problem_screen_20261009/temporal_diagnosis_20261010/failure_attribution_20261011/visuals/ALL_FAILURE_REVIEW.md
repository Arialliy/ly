# 全窗口失败样本的独立视觉核查

实际逐个打开并查看了冻结的 **16 个全诊断窗失败详情 PNG**，另看了已冻结选择的 **4 个稳定成功参照**。本次核查由 `/root/failure_conditions` 完成，独立于 root 对全部 128 个增损对象拼图的审阅。没有重选样本，没有查看新来源或保留确认集，没有修改 `conditions/` 的任何冻结产物。

**这组图像支持把全失败再分成“局部结构可区分但响应弱”“局部结构本就难判读”“边界目标”和“高响应仍未定位匹配”几类待查案例。它不能支持把全部弱响应归因为不可见、遮挡、物理静止或错误标注。**

## 核查范围与读取边界

16 例是原定 12 例加记录在案的 4 例类别覆盖补充。详情面板含固定当前原图、原/新融合分数图、示例诊断窗、固定当前中心像素灰度曲线、各帧标注中心灰度曲线、标注图像坐标轨迹及参考访问范围。原图统一使用 0..255 灰度，分数图统一使用 0..1 色阶，未逐图增强对比度。

本次仅直接查看这些已生成详情图，未额外读取相邻帧原图。曲线为 8 位图像灰度，并非温度或目标可见性测量；标注中心轨迹不是物理运动轨迹。细图显示的是少量放大像素，绿色框本身还会遮盖部分边缘，因此对可见性、遮挡、类别细节和标注对错均保留判断边界。

**真实可见时长、遮挡、相机运动及物理运动均未定量确认。** 标注持续时间不能代替真实可见时间；“暗结构可区分”或“弱亮团可判读”只描述当前局部图像，不等同完整目标可见性的真值。

“高/低框响应”来自冻结数值表，而不是肉眼判定色图。全失败对象不存在成功诊断窗，面板中的两个示例窗位置可能重复展示首个失败窗；这不构成两个独立窗口证据。稳定对象若无失败窗，则展示最后一个可用窗。图中没有精确标注组件 row-major 峰，不能只靠彩色团的位置认定精确峰位、组件合并或匹配竞争。

- [0067 / 7702017 / 帧 35](DJI_0067_2_track7702017_frame035_ann870580.png) 和 [7701908 / 帧 64](DJI_0067_2_track7701908_frame064_ann873182.png) 也贴桥侧长边缘、局部轮廓不清，却有匹配成功的响应。后者框宽仅 3 像素。因此，桥侧纹理和窄框应作为核查定位稳定性的条件，不能被直接标成“不可检测”。

这 4 个参照由已有响应定义，不是独立自然对照；它们用于防止对失败图单向解释，不提供方法效果或因果结论。原冻结配对关系和逐图记录见 [STABLE_REFERENCE_REVIEW.csv](STABLE_REFERENCE_REVIEW.csv)。

## 这些图像对下一步的具体约束

1. 对局部暗结构清楚但弱响应的船轨，保留“目标结构存在而模型输出弱”的直接证据；先检查原输出的空间/时序响应及训练监督对应，不能先定为数据中没有目标或运动不够。
2. 对桥侧行人/骑行者，把长边缘、窄框和相邻目标作为候选定位条件。高框响应但失配的例子必须联查准确组件峰与框，不以框中有亮分数代替检出。
3. 对图像边缘或单点标注例，先核实原框与可见局部的对应。细图不足以判断遮挡、错误标注或任务是否本应检测，不宜据此改标签。
4. 本样本按序列、响应层、轨迹及类别补充确定性选择。**不能从 16 例计算 4,391 个全失败对象中“可见”“不可见”“错框”或任何视觉机制的比例。** 目前结果只是后续定量核查的线索。
