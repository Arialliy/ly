## 2. 全窗失败大多远低于 0.5

此处为固定诊断网格 `[0,12,…,120]` 中**覆盖当前帧的可用窗口**，不是每个对象都有 11 个窗口，也不是穷举所有可能起点。对每个对象先取各窗口框内最大概率，再对可用窗口取最大，记为 M。只分析全部可用诊断窗均没有实际点匹配的 **4,391 个几何小目标帧、123 条序列内轨迹**。

| M 区间 | 目标帧 | 占 4,391 | 涉及轨迹数 |
|---|---:|---:|---:|
| [0, 0.001) | 4,170 | 94.97% | 116 |
| [0.001, 0.01) | 68 | 1.55% | 37 |
| [0.01, 0.1) | 46 | 1.05% | 24 |
| [0.1, 0.5) | 58 | 1.32% | 29 |
| [0.5, 1] | 49 | 1.12% | 16 |

轨迹在区间之间可以重叠，不能加总为独立轨迹。累计 M<0.01 有 4,238（96.52%）；M<0.1 有 4,284（97.56%）；M<0.5 有 4,342（98.88%）。M 的 Q1=`1.75731e-6`、中位数=`4.31192e-6`、Q3=`3.40980e-5`；分位数采用 NumPy 默认线性插值。

0026_2 的全窗失败对象中 286/302（94.70%）的 M<0.001；0067_2 是 3,884/4,089（94.99%）。这是同一两段开发材料的描述性复算，不是新增独立来源验证。

这些数字说明：**大多数全窗失败不是分数恰好低于 0.5 的临界例，而是已测窗口中框内响应普遍很弱。** 但没有评估降低阈值后的背景预算，因此不能进一步声称阈值调整绝不可能改善；也不能从低响应直接推断目标不可见、训练缺样本或某个模型结构是原因。概率值亦未被证明是校准后的真实置信概率。

本层可用窗口数分布为：1 窗 695 个、2 窗 579 个、3 窗 2,228 个、4 窗 889 个。其中 **695 个只有一个已测窗口**，不能把它们作为跨上下文不稳定的证据。该层在问题规模统计中的地位是持续失败队列，不是增损交换队列。

原始累计表：[ALL_WINDOW_FAILURE_RESPONSE_CDF.csv](ALL_WINDOW_FAILURE_RESPONSE_CDF.csv)，互斥区间表：[ALL_WINDOW_FAILURE_RESPONSE_BINS.csv](ALL_WINDOW_FAILURE_RESPONSE_BINS.csv)，均含逐序列与类别；这些阈值沿用既有阈值，未按结果搜索最佳分割。
