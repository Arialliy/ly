# 局部参照时序证据 N0 / N1 / N2：固定筛选结果

2026-10-12。三组训练、两片完整画面推理、固定O/S评价及预登记位置错配辅助均已完成。本轮没有改变研究问题：恢复真实场景的持续漏检，同时约束背景代价和原成功丢失。

**首版收束，停止扩展：保留有限开发增量，但不将其确立为论文模型主线。** N2保留冻结小目标集合的全部原成功，但低响应仅恢复O2/S3个目标帧；相对普通差分N1新增的低响应是同一个对象帧。全部增益来自0067；4170个极低响应对象无恢复。N2没有缩短任一轨迹的最长漏检段。S有预算内真实增益，应保留；O超过既有预算，不能改写为通过。错配参照后唯一新增低响应对象仍然检出，辅助结果没有支持该收益需要正确位置的局部参照。

采用用户授权的独立原图证据分支，未修改DeepPro-Plus的唯一TPro。原70913参数和全部BN状态冻结，新分支1529参数。三种模式共享网络、初始化和通道接口；N0仅新增当前图像信息但仍读原时序H0，N1新增间隔1/4有符号差分，N2再加入方环局部median/MAD及相对差分。环内外半径5/7由训练尺寸规则固定，分母下限为1/47.4845；不使用开发响应调参。

三组seed46、各512步、相同2048窗口曝光，复用旧监督和归约。仅末层输出投影零初始化，Δz可正可负。主评估只用512；未选中间检查点。用户指定GPU2/3，实际GPU2有外部占用，全部本轮GPU作业顺序运行于GPU3，无中止外部任务。[冻结协议](PROTOCOL.md)、[工程规格](ENGINEERING_SPEC.json)、[源码冻结](PROTOCOL_FREEZE.json)保留精确定义。

## 本轮决策

保留以下两个层次：S下N2比发布模型、N0、N1多检出少量对象且保持原成功，这是实际小幅增量；然而增量只集中于单片段的阈值附近对象，当前持续漏检主缺口几乎不变，正确参照位置的辅助解释也未得到支持。结合背景成本和约1.43—1.45倍的当前运行时间，**不足以支持把局部参照升级为模型主线；本首版停止扩展**。

这是候选研究价值的综合判断，不是事后规定至少恢复多少帧，不是把两个安排同时过预算添加为新硬门槛，也不是声称所有差分/局部参照方法无效。N0、N1保留为本轮控制，不自动升为新候选。没有必要用错配作为另一种方法重新训练。

本轮到此交付：不追加训练、种子、确认来源、阈值调整、环半径/时间间隔/分母搜索或新模块。研究目标保留；新的方案需要不同于本轮的有效信息或约束证据，不能仅由本首版未达到主线要求自动触发。
