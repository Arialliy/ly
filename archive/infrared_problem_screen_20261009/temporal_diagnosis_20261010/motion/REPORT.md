# 固定真实序列的背景运动与标注核查

**范围：** VT-Tiny-MOT train2017/DJI_0028_2/01，原始帧173–332；开发诊断片段，非官方测试结果。只读取原图和原始标注，没有读取模型输出。

## 执行与预设规则

- CPU Docker 镜像 `deeppro-official-eval:20261009`，完整 image ID 记录在 JSON；OpenCV/NumPy seed=46。
- 相机诊断规则先写入 `PROTOCOL.json` 并保存 SHA256；使用全部标注框外扩8像素的背景，LK前后向检查和完整仿射RANSAC。
- 直接匹配 t→t+5，不累积变换；每个40帧块只统计块内35个lag5配对。全局拟合有效还要求目标中心位于支撑凸包内且最近内点≤160像素，避免远距离外推。
- 原始存在越界框，首次强度采样报错；保留错误日志，并在计算相机运动前补充 `PROTOCOL_BOUNDARY_AMENDMENT.json`：仅强度采样裁到画幅内，原始框、轨迹中心及所有配准参数均不改。

## 背景运动检查

- 155/155个全局配对通过预设质量门槛；内点数中位138，最少116；内点比最小0.9137。
- 内点凸包面积占画幅中位31.37%；各配对内点残差中位数的中位0.0878px，最大0.1376px。
- 支撑集中于远处岸线和近处前景，缺乏水面内独立锚点。单仿射只能作为共享图像运动近似，不能等同于校准后的物理相机运动，也不能完全排除视差。

## 重要的近邻/重叠条件

- 3800006与3800007在109/160帧标注框相交；最大IoU=1.0000，中心距离≤3px共13帧，最小中心距离0.000px。
- 原始帧264–272共9帧，两个不同ID的框完全相同（IoU=1、中心重合）。这9帧之后中心左右顺序交换。该候选不是干净的单目标加速片段；不能排除投影重叠、超越或ID分配歧义。
- 框内最大响应可能由同一个响应同时满足两个轨迹，不能把两次框命中计成两个独立实例检出。后续若做检测命中统计，必须保留一对一匹配和合并/分离错误检查。

## 结论边界

该片段可保留为真实序列中的图像运动变化候选。现有检查不支持将其原始位移变化全部归为共享背景运动，但也没有证明物理加速度，更没有证明DeepPro-Plus存在时序缺陷。与检测结果结合时，需要同时保留邻近重叠、对比度和尺寸变化这三个混杂条件。
