# 原始输出：按结果分层的探索性诊断

本报告只重算既有预测、原始框标注和图像/运动诊断。主分析是原始 T40/stride36/last-anchored、重叠取最大值的输出；阈值 0.5，清洁条件为框完整在图内且不与其他 GT 框重叠。低框响应定义为框内最大预测概率 < 阈值，与点匹配失败分开。所有计数的单位是目标帧，目标帧不是独立样本；没有逐帧显著性检验。分析规范是在看过主结果后固定，属于探索性分析。

**优先观察的能力缺口：在两个道路片段中，确有标注位置移动、框较小、相对环形背景均值更亮的目标持续或反复低响应；主要落在行人，但正的原始均值差常伴随较大的局部背景标准差。** 当前数据支持这种条件组合下的响应缺口，尚不能把原因归给运动融合、类别或训练缺样。静止/近静止船类提供了另外的失败条件，但两段 DJI_0028 可能来自同一拍摄场景，而且原任务针对运动目标，不能把这项边界现象写成违背原方法承诺。

## 能据此说到哪里

结果已经把可重复的失败条件缩到：两个道路片段的移动、小框、正原始差值目标，尤其是背景波动下标准化对比度不强的行人；以及同拍摄场景的近静止船类。现有数据还不能分离类别、外观、局部背景、轨迹运动和上下文的贡献。没有在这里建议或修改网络、训练数据、损失、阈值。官方训练标注中是否存在这些类别以及真实 Gaussian mask/检查点曝光须与父任务的数据覆盖审计共同解释，不能从漏检倒推“训练集中没有行人”。

限制：框标注不等于像素目标掩码，持续标注不证明每帧可见；负框减环均值差不等于热极性；四个片段预先筛选、两个船片段可能同场景；所有轨迹数均是原始标注 ID，缺帧/ID 碎片使独立样本数更小；原始响应是融合后的框内最大概率，可能受覆盖/饱和/形状影响，因此点匹配与响应始终分别列出。

```bash
python3 analyze_response.py
```
