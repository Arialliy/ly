# 多帧红外小目标：从已有单帧经验确定研究入口

日期：2026-10-09。当前任务来自用户最新选择：多帧红外小目标检测；过去主要使用 NUAA-SIRST、NUDT-SIRST；研究价值不能只来自 Pd/Fa 的小幅改善。

## 当前判断

保留单帧红外检测积累，优先寻找多帧方法在特定条件下的能力缺口。NUAA-SIRST、NUDT-SIRST 的独立图像不能直接充当时序验证。当前尚无新模型实验，不把论文结果称为本地复现。

### 入口 A：运动证据消失时，检测是否也随之消失？

- **已报告现象**：DeepPro 论文 IV-G 展示真实场景中的静止目标漏检，并解释固定图像位置的灰度长时间保持平台、缺少移动目标时序轮廓。作者明确限定其移动目标适用范围。[作者全文](https://arxiv.org/html/2506.12766v5#S4.SS7)
- **开源入口**：DeepPro / DeepPro-Plus，TPAMI 2026，DOI 10.1109/TPAMI.2026.3683258；[官方代码](https://github.com/TinaLRJ/DeepPro)包含模型、训练测试及权重。原生输出像素置信图，更接近用户原来的分割式 IRSTD 工程。
- **研究目标**：在保留弱目标检测和计算效率的同时，改善目标从运动变为近静止时的持续检测，并避免目标真正离开后继续产生残留响应。后两项时序行为目前没有本地测量，不能写成已有实验结论。
- **必须面对的已有解法**：DeepPro 已有引入空间计算的 Plus 版本；TDCNet 已报告静止/极慢目标测试。因此不能主张整个领域无法检测静止目标，也不能把增加空间分支或一般记忆机制直接视为新颖贡献。
- **先做什么**：复现官方推理；从真实序列中找到具有可靠可见性标注的运动变化片段；与单帧方法、DeepPro-Plus、简单时序平滑或检测加关联对照。确认错误是否与运动证据减弱有关，而非目标变暗、遮挡或标注消失。

### 入口 B：帧间隔改变后，时序模型为什么明显退化？

- **已报告现象**：TDCNet（AAAI 2026）补充 §5.4 的跳帧对照中 AP50 从 93.83 降到 83.12。[作者全文](https://arxiv.org/html/2511.09352v2)
- **证据边界**：跳帧同时改变目标位移、背景错位和时间跨度；不能把损失全部归因于配准误差。该方法 §5.3 还报告了静止/极慢目标的较好结果。
- **代码条件**：[官方实现](https://github.com/IVPLabs/TDCNet)要求背景对齐前处理。检测器与对齐成本应一起核算；原生框检测指标不能直接与像素方法的 IoU 混比。
- **研究目标**：在帧率变化或历史信息变差时，保持当前帧检测能力；进一步测出何时历史真正有帮助、何时引入错误。不能先认定必须增加门控或配准模块。

## 多帧评价要补什么

保留原方法的标准指标和实现，同时增加与所选问题对应的诊断：

| 能力 | 建议测量 | 必要约束 |
|---|---|---|
| 持续检测 | 每条目标轨迹的连续漏检长度分布 | 只统计标注可见且属于检测任务的时段；需可靠身份或匹配 |
| 状态变化恢复 | 运动变化或短暂遮挡后的重新检出时间 | 单列完全不可见时段，不能要求从无证据帧检测目标 |
| 及时清除旧响应 | 目标离开后的残留误报持续时间 | 要有离开事件和充分标注，不把未标注目标直接当背景 |
| 公平的时序收益 | 同一当前帧的单帧与多帧配对结果 | 固定训练预算、当前帧和计算成本口径；说明能否访问未来帧 |

逐帧总指标对错误时间顺序不敏感：同样十次漏检，零散出现和连续出现可以有相同 Pd。这个定义上的差别支持补充时序诊断，不证明任何模型已经存在严重连续漏检。

## 数据与实施次序

1. 原 NUAA-SIRST、NUDT-SIRST：保留单帧基准和空间分支对照。
2. NUDT-MIRSDT 等序列数据：用于原方法工程复现，严格采用各自原生协议。
3. 真实连续视频：用于实际问题验证。DeepPro 的 RGBT-Tiny 红外子集是一个入口，但它由框生成粗掩码；不能把这些粗掩码当精确像素真值。IRSTD-UAV 切段划分不能自动代表未见场景泛化。
4. [MIST，TIP 2026](https://github.com/ShuCvlab/MIST)：复杂运动补充诊断，作者采用合成目标与真实背景，不能代替真实视频证据。数据、代码和权重入口公开。

建议先深入入口 A 的 DeepPro-Plus，理由是自身失败分析明确、代码权重可得、输出形式接近现有经验。入口 B 作为有直接量化证据的备选。最终研究问题和具体方法尚未冻结；本轮不启动训练。

完整原文抽取及数值边界见本目录各 source audit 与 temporal_evidence 文件。
