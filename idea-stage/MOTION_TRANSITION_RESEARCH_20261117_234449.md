# 动静转换中的红外小目标检测：专题调研与研究设计

调研日期：2026-11-17。范围：先不考虑会议，比较两个题目的关系，核验既有实验、数据与可能的贡献。沿用 idea-creator 的文献查新和独立审查流程。本轮是调研与设计，没有新训练、推理或真实停走人工标注；既有先导统计不升级为新结论。

## 1. 两个题目相交，但不是同一件事

| 表述 | 核心问题 | 需要承担的额外任务 |
|---|---|---|
| 运动—停止转换中的检测偏差，以及缺失观测下的证据积累 | 运动证据或当前观测减弱时，如何判断目标是否仍存在 | 遮挡、低对比度、丢帧、离场；存在推断、记忆保留与删除 |
| 面向动静转换的红外小目标视频检测：运动依赖诊断与稳健训练 | 当前目标仍可见时，检测器是否过度依赖运动，以及怎样修正 | 受控诊断、训练分布与表示机制的区分；不必增加跟踪器 |

建议先以第二个问题为主线。工作题目可收敛为：

**红外小目标视频检测中的动静转换：运动依赖诊断与转换稳健学习。**

这里“偏差”尚是假设。更严格的任务定义是：对属于目标类别、在当前红外图像中具有可评价可见性的目标，移动与停止期间均要求检测；运动检测算法若本来只定义移动前景，不应仅因不报静止物而被判错误。

静止、动态、缺测也不可混为一谈：
- 目标停止：运动状态改变，当前图像仍可能提供有效证据。
- 部分遮挡、低对比度：观测质量降低，仍可能存在弱测量。
- 完全遮挡：存在可推断，但当前位置未必可直接验证。
- 传感器丢帧：没有本次测量，时间仍向前推进。
- 目标离开视野：当前视野内不应继续输出目标；不等于物理目标消灭。

需同时区分像面位移、背景补偿后位移与物理运动。摄像机跟随运动目标也会产生低像面位移。主张应限定在实际测得的运动坐标系。

检索结论限于：**本轮核读来源中，尚未核实一篇完整覆盖“固定当前帧、改变停止历史、事件对齐曲线、训练病因区分、真实跨场景验证”的红外小目标检测研究。** 这是候选组合空缺，不是全球首次的证明；其中每个工具或单项实验都可能已有先例。

检索词覆盖 stationary/static、stop-and-go、zero velocity、moving-to-stationary、frame repetition/freezing/shuffle、motion bias、counterfactual history、occlusion、missing observations、Bernoulli/TBD，以及各数据集作者来源。

## 3. 可能的创新：先提出可被推翻的机制解释

### 3.1 推荐主假设

在当前目标仍可见、尺度/局部对比度/背景尽可能匹配时，部分视频检测器在运动转停止后会出现额外漏检；这一效应可能与训练中的运动状态覆盖和时间表示的有限支持有关。

**最值得检验的具体预测：停止后的退化是否跟“最后一次有效运动信息离开时间窗口”同步，而不是仅跟当前图像变暗同步？**

如果时间窗口改变，退化位置也相应移动；如果补齐停走训练仍存在这一现象，才更支持表示机制的解释。反之，均衡训练即修复，应把结果归因于分布覆盖，不能强行包装为新记忆结构的必要性。

本地 TPro 在时间轴上使用 nn.Linear(seqlen,out_len)，见 [TPro.py](../sources/official_deeppro/networks/layers/TPro.py:20)。因此固定时间支持是可测对象，但它并不数学保证“停止40帧必然漏检”。网络含空间信息，实际退化必须测出来。

### 3.2 两条可以分开的贡献

1. **机制与评价贡献**：建立真实停走事件集和受控轨迹对照，定位超出外观变化能够解释的运动依赖；揭示停止持续长度、历史支持与恢复行为之间的关系。
2. **训练贡献**：如果证据支持训练偏差，形成可迁移的转换训练协议；如果简单增强无法解释，再设计对应的最小读出改动。

“加一条静态分支”“加门控记忆”“提出反事实损失”“把检测器接跟踪器”本身均不足以区分上述近邻。训练方案是否具有独立创新，取决于比等量普通增强、组重加权和现有记忆方法多解决了什么。

## 4. 建议怎样展开实验

下述为研究设计建议，尚未冻结、执行或产生结果。

### A. 真实事件诊断：先确认我们测的是停止

从现有 train/dev 筛候选，再人工核验完整时间线。首轮目标可设为至少30个独立事件、覆盖至少5个原始场景组；这是可行性目标，不是已经发现的样本数量，也不是统计功效保证。若不够，补外部数据或采集，不能用高度重叠窗口凑数。

事件包含：持续移动、动→停、停→动、动→停→动、从片段开始即静止、短暂遮挡、离场。不要按模型低分挑主评估样本。需要记录目标尺寸、局部SCR代理、遮挡状态、相机运动、停止长度及定位不确定性。

以停止时刻为零，画每个事件及场景平均的“检测概率/匹配召回—相对时间”曲线；同时看停前已经漏检的事件，避免只选容易的成功轨迹。

### B. 受控干预：固定当前帧，只改变到达当前帧的历史

1. 使用独立的目标层与背景层，构造到达同一当前位置的不同历史：持续移动、短停、长停、停后重启。
2. 共享当前帧、当前目标信号、尺寸、点扩散形状；保持背景视频与噪声过程可控，跨多个背景及噪声种子重复。
3. 单独改变停止持续时间，例如4/8/16/32/64帧，再独立改变SCR、相机运动和遮挡。
4. 加入同处理流程的目标缺席样本、固定热亮点、曾经有目标但现已离场的负例。

不能冻结整帧来替代真实停止：这样连背景、噪声与压缩误差都冻结了。合成中的“保持相同”只在渲染模型内成立，不能自动推广为真实世界因果结论。自然序列匹配与真实再标注必须验证趋势。

固定当前帧但改变历史，本来就可能改变合理的后验概率，所以“两个分数不同”仅证明历史依赖，**不能单独证明有害偏差**。还需检查可见帧任务损失、校准、固定虚警下的漏检和正确历史带来的收益。

### C. 分清训练覆盖、结构限制与信息不足

最少形成以下对照，不先堆模块：

| 对照 | 解决哪个疑问 |
|---|---|
| 强单帧模型；DeepPro-Plus；时间差分型TDCNet或DTUM；记忆型MTTU-Net | 问题是否跨模型存在，是否只属于一种归纳偏置 |
| 原训练；停走事件均衡采样；等量普通轨迹增强 | 是否只是缺少对应训练样本 |
| 当前帧重复、真实历史、错配历史、打乱历史 | 历史是否有用、是否依赖时间顺序；重复/乱序仅为诊断，不自动当自然分布 |
| 按各模型支持方式改变历史长度、限制记忆运行时长 | 长历史是否消除问题，还是只推迟退化 |
| 同训练样本、同训练曝光和相近算力的候选稳健训练 | 排除数据量、优化步数、计算预算的解释 |
| 若研究存在积累：单帧＋EMA/保留策略、常规跟踪、条件检测概率Bernoulli基线 | 收益是否只是输出持续更久 |

TPro 的时间线性层尺寸与窗口绑定，不能把40帧权重直接当作80帧模型；需要有效的独立训练或明确参数转换，并报告其代价。已有整窗多输出结果也不能直接叫在线检测。严格因果版本只用当前和过去帧；离线版本统一未来信息预算，二者分开。

### D. 最小训练候选：转换配对训练

先不增加新网络分支：
1. 为同一基础场景生成目标持续运动、提前停止、停后重启的配对样本，保持终点当前帧一致。
2. 用每个样本的正确检测标签训练，适度强调最差的运动/停止持续长度组；同时训练真实静态干扰、目标缺席和离场负例。
3. 在开发数据约束全图虚警，再检查未参与训练的真实停止事件、移动段及长停留段。

不强迫所有历史产生完全相同的概率，不把遮挡帧标成必须高置信检测。若额外使用配对一致性，只能限定在当前仍有足够可辨别证据的条件下，并独立消融；这仍是候选而非现成创新。

必须比较：同样样本但不配对的增强、停走均衡采样、常规最差组训练。若它们相同有效，优先接受简单解释。

### E. 指标和决策条件

主指标：在开发集冻结阈值或虚警工作点后的停止可见帧召回、事件等权召回、停止段最长连续漏检、重启后的首次稳定检出延迟。事件没有漏检/没有恢复时须标为删失或单独统计，不能随意填零。

同时报告：移动段性能、全图FP/帧或每百万像素虚警、静态干扰持续误报、离场后的虚警持续时间。阈值只在开发数据选一次；测试各状态不能分别调阈值。常规Pd/Fa、框指标与本地M/U保持各自定义，派生Gaussian mask不充当精确像素真值。

区间估计按原始场景组或事件组重采样，不把连续帧当独立样本。先导单种子可用于筛问题，正式训练至少多种子并给出不确定性；预先定义有实际意义的改善阈值与不劣界限。

| 观察结果 | 合理结论与下一步 |
|---|---|
| 控制SCR、可见性、背景运动后，多个模型仍有额外停后漏检 | 支持继续研究运动依赖 |
| 长度改变使退化点移动，均衡训练后仍存在 | 支持有限时间支持这一机制候选 |
| 等预算普通停走增强基本消除问题 | 训练覆盖解释更强；保留诊断贡献，不宣称复杂新机制必要 |
| 单帧与视频同样下降，主要由对比度/遮挡解释 | 不支持所述额外运动偏差 |
| 仅合成有效、真实不复现 | 干预或域差异问题，不能声称真实鲁棒性 |
| 停止召回提高但离场/亮点持续误报恶化 | 可能只是更强保留，主张不成立 |

2. IRDST官网真实子集为85/40650；TDCNet补充材料出现92/40656且又写42+43分割。应报告实际使用版本，不把数字混用。[官网](https://xzbai.buaa.edu.cn/datasets.html)、[补充材料](https://arxiv.org/html/2511.09352v1)
3. IRSTD-UAV原划分在每个序列内将50帧片段随机8:2。复现其成绩与证明跨场景泛化是不同协议；本研究必须补按原始场景划分的实验。[原文§3.2](https://arxiv.org/html/2511.09352v1)

**标注不是可见性真值。** RGBT-Tiny论文说明短于5帧的遮挡使用框插值，超过5帧的遮挡未解决。因此有框不保证当前看得见，缺框不保证离场。需新增bbox来源与可见性审核，而不能直接把标注间断当目标消失。[原文§III-B](https://arxiv.org/html/2406.14482v2)

另有处理版本排除了DAUB第21序列，理由包含盲像元、几乎无帧间位移和极暗目标。该例说明不同论文的难例保留政策必须对齐；这些因素混在一起，不能作为停止的单因果证据。[DEMNet §3.1](https://www.mdpi.com/2072-4292/17/17/2963)

获取：现有本地数据先用；RGBT-Tiny官方申请表本轮未提交。IRDST、NUDT、IRSTD-UAV和HGTMT提供下载入口。没有下载大包，也未核验各包独立数据许可证；代码许可证不能代替数据许可。

## 6. 最小事件标注结构

建议另存派生标注，不改原始框：

```text
scene_group_id, recording_id, sequence_id, track_id, frame_id, timestamp
original_bbox_or_point, corrected_location, localization_valid
bbox_provenance = observed / interpolated / unknown
in_view = yes / no / unknown
visibility_ir = visible / partial / fully_occluded / unresolved
missing_reason = occlusion / low_contrast / sensor_gap / out_of_view / unknown
existence_evidence = observed / inferred_continuity / unknown
motion_image, motion_background_compensated, registration_quality
motion_state = moving / stationary_relative_background / transition / unknown
event_id, stop_start, stop_end, restart, confidence, annotator, adjudication
```

可见光可辅助人工确认身份与遮挡，但纯红外方法推理不得输入RGB或GT运动/可见性。完全遮挡时未知位置不造框；未来重现只提供离线标注证据，不自动证明每一遮挡帧的位置。

速度阈值与最短停留长度根据定位噪声在train/dev确定，并做敏感性分析。按原始拍摄记录、地点和相关航迹分组，RGB/IR、裁剪、相邻片段及同源合成背景必须同组。

现有8训练/2开发/4确认的历史协议不改变。先在train/dev确定规则；新增独立数据另建协议。不能查看确认数据后挑停走案例，再称其盲测。

还应核对发布权重曾使用的训练序列：本地划分与作者预训练划分不同，不能仅凭本地文件名不重叠就宣称预训练从未见过测试场景。泛化主实验应使用来源明确的权重或按新协议重新训练；目前作者Gaussian监督的完整生成参数未取得，不能声称完整复现其真实数据成绩。

## 7. “缺失观测下证据积累”如何放置

建议作为第二阶段，或第一阶段的负对照，暂不与停止问题强绑成一个网络。

若没有采集到帧，跳过本次测量更新，但存在先验仍随时间变化；若收到清晰图像且预期目标容易检出，却没有目标证据，应降低存在信念。低置信度本身不能当遮挡证明，否则会产生自我维持的假轨迹。

经典条件检测概率已处理这类区别，新方法需要超越成熟Bernoulli/MBM和合理保留策略。完全遮挡与离场产生相同观测时没有可保证的辨识性，应表达不确定性，而非宣称必能找回。

评价应区分“当前图像检测”“遮挡中位置预测”“重现后恢复”。只补出遮挡框或提高MOTA，不能替代停止后可见帧检测改善。

## 8. 本地证据与建议执行顺序

已有CPU审计只基于框中心五帧净位移，未经图像核验：
- 训练集低位移连续≥16端点：27条轨迹；开发集9条。
- 与严格小目标评价相交后，开发集≥16端点仅4条轨迹，其中低响应3条。
- 这是可行性线索，不能证明物理停止、当前可见或停止导致漏检。主样本不能由低响应筛选得出。

详见[既有审计](pilot_feasibility_20261117/README.md)。既有局部视频探针结果为MIXED_OR_NULL，不是本方向的停走实验；已有历史融合负结果也不能当作新方案成功。

建议执行顺序：
1. 核验来源版本与标注语义，筛人工可确认的事件；预计1–3人日，取决于候选质量。
2. 建立事件对齐评估及同当前帧的受控诊断；预计2–4人日；先进行小规模CPU生成与GPU测速，再估完整费用。
3. 只有确认问题后才比较均衡采样、等预算增强与候选训练；预计3–7人日编码和分析，GPU时长须按实际吞吐另估，不把估计当实测。
4. 获得跨场景真实收益后，判断是否值得单独推进缺测存在推断。

本轮没有GPU开销。方法新颖性仍待实验和后续查新；独立Codex GPT-6-Astra审查属于同家族暂定意见，不是第三方认可。当前最有价值的产物是一个有明确否定条件的研究问题，而不是提前命名复杂网络。
