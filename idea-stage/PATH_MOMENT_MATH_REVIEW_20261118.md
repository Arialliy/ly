# 路径矩方案：数学、表示与实验识别审查

审查对象：`infrared_video_detection_research_plan.md`，2026-11-18。原文保持不变。没有训练、图像读取、数据下载或confirmation访问。以下判断针对文件中的具体数学模型，不评价论文首创性。

**结论：固定输入窗口、共享局部backward Markov对应图下，一阶/二阶递推和二次分数期望公式成立。方案可以实现，但“检测监督为何保留对应不确定性”尚没有训练目标层面的回答；时间编码、线性项实现和公平对照还需明确。独立数值复现通过，不等于检测效果通过。**

## 1. 高优先级：检测损失本身不鼓励保留多路径不确定性

位置：原文385行（常规检测监督）、541行（分布塌缩检查），以及285行的期望分数。

对固定输入、固定每条路径分数gπ，令s=Σπ qπgπ，二元BCE为ℓ(s,y)=log(1+exp(s))−ys。其导数为σ(s)−y。

- y=1时，损失关于s严格递减，因此若q可在单纯形内自由选择，最优解可集中到argmax gπ。
- y=0时，损失关于s严格递增，最优解可集中到argmin gπ。
- 单终点的局部Markov转移可以取确定性转移，从而实现任一支持内路径的点质量；有限softmax参数下可无限接近该解。

因此，“保存所有候选路径”不是这个损失自动奖励的性质。给定当前表示，训练可能偏向选出有利于标签的一条路径。原文把塌缩仅列为事后异常检查，低估了它与所选判别目标之间的联系。

这**不证明真实共享网络一定塌缩**：不同图像和终点共享参数、表示与q联合更新、有限容量以及优化偏置都可能保留混合。论断只针对单样本、固定路径分数、自由可调q的条件优化。也不能因为该风险就否定固定q下的二阶信息价值。

建议先完成两种彼此独立的判断：固定共同对应图时二阶信息有没有用；再让所有方法公平端到端训练，观察这种信息是否仍被保留。记录路径/局部转移集中程度和实际二阶修正，不预先添加熵正则来挽救原机制。

## 2. 高优先级：“加相对时间编码”不足以避免求和丢失顺序

位置：原文220–234行，尤其223行。

若实际采用常见加法h_t=F_t+p_t，则v=ΣF_t+Σp_t。对同一时间集合，第二项是固定常数；把两帧内容交换仍可得到相同v。单纯拼接h_t=[F_t,p_t]后求和也有同样问题。二阶矩无法恢复已经由该路径表示删去的次序。

必须明确时间与内容之间存在交互，例如h_t=B_tF_t，或者h_t包含b_j(t)F_t；也可以经一个已定义的非线性映射组合内容与时间。这里是补全原文已经要求的时间表示，不是额外创新模块。

少量时间基函数仍只保留受限的时序投影，不等于完整时序协方差。由R个投影得到的n_r=E[(a_rᵀv)²]足以精确计算**所选低秩二次头**，不能由此声称完整恢复所有跨时、跨通道依赖。

## 3. 中优先级：低秩实现漏写独立线性项的计算路径

位置：原文279、287行定义wᵀμ；327–368行只维护R个二次投影的m_r和n_r。

除非明确约束w位于span{a_r}，这些R个一阶投影不能一般恢复wᵀμ。例如a₁=(1,0)、w=(0,1)，路径表示v=(0,1)时，已有m₁=n₁=0，但线性项为1。

可直接维护一条标量一阶累积：

    l₁(x)=wᵀh₁(x)
    l_t(x)=wᵀh_t(x)+Σ_y P_t(y|x,X) l_(t−1)(y)
    s(x)=b+l_T(x)+Σ_r λ_r n_T^r(x).

这样不需要完整μ，复杂度成为O(THWK(R+1))，与原量级一致。若改为w=Σβ_ra_r，则应承认判别头的约束改变，并让基线使用相同约束。独立复现脚本采用第一种直接线性递推。

## 4. 中优先级：固定对应图和端到端公平训练需拆成两个实验协议

位置：原文490行、502–503行、511行。

文件同时要求“固定编码器/P”和“分别充分训练”。两者可以兼容，但必须写清分别训练的是head，还是连encoder/P一起训练。如果各方法端到端独立训练，P已经不同，结果不能单独归因于在同一q上多算了二阶矩；如果只冻结A3训练出的表示后比较head，则表示可能已经偏向A3。

建议明确：

1. **固定表示条件实验**：使用相同的冻结编码器、P和时间映射，对A2/A3/A4分别训练各自head；说明冻结表示的来源。共享权重的删项只能作为补充，不能代替充分训练。
2. **端到端性能实验**：各方法从匹配初始化和预算训练全部允许参数；此时只主张整套训练方案的差异，另报告P与修正项变化，不能声称“唯一变化仍是计算顺序”。

对511行的“保边缘破依赖”可以给出精确参考构造。对固定终点x，从同一个q求各时刻边缘q_t(x_t|X,x)，构造q_ind=∏_t q_t。它保持每个时刻特征的边缘分布，但删除跨时关联。相应地：

    M_ind = μμᵀ + Σ_t Cov_q(h_t | X,x)
    E_q[g] − E_q_ind[g] = tr[A Σ_(s≠t) Cov_q(h_s,h_t | X,x)].

这是比“随机打乱对应图”更严格的机制对照。q_ind产生的组合可能违反原局部边支持；它应被定位为信息消融参考，而非物理可行的新tracker。逐终点边缘的精确计算还需核算成本，首轮可以对少量位置做枚举/采样诊断，不应无依据声称全帧同成本。

另外，497行的A4若只读取已经压缩成v的均值，仍不能代表所有软对齐方法。可明确另一个强对照：保留各时刻对齐后的边缘特征/边缘二阶量，按时间拼接后交给等预算时序头。它没有完整路径联合关系，却避免过早把所有帧压成一个向量。若该对照已有相同收益，不能把结果推广成“软对齐普遍丢失了本方法才保留的信息”。上述q_ind对照仍是隔离跨时依赖的最直接参考。

## 5. 中优先级：递推状态的条件必须固定，不能直接跨滑窗缓存

位置：原文192、205行P依赖整个X；223行相对时间编码；373行复杂度。

递推的正确性条件是m_t(y)和n_t(y)均在**同一个最终输入窗口X**和同一组转移下定义。给定该X与当前状态x_t，过去路径按P_t分解，条件期望递推成立。历史时刻的P使用窗口内更晚帧不违反“当前输出无未来帧”，因为这些帧都不晚于最终输出时刻T。

但滑窗前进后X改变，如果匹配网络使用全窗口内容，历史P也可能改变；即使P只依赖相邻帧，相对终点时间基函数也可能全部变化。上一窗口保存的m/n不能不加证明直接复用。原文按窗口计算O(THWKR)是合理的，没有自动推出常数开销的在线更新。首版应明确每窗口重新递推，任何缓存优化另做等价检查。

此外，当前公式依赖转移P在所有最终终点间共享。若以后加入依赖最终目标查询/终点的P_t(y|x_t,x_T,X)，当前共享状态递推和复杂度不能直接沿用，需要保留额外条件状态。

## 成立的部分与次级边界

- q是归一化backward Markov路径分布。固定终点且每一有效节点转移归一化时，对所有过去节点依次求和得到1；边界掩码需先屏蔽无效节点再归一化。
- E[g(v)]−g(E[v])=tr(AΣ)成立。任何A只需取其对称部分；R维带符号分解定义的是rank≤R的对称二次头。
- 单点q必使Σ=0，但逆命题不成立：多条路径可以有相同v；即使Σ非零，所有a_r落在其零空间时低秩修正也为0。实际诊断需同时看q的集中程度、投影方差以及Σλ_r Var(a_rᵀv)，不能只看softmax熵。
- 带符号λ允许奖励或惩罚不同方向方差，符合原分析。它带来参数尺度非唯一性（a_r乘c，λ_r除c²）；累计和随T增大会使平方项达到O(T²)尺度。这是初始化、数值精度和窗口比较需监控的问题，不是推导错误，也不要求预先追加正则模块。
- 用n−m²计算小方差在低精度下可有消减误差；训练实现应对照双精度参考，并区分真实塌缩与舍入产生的微小负方差。
- 路径监督必须指明固定终点、GT身份及有效时间集合；若支持内没有任何允许路径，所写−log路径质量为无穷。不能把不可达样本直接作为普通有效监督，也不能将路径质量称为已校准物理概率。
