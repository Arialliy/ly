# 一种由新观测解除的高频歧义

在这个构造中，只有把两种采样位置的低清帧结合起来，才能判断中央高清图的相邻细纹是同相还是反相。在 8 个训练视频背景的 32 个合成样本中，已知载波的解析读取得到 **32/32**。冻结 DUF 的中央超分输出在指定高频分量上得到 **16/32**。这是一个可复现的合成例子。[冻结构造](PROTOCOL.md) · [逐样本记录](RESULTS.json)

## 如何保证揭示帧本身没有标签捷径

每块背景固定不变，生成四种等概率高清图。设载波幅度为 0.05，偶列采样的极性为随机符号 s，奇列采样的极性为 s×b。b 决定同相或反相，是要判断的事实。相同 s、相反 b 的所有偶相位低清帧完全相同。单独看奇相位揭示帧，(s,b) 和 (−s,−b) 也完全相同。程序直接核对了整个 RGB 像素数组的相等性。观察任一种相位时，等先验最优正确率恰为 50%。看到奇偶两帧后，两个低清帧与公共载波的投影符号相乘即可判断 b。真实背景中该指定频率的投影在构造前已去除。

| 中央图的观测时限 | 早到组的理论最优 / DUF | 晚到组的理论最优 / DUF |
|---|---|---|
| 中央时刻 | 50% / 50% | 50% / 50% |
| 看到下一帧 | 100% / 50% | 50% / 50% |
| 看到下两帧 | 100% / 50% | 100% / 50% |

早晚两组最终五个外部输入槽具有完全相同的图像多重集。揭示帧分别放在中央时刻后第一或第二槽，另一槽使用公共参考。对每个截止时刻，以参考填满尚未可用的槽，再从头前向计算中央帧。获得新观测前，模型在相反世界上的输出逐像素相同。

**连续响应也很弱。** 世界之间真实的奇列目标系数差为 0.10。固定背景及中心极性，有 16 对相反事实；早到组 10 对的 DUF 输出系数向正确区分方向移动，晚到组为 4 对。带符号的平均恢复比例分别为 −0.029% 和 −0.049%，未见有意义的系数区分。对早到组，真实奇列系数为 −0.05/+0.05 时，模型平均读出为 +0.000325/+0.000296；晚到组分别为 +0.000387/+0.000338。

**解读边界。** 数据使用 REDS 训练帧作背景，点采样、成对奇偶纹理及其证据时刻均由程序指定。自然视频中这类事件的频率、其他模型的表现及真实相机模糊的影响均未被测量。解析读出知道载波和采样几何，DUF 只接收 RGB 序列。五帧转七槽时复制首尾，最后一个外部槽被内部使用两次；模型也没有跨这些截止时刻保留循环状态。早晚两种结果有不同的槽位敏感性，不能推断时序“锁定”或普遍缺乏更新能力。

脚本使用 CPU 和仓库固定镜像，已完成退出码 0。数据选择仅使用 V1 训练序列 002、012、022、032、042、052、062、072 的第 32 帧中央 64×64 块。[执行脚本](witness.py) · [运行命令与源文件哈希](LAUNCH.json)
